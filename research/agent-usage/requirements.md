# Agent 用量记录：需求草案

调研日期：2026-10-02（Asia/Shanghai）。状态：需求与选型阶段；未开始实现。

## 已确认需求

| 项目 | 用户确认的范围 |
|---|---|
| 电脑端 | 当前 Windows 主机，常驻采集本机 agent 使用数据 |
| 手机端 | iPhone / iOS 优先，独立 App 为产品目标 |
| 联通方式 | 外网可查看，不能只依赖同一 Wi-Fi |
| 操作权限 | 手机只查看统计 |
| 覆盖对象 | Codex Desktop / CLI、Claude Code、OpenCode、Cursor、WorkBuddy、MiMo Code、Trae，以及其他常用国内外 agent |
| 计费方式 | 同时支持订阅账号与按量 API |
| 隐私 | 只同步统计；端到端加密，使云端不能读取统计内容 |
| 当前阶段 | requirements gathering 与 research，暂不写代码 |

用户输入中的“trea”暂按 Trae 理解。国际版、国内版、SOLO、Work 产品不能在采集能力上自动视为相同。

## 产品目标与用户任务

产品的目标是让用户离开电脑后，仍能在 iPhone 上回答：今天哪些 agent 和模型用了多少 token，趋势如何；哪些订阅额度接近用尽，何时重置；按量 API 的费用是多少；这些数字来自哪里、覆盖多少，以及最后何时更新。

手机看到的是电脑已采集并同步的数据。电脑休眠或离线后，历史统计仍可查看；新的本机活动和额度读取停止更新，界面必须标明最后采集时间。首版不把服务商凭据转移到手机，因此不能承诺电脑关机时继续刷新所有账号额度。

## 必须分开的数据口径

| 指标 | 定义与显示规则 |
|---|---|
| 本机观测 token | 从本机日志、数据库或官方事件中获得；可能不包含另一设备、网页端或云端任务 |
| 账号 token 活动 | 服务商返回的账号级统计，覆盖范围由服务商决定；与本机统计独立展示，不相加 |
| 订阅额度 | 服务商返回的百分比、积分、请求数、余额及重置窗口；不能用 token 数反推 |
| API 等价费用 | 根据模型价格估算的 token 成本；订阅使用可显示这一指标，但不是实际支付费用 |
| 服务商返回费用 | 来源可为 usage 或账单导出；标注具体来源，不能自动称为最终结算账单 |
| 最终账单费用 | 只有账单、结算数据或足够明确的计费 API 才能支持该名称 |
| 活动量 | 请求/会话数量、活跃日期等；不等价于生产力或任务价值 |

统一事件需要保留 agent、入口、provider、模型、设备、可确定的账号标识、来源时间、采集时间、来源类型、解析器版本及数据质量。未知值与已测得的零必须分开。模型缺失价格时显示“未定价”，不能显示为免费。

缓存和推理字段在不同来源里可能是输入/输出的子集。先记录字段语义，再计算不重叠的总量；不得把已经包含在输出中的 reasoning 再加一遍。项目与会话归因只在来源有明确证据时提供，不把历史全部归到当前登录账号。

## 支持能力合同

每个 agent 分别声明以下能力：检测、历史 token、token 拆分、模型、项目/会话、实时活动、订阅额度、费用来源、账号归属、Windows / WSL 支持。状态使用“已验证”“部分支持”“需授权连接”“未验证”“不支持”。

“安装了适配器”“上游 README 宣称支持”和“本机真实样本验收通过”是不同状态。综合首页必须显示覆盖范围和缺失来源，不能用静默零值掩盖未采集数据。

## 建议的最小版本 P0

以下为建议范围，尚不是最终验收批准。

1. 一台 Windows 电脑与一部 iPhone 配对。电脑有托盘、采集开关、状态、手动刷新及可关闭的开机启动；iPhone 有独立 App、刷新及离线缓存。
2. 外网端到端加密同步统计。电脑主动上传，手机主动读取；云端保存密文与必要的路由/权限元数据。手机读取凭证不能上传、改写或删除统计。
3. 今日、最近 7 天、最近 30 天、已有历史累计视图；按 agent 与模型查看 token 和估算费用；缓存拆分仅对具备可信字段的来源显示。
4. 已接通来源的订阅额度、独立额度池与重置时间。只支持读取，不自动消耗重置次数或触发充值。
5. 宽覆盖的适配器目录；优先验收 Codex Desktop / CLI、Claude Code、OpenCode、WorkBuddy、MiMo Code。Cursor 与 Trae 单列所需连接方式及能力限制，纳入首版支持矩阵。
6. 数据质量页面：来源、覆盖时间、最近采集、最近云同步、是否过期、错误原因、未定价模型、部分数据。
7. 可清晰选择范围的本地导出、数据删除与设备解绑。删除统计不能删除 agent 自身业务数据。保留期按后续确定的策略实施。

不建议把“每个市面上的 agent 都有 token、实时状态和准确账单”列为首版承诺。全面覆盖的目标应体现在适配器目录与持续验证上，不能通过猜测补齐数字。

## 排除与后续范围

| 项目 | 建议阶段与原因 |
|---|---|
| 远程发任务、审批、终端、改文件、切模型/账号 | 排除；用户选择了只查看统计 |
| 提示词、回复、代码和完整对话同步 | 排除；统计产品不需要保存或上传这些内容 |
| 公共排行榜、公开个人主页 | 排除；与私人统计和端到端加密目标不符 |
| 自动修改全部 agent 配置或统一走代理 | 排除默认行为；需要时再明确选择单个接入方案 |
| 自动购买额度、消耗重置权益、自动切账号 | 排除 |
| 多用户团队权限、团队报表、企业计费、营销订阅 | 排除首版；个人自用是当前工作假设 |
| Android、macOS / Linux 客户端 | 后续；目前 iOS 与 Windows 优先 |
| 项目/会话详细分析、父子 agent 成本归因 | P1；有来源证据再提供，不能猜测关联 |
| WidgetKit 主屏幕/锁屏组件、Live Activities | P1；独立 iOS App 与加密闭环先验收 |
| 自定义区间、年度热力图、预算提醒 | P1；预算口径先区分 API 估算与账单 |
| App Store 公开发布 | 独立发布阶段；不视为本轮授权 |

## 建议验收标准

1. 对首批每个来源选取脱敏真实样本，能够解释并独立核对 token 总量、缓存/推理拆分和归因；记录工具版本与解析器版本。
2. 会话日志迁入归档、文件复制、重试、fork、父子 agent、重启及重复上传，不产生额外使用量。不同设备读到同一账号额度时，不叠加额度百分比。
3. 部分日志、不完整 JSONL、数据库忙、凭据过期、缺少字段和未知模型，显示部分/不可用状态；失败不能把已有有效统计清成零。
4. 经官方来源读取的额度，在相同账号与同一观察时间范围内可核对；窗口长度按实际返回显示，不写死 5 小时/一周。
5. 在电脑在线、样本来源可持续更新、网络正常时，本地统计变化到 iPhone 前台可见的目标为 60 秒以内；这是待测目标，不是已测结果。额度读取建议先按 5 分钟与退避策略设计，尊重服务商限制。
6. 电脑断网后继续本地采集；恢复网络后补传且不重复。电脑休眠后手机仍可看历史，并清晰显示过期状态。
7. 使用蜂窝网络完成真实 iPhone 测试，验证连接、刷新、切后台/恢复、离线缓存和配对撤销。桌面浏览器模拟不能替代 iPhone 真机。
8. 云端数据库、服务日志和网络载荷中没有统计明文、provider 凭据或对话内容；篡改密文和重放旧版本被客户端拒绝。
9. 手机只读凭证尝试上传、删除、管理设备时被服务端拒绝。撤销设备后停止授权，并按设计轮换后续内容密钥；已被被撤销设备解密或复制的历史无法追溯抹除。
10. 用户能完成导出、解绑和删统计；不影响 agent 会话、配置、凭据与项目文件。安装后验证真实登录启动、退出停止采集及无多实例重复采集。

## 尚需决策

| 问题 | 当前工作假设或影响 |
|---|---|
| 自用还是计划公开产品 | 暂按个人自用设计；商业化会增加账号、分发、运维与许可证核查工作 |
| 云服务月预算与部署区域 | 未确定；不能把海外服务免费层当成国内蜂窝网络可用性保证 |
| iOS 分发与构建资源 | 需决定真机开发测试、TestFlight 或公开上架，以及本地 Mac / 受控云构建方式 |
| 小组件是否首版硬要求 | 建议 P1；如必须随首版交付，需重排 iOS 技术选型 |
| 保留期与恢复方式 | 未确定；可讨论详细统计保留 90 天、日汇总更久的策略；不自动采纳 |
| 密钥恢复 | 建议首版以电脑为恢复来源，手机重装可重新配对；避免服务商托管可解密统计的密钥 |
| API 账单与账号级授权 | 需列明各 provider 是否存在可用的只读账单/用量能力；当前未授权读取任何真实凭据 |

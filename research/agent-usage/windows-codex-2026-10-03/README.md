日期：2026-10-03，Asia/Shanghai。

用户已明确本轮范围为「当前 Windows 本地统计＋Codex 额度」。本轮交付需求与资料调研，不实施代码，不运行候选应用，不连接账号，不改变已批准阶段。原 research/agent-usage 中的长期需求与既有研究保留。

## 结论

继续保留当前 Electron、token-monitor v0.65.0 与官方 Tokscale 4.17.0 基线；从 AgentHub、Win-CodexBar 等提取额度状态、刷新策略和异常测试思路。先证明本机统计准确、独立账号额度可核对和真实 Windows 生命周期可用，再评估其他提供商、手机和同步。

当前最重要的产品合同是：本机 token、账号额度、API 等价估算各自显示来源和时间；缺失与零分开；历史 token 不猜测账号归属；连接账号不改变其他客户端登录。

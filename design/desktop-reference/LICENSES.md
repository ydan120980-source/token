# Asset and dependency attribution

- Design reference: [Tokens](https://github.com/missuo/tokens), MIT, original contributors Junho Yeo and Vincent Yang. The preview was independently implemented from observed public UI; its cloud/CLI/source code is not imported.
- UI icons: [Tabler Icons](https://github.com/tabler/tabler-icons), npm `@tabler/icons` **3.48.0**, MIT. Copyright 2020–2026 Paweł Kuna. Original SVG assets and full license are in `assets/ui/`. `calendar.svg` (added 2026-10-06) was reproduced offline from the Tabler outline `calendar` icon and has not been byte-compared with the 3.48.0 package. `copy.svg` and `history.svg` (added 2026-10-12) were reproduced offline the same way from the Tabler outline `copy` and `history` icons and have not been byte-compared either.
- Typefaces: Inter and Noto Sans SC (思源黑体), both SIL Open Font License 1.1, chosen in `docs/m2/UI-FONTS-20261029.md`, licence texts beside the WOFF2 files; Geist Mono from [Geist](https://github.com/vercel/geist-font), npm `geist` **1.7.2**, SIL Open Font License, unmodified variable WOFF2.
- Agent icons: existing token-monitor assets, retained under the repository's MIT source baseline and attribution in `docs/m1/UPSTREAM.md`. Codex and Claude marks identify their respective sources; they do not indicate affiliation. Generic Tabler icons are used where a source-specific brand asset has not been verified. The Antigravity mark (`assets/agents/antigravity.svg`) wraps the `icon.png` shipped in the locally installed Antigravity app (`resources/app.asar`), unmodified apart from cropping; Antigravity is a Google product and the mark only identifies the source. Marks added 2026-11-04, each only identifying its source, none implying affiliation: GitHub Copilot from primer/octicons (`copilot-24.svg`, MIT), Cline from cline/cline (`assets/icons/icon.png`), Pi from pi.dev (`favicon.svg`, its system-theme rule removed), Continue from continuedev/continue (`docs/logo/light.svg`), Qwen Code from QwenLM/qwen-code (the VS Code companion's `assets/icon.png`), Kilo Code and Kimi from their organizations' GitHub avatars (Kilo-Org, MoonshotAI), wrapped in an SVG with rounded corners.

- React layer (2026-10-25, `docs/m2/UI-REACT-FOUNDATION-20261025.md`): `ui/agent-ui.js` and `ui/agent-ui.css` are built from `ui/` with React, Radix UI, Motion, Tailwind CSS, Tabler/Lucide icons and components vendored from [fluid-functionalism](https://github.com/mickadesign/fluid-functionalism) (MIT, upstream commit 7387f36, local changes listed in `ui/src/vendor/fluid/VENDOR.md`). The build writes every bundled package's name, version and license text to `ui/agent-ui.LICENSES.txt`, which ships beside the bundle. These packages are build-time devDependencies; none is a runtime dependency of the app.

The production runtime dependencies in package.json and the Tokscale pin are unchanged. Any further integration must preserve the applicable notices.

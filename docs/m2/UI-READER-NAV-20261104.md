## 改了什么

### 左栏（`ui/src/pages/sessions/reader-nav.tsx`）

- 顶部切换：目录 / 会话。页面顶部的“打开其他会话”按钮和 `PanePicker` 弹窗都去掉了，`O` 键打开“会话”并把焦点放到搜索框。
- 会话按项目分组（文件夹图标，可折叠）；每组先显示 5 个，其余放在“展开显示”后面。当前会话高亮；置顶的组在最前。
- 每行：Agent logo、名称、最后活动时间，下面一行是活跃点、Token、估算和时长。未命名的会话显示时间，和会话页的规则一致。
- 指向一行时，时间换成三个操作：置顶、并排打开、归档。旁边的悬停卡片列出 Agent、项目、模型、起止时间。键盘 Tab 也能到这些操作。
- 点一行就在当前位置打开，左栏停在“会话”上，可以连续看下去。放不下更多栏时，“并排打开”不可用，并说明原因。
- 搜索框旁的筛选按钮展开两项：按项目 / 按时间，只看一个 Agent。
- 折叠状态只保存在这次运行的内存里，不写入新的路径。

### 默认状态的变化

- 左栏默认打开，不再要求 4 轮以上：短会话也要能找到其他会话。隐藏后记住选择。
- 目录从右栏的标签移回左栏，右栏固定为五个标签。并排时两栏怎么放，以 `UI-READER-PANES-20261104.md` 为准（所有者当天改为不遮挡）。
- 换会话读取期间，左右栏都不再收起又打开。

### 右栏（`ui/src/pages/sessions/side-tabs.tsx`、`compare.tsx`）

- **文件**（照 Codex 的更改树）：工作区名、筛选框、“所有更改”、“已更改的文件”，然后是目录树。文件有类型图标，名称和右侧标记表示新增、删除或修改，并显示增减行数。选中文件后只看相关的轮次，底部给出“还有哪些会话改过它”。
- **命令**（自行设计）：按轮次折叠。普通命令前面是 `$`，失败的是红色叉；程序名加重；能复制；长命令悬停看全文。
- **失败**（自行设计）：按轮次折叠。显示工具、它做了什么、输出的第一句话。
- **对比**（自行设计）：每个会话用 logo 加序号区分，因为两个会话可能是同一个 Agent。估算和 Token 用横条，构成用堆叠条，轮次、工具等计数放在紧凑表格里。还没选对比对象时，列出最近的会话（同项目优先），点一下就加入。

### Kit 和令牌

- 新增 `ui/src/kit/side-list.tsx`：`SideRow`、`TreeChevron`、`FileMark`、`FileStatus`、`DiffCount`。
- `useHoverCard` 的 `bind` 增加位置参数，密集列表的卡片放在列表外侧，不盖住其他行。
- `tokens.css` 新增 `--ff-count-*`、`--ff-file-*`、`--ff-side-selected`。这些颜色只区分改动方向和文件类型，不表示好坏。

## 判断（不是所有者原话）

- **修改状态的来源**：只有记录明确写了新增（`add`）才算新增。整文件写入（`write`）可能覆盖了旧文件，所以算修改。
- **只有一个子目录的目录合并成一行**（`design/desktop-reference`）：Codex 是逐层展开的，但右栏窄，逐层缩进会挤掉文件名。如果所有者想要逐层，可以改。
- **点一行是替换当前会话，并排要点操作**：和 Codex 点侧栏的行为一致；旧的弹窗默认是并排。

## 顺手修的旧问题

`PositionRail` 占了共享提示层的渲染位，却没有渲染这一层，所以阅读页上这个层的悬停卡片都不显示，包括位置条自己的卡片。现在渲染了。

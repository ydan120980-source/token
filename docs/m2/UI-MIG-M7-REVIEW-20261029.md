## 3. 修整内容

- **今天卡片**：
  - 四项读数（Token、估算、记录、会话）统一成“小标题在上、数字在下、右对齐”，用间距隔开，不画竖线。
  - 会话数改用 kit 的 `ValueButton`。它和旁边的数字同字号、同字重，没有内边距，指上去出下划线。
  - 表格改用 `DataTable variant="plain"`：没有行线，表头是灰色小字，每个 Agent 组的上方多留一些间距。
  - 模型行改为缩进，去掉树形连线。
  - Agent 行后面的“N 个会话 · N 条记录”改成灰色小字，不再用灰色徽章；会话数仍然可以点。
- **用量页其余部分**：
  - 活动区去掉日历和每小时之间的分隔线，每小时右侧的读数列表也去掉了行线。
  - 趋势底部“峰值日”的值改用 `ValueButton`，和其它三项对齐。
  - 删掉“点一天看它的 24 小时”。
- **kit**：
  - `DataTable` 新增两个可选参数：`variant="plain"`（不画线）和 `groupStart`（组首行上方加间距）。默认仍是 `ruled`，其它调用方不变。
  - 新增 `ValueButton`。
  - `TreeBranch` 保留，`ListRow` 和组件展示页仍在用。

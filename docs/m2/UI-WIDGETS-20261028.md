# 小组件栏实现记录 · 2026-10-28

**状态**：已实现，并用合成数据做了测试。依据是所有者 2026-10-27 通过的第四版设计，见 `UI-PALETTE-QUOTA-SUMMARY-PROPOSAL-20261027.md` 第 4 节。本记录覆盖实施顺序中的“侧栏框架”和“小组件”两步。“概览”首页和 C 配色另行记录。

## 1. 做了什么

| 部分 | 实现 |
|---|---|
| 位置 | 原来额度页的摘要栏改为小组件栏，除设置页外每个页面都有。窗口宽 ≥ 1360 时停在页面面板右侧的窗口底色上，页面面板相应变窄；更窄时从标题栏按钮浮出。阈值原来是额度摘要用的 1120，现在提高到 1360。原因是在 1280 宽的窗口里，停靠后费用页内容区只剩约 712 像素，低于 760 像素时费用表会收起占比、单价、构成和走势四列。按钮上的小圆点表示有额度连接需要处理。 |
| 布局数据 | `design/desktop-reference/widget-layout-model.js`：纯数据，`tests/m1/widget-layout-model.test.js` 覆盖。保存在本窗口的 `localStorage`（`agentusage.widgets.v1`），与个人资料、主题等本机偏好相同。最多 6 套布局，每套最多 16 个小组件。读到无效数据时回到默认布局。 |
| 默认布局 | 额度窗口、今天、每天花费、近 7 天，都是中尺寸（所有者 2026-10-27 确定）。 |
| 编辑 | 点“编辑”后，每个小组件上方出现工具条：拖动标记、S / M / L、设置、移除；末尾是“添加小组件”。排序方式：按住小组件拖动，或聚焦后按 Alt + ↑↓。 |
| 组件库 | 右侧 Sheet，按分类浏览。预览就是小组件本身，用当前数据渲染，不能交互。同一种小组件可以添加多个，比如两个额度窗口分别看不同 Agent。 |
| 单个小组件设置 | 右侧 Sheet：尺寸、颜色（跟随 Agent / 单色 / 墨色）、背景（默认 / 浅灰 / 着色 / 反色）、Agent 范围、时间范围（有的才显示）、在标题栏显示读数（额度窗口）。范围与当前页面的筛选无关。 |
| 标题栏读数 | 某个额度窗口小组件打开读数后，标题栏显示该 Agent 前两个窗口的读数，例如“5h 0% · 周 84%”。点击打开额度页。同一时间只有一个小组件显示读数。 |
| 管理布局 | 设置 › 常规 › 小组件：重命名、切换、删除（至少保留一套）、复制当前布局为新布局、把当前布局恢复为默认。有多套布局时，栏顶的布局名变成下拉菜单。 |
| 明细 | 带箭头的行点击后在原位展开，不用悬停浮卡，也不压暗其他项。 |

13 个小组件在 `ui/src/pages/widgets/`。共用的外框、明细行和小图形在 `ui/src/kit/widgets.tsx`，背景、着色和斜纹在 `ui/src/theme/widgets.css`。新增的 token：C 配色的蓝阶 `--ramp-1…5` 和墨色四档 `--ink-1…4`，在 `tokens.css` 里分浅色和深色两组。原有 Agent 色和其他颜色值都没有改。

## 2. 与设计稿的差异和原因

| 设计稿 | 实现 | 原因 |
|---|---|---|
| 栏的标题叫“侧栏” | 叫“小组件”，标题栏按钮也叫“小组件” | 左侧导航已经叫“侧栏”（“收起侧栏 Ctrl+B”），同名会混淆。 |
| “最近 1 小时”，每分钟的 Token | “最近 24 小时”，每小时的 Token | 快照只按小时保存，没有分钟数据；不能编造分钟曲线。“采集中”只表示采集开着。 |
| 设置弹层贴在小组件旁边；组件库是浮层 | 两者都用右侧 Sheet | 按 UI 规则，对话框复用已有的 Sheet，不另做浮层组件。 |
| “设置 › 侧栏”单独一节 | 放在设置 › 常规里的“小组件”卡片 | 内容只有一张卡片，不值得单独占一个分类。 |
| 每个窗口一行一个小眼睛 | 每个小组件一个眼睛（在标题行），设置里也有同一开关 | 标题栏一次只显示一个小组件的读数。 |
| 拖动 ⠿ 立即开始 | 按住约 0.35 秒后开始拖动，⠿ 只是标记 | 复用额度卡片已有的排序组件，行为和键盘方式一致。 |

## 3. 数据规则

- 只读渲染层已经持有的本机数据：每日和每小时用量、已保存的来源状态、会话列表、额度视图模型。读取不触发采集，不发 provider 请求，也不写任何东西。为此在 `preview.js` 的 `usageData` 上加了只读的 `hourly()` 和 `sources()`，在 `sessionsUi` 上加了只读的 `list()`。
- 未计价显示“未计价”，未报告的类型显示“未报告”，都不显示为 $0。额度不跨账号相加。“比上月同期”胶囊用中性色。
- 额度相关的小组件使用额度页的视图模型，所以隐藏的卡片在小组件里也不出现。
- Agent 图的连线表示“本机在读取这个 Agent”以及读取或连接的状态，不表示调用关系。

## 4. 额度页的变化

原来的 `quota-summary` 岛已退役。“需要处理”和“未连接的 Agent”两个列表现在固定显示在卡片下方（`quota-after`），不再依赖摘要栏是否固定。概览改版时，这一部分会再调整。

# 外框与页面版式规格 · 2026-10-27

本规格补充 `UI-SPEC-20261025.md`（颜色、文字、控件、动效、数据显示），规定外框和页面的几何：每个区域的位置、尺寸、间距和层级。两份规格冲突时，几何以本规格为准，其余以 `UI-SPEC` 为准。对照门槛见 `UI-LAYOUT-GATE-20261027.md`。

## 0. 所有者决定（2026-10-27）

| 项 | 决定 |
|---|---|
| 外框 | 侧栏和标题栏放在窗口底色上；每个页面放在一块圆角面板上，面板四周留出底色（参考 Codetwo 的圆角叠加）。 |
| 右侧栏 | 只保留摘要栏的功能，做成 Codex 式的弹出卡：标题栏按钮展开、收起；窗口够宽时固定在面板右上，页面让出位置；窄时浮在页面上方。2026-10-27 更正：所有页面都有摘要栏（设置页不放），内容是该页的缩减精华（`UI-UNIFY-COST-REFERENCE-20261027.md` 第 5 节）。 |
| 左侧栏 | 双层侧栏暂不做；保留单层侧栏和收起成图标栏的现有功能。 |
| 额度页 | Claude 重做渲染层（M6），数据层沿用 Codex 提取并经审核的 `quota-model.js` / `quota-host.js`；账号卡片保留旧渲染（`quota-card-grid.js`）。2026-10-27：当前是过渡版本，新设计定下前不做设计改动（`UI-QUOTA-PAGE-20261027.md`）。 |
| M7、M8 | 仍由 Codex 实现，先 M8 后 M7。外框几何按本规格；外观按 `UI-UNIFY-COST-REFERENCE-20261027.md` 统一到模板库和费用页，~~不再要求与旧版逐像素一致~~（2026-10-27 更正）。 |

`UI-SPEC` 第 3 节“不允许卡片里再套卡片”的含义不变：面板是页面本身的底，不是卡片；卡片直接放在面板上，卡片里仍然不得再放卡片。

## 1. 外框几何

数值都在 `design/desktop-reference/tokens.css`，下表是 CSS 像素。

| 区域 | 位置和尺寸 | 颜色 |
|---|---|---|
| 窗口底色 | 整个窗口 | `--bg`（浅 `#f6f6f6`，深 `#171717`），与系统标题栏覆盖层同色 |
| 标题栏 | 顶部 44 高，通栏；右侧 140 宽留给系统窗口按钮 | `--bg`，无底边线 |
| 侧栏 | 标题栏下方，宽 216（`--sidebar-width`）；收起后 60（`--sidebar-rail`） | `--bg`，无右边线 |
| 面板 | 上 44、右 8、下 8（`--panel-inset`），左贴侧栏；圆角 16（`--panel-radius`） | `--panel`（浅 `#fff`，深 `#1e1e1e`），外圈 1 像素 `--panel-edge` |
| 面板内边距 | 上 36；左右 `clamp(24px, 4vw, 56px)`（1180 宽时约 47）；摘要栏停靠时左右 32（`--panel-padding-docked`）；下 40 | — |
| 内容宽度 | 旧页面的 section 最多 1050 / 1100，居中；React 页面用 `max-w-275`（1100）居中 | — |
| 摘要栏（固定） | 窗口宽 ≥ 1120 时，弹出卡固定在右上：上 52、右 16（`2 × --panel-inset`），宽 304（`--summary-width`），最高到窗口底部 24（`100dvh − 52 − 3 × --panel-inset`），内容自己滚动；圆角 14（`--radius-l`），`--card-edge` 细线加浅阴影（`0 8px 24px` 6%）；层级 6。面板左右内边距改为 32（`--panel-padding-docked`），右侧再让出 `304 + 16`。 | `--card` |
| 摘要栏（浮动） | 窗口宽 < 1120 时，同一张卡、同样的位置和尺寸，浮在页面上方；弹出层阴影（`--pop-shadow`）；层级 30；页面不让位 | `--card` |
| 窄窗口（≤ 800） | 侧栏变成标题栏下方的横条；面板左边距改为 8 | — |

**滚动方式**：窗口本身滚动（页面和测试都读 `window.scrollY`），面板不是滚动容器。`#panelFrame` 固定在面板的位置，用底色画出面板外的区域和四个圆角，页面滚动时内容从它下面经过。层级：面板遮罩 4，侧栏 5，摘要栏固定 6、浮动 30，标题栏 20。页面里新的固定或粘性元素层级要低于 4，弹出层高于 30。

**侧栏收起、摘要栏开关的动效**：宽度、外边距和位置一起变化，240 毫秒（`--motion-shell`，对应 `spring.slow`）；动效设为“减少”或“关闭”时直接到位。

**摘要栏的行为**（`window-shell.js`）：
- 页面在 `#summaryPanel` 的 `data-summary-views` 里登记后才显示标题栏按钮。2026-10-27 起所有页面都要登记（设置页除外，按钮隐藏）；目前只有额度页已登记，其余页面随各自的迁移加入，在 `#summaryPanel` 里放自己的岛 `<page>-summary`，只在该页是当前视图时渲染。
- 内容：该页的缩减精华，每页 2–4 节，只读加跳转，不放页面上没有的操作；没有内容时不显示按钮（`UI-UNIFY-COST-REFERENCE-20261027.md` 第 5 节）。
- 宽窗口下，开关状态记在 `agentusage.summary.v1`（各页共用一个开关）；窄窗口下只在本次打开有效，按 Esc、点击栏外或切换页面都会关闭。
- 页面通过 `window.uiShell.summaryAttention(count, label)` 在按钮上显示提醒圆点。
- 摘要栏没有停靠时，页面必须在正文里提供同样的内容，不能让任何操作只存在于收起的栏里。

## 2. 页面结构（面板内）

从上到下：

| 位置 | 规定 |
|---|---|
| 页头 | 标题 `text-display`（28 / 34，semibold）；标题右侧可以放一个状态短语（`text-caption`，带 14 像素图标）。说明行 `text-caption`。操作放在页头右侧，宽度不够时整组换到标题下方，不拆开。 |
| 页头与提示 | 间距 12（`gap-3`）：批次结果、横幅、状态消息紧跟页头。 |
| 区块之间 | 32（`gap-8`）。 |
| 区块标题 | `text-title`（16 / 22，semibold），右侧放筛选或操作；标题与内容间距 16（`gap-4`）。 |
| 卡片网格 | 列宽至少 260（`ff-grid-quota`），自动填满，间距 16；同一行的卡片等高（`Card fill`）。 |

## 3. 卡片

新的 React 页面用 kit 的 `Card`：

| 项 | 规定 |
|---|---|
| 外形 | 圆角 16，内边距 24（`p-6`），1 像素 `ring-border` 细线，底色 `bg-surface-3`。 |
| 卡片头 | 24 的 Agent 图标、名称 `text-subtitle` semibold、Badge；下面一行次要信息 `text-caption`；右侧时间 `text-caption`。 |
| 卡片内的块 | 子块用 `bg-surface-2 rounded-xl`，警示块用 `bg-warn-soft rounded-xl`，内边距 12 / 8。 |
| 卡片脚 | 贴底（`mt-auto`）：左侧状态，右侧操作（紧凑档）；放不下时换行，不截断状态。 |
| 主数字 | 百分比 `text-figure-md`（28），金额和余额 `text-figure-lg`（40），单位 `text-caption`。 |

**额度页的账号卡片例外**（所有者 2026-10-27“agent 卡片不要改，还用原来的”）：卡片、筛选条和卡片移动用旧渲染 `design/desktop-reference/quota-card-grid.js` 和旧样式，几何以旧版为准，不套上表。它渲染进 `#quotaCards`，位于 React 岛 `quota` 和 `quota-after` 之间。

## 4. 控件档位

默认 36；紧凑 28 只用于：区块标题旁的筛选、卡片里的操作、卡片脚、摘要栏的行内操作、Sheet 脚里的逐行操作。

## 5. 颜色

除 `UI-SPEC` 第 1 节外，新增两个语义色：`bg-panel`（面板底，只给外框用）和 `bg-warn-soft`（警示块的底，`--warn` 的 14%）。警示色仍然只用于“真正用尽或登录失败”。

## 6. 额度页（过渡版本）

`ui/src/pages/quota/` 加旧卡片渲染。2026-10-27 所有者对现状仍不满意，这是过渡版本：保留接口、钩子和下表的分区与位置，新设计定下前不做设计改动，也不作为其他页面的版式参照（参照改为费用页，见 `UI-UNIFY-COST-REFERENCE-20261027.md`）。记录：`UI-QUOTA-PAGE-20261027.md`。

| 区块 | 内容 |
|---|---|
| 页头（React 岛 `quota`） | 标题、最快恢复的短语；“已连接 N / M · K 个需要处理 · J 个超过 1 天未更新”（最后一项可点，依次定位）；剩余 / 已用、自动刷新、复制摘要、全部刷新。 |
| 概览（`quota`） | 两张卡：最紧的窗口（读数、时间与额度两条、节奏、切换其他窗口），余额（每个账号各自的单位，不相加）。 |
| 接下来（`quota`） | 24 小时 / 7 天 / 30 天；每条窗口或到期一行，点轨道或标记固定时间针，读出那一刻的数值和已重置、已到期的批数。 |
| 账号（旧渲染 `#quotaCards`） | 筛选、长按或 Alt + 方向键排序、隐藏；卡片显示窗口、余额（WorkBuddy 按到期分组的构成）、没有额度项、尚未读取。详情和连接的 Sheet 由 React 岛经 `window.quotaUi` 打开。 |
| 卡片下方（React 岛 `quota-after`） | 摘要栏没有固定时：需要处理、未连接的 Agent、说明，与摘要栏同一份内容。 |
| 摘要栏（`quota-summary`） | 下一次恢复、需要处理、未连接的 Agent、说明。 |

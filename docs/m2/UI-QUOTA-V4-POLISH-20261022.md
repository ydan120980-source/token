# 额度页 v4 细节打磨（2026-10-22）

v4 三步合入后，所有者圈出四处问题，并要求"继续优化 UI 细节，符合整体设计，Apple design 风格"。参考：所有者提供的"借鉴卡片"，以及 Apple《Designing Fluid Interfaces》等公开设计原则（克制、层级、细节打磨、标签不与其他元素争位置）。

## 所有者圈出的问题与处理

| 圈出的位置 | 原因 | 处理 |
| --- | --- | --- |
| 时间线上的到期标签 | 标签放在菱形上方，压住了刻度上的"周一"；两个相邻菱形抢一个标签的位置 | 标签一律放在标记右侧、与标记垂直居中，不再出现在上方。<br>距离不足一个标签宽度的标记共用一个标签，写在最后一个标记之后，例如"25 日起 · 120"。<br>超出范围的批次写成"+24 批"，完整说明放在悬停提示里 |
| Codex 每周泳道 | 色条很粗、里面塞了文字；"84%"紧贴色条；重置竖线压住了时间文字 | 泳道改为 6px 的细胶囊；重置处画一个外圈是卡片底色的圆点；时间和节奏写在圆点旁。<br>标签超过轨道约三分之二时改到圆点左侧，并加卡片底色衬底。<br>名称列和轨道之间留 12px。<br>新增浅色日刻度线；刻度起点标"现在"，紧挨着"现在"的日刻度不再标注 |
| WorkBuddy 钱包口袋 | 卡片内容竖直居中，内容超出时会同时向上溢出，压到标题；原来的裁切检测只测了底部 | 卡片内容改为 `justify-content: safe center`，超出时只向下溢出，不压标题。<br>票据改为浅色调（Agent 色 24%，7 天内到期的用警示色 15%），文字用正文颜色。<br>口袋再收紧约 10px。<br>截图工具的裁切检测改为同时测量上下两个方向 |
| OpenCode 需要处理框 | 整块暖褐底色显得浑浊 | 改为中性的浅底，标题前加一个警示色圆点，只有标题用警示色。<br>副标题缩短为"下方是 1 天前的数据" |

## 其他调整

- **需要处理条**：改用卡片底色，警示色只保留在"需要处理 N"前的圆点和文字上。
- **说明文字**：时间线说明改为"圆点是重置，菱形是到期"。
- **泳道名称**：同一连接的多个待刷新窗口写成"N 个窗口"。
- **Agent 色调选择器**：第二步加的 `[data-agent]` 色调选择器原本对所有页面生效，现在限定在额度页的泳道、需要处理条和详情面板内，不再影响用量页、会话页的 Agent 选择器。

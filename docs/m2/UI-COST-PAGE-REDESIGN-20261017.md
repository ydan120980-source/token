# 费用页重新排版与新增功能（2026-10-17）

接在 `UI-COST-PAGE-20261017.md` 之后。项目负责人看过第一版后认为单张大卡片不符合整体版式，要求重新排版、加功能，并且和用量页有明显的方向差异。样稿经过几轮修改后批准，要点如下：

- 版式与用量页相同：不加框的总览，再加带分组小标题的卡片；
- 以文字为主，图只做辅助；
- 费用构成用两张方格对照（负责人在四个方案里选定）；
- 订阅月费存本机设置；
- 推算按有用量的日子；
- 方格的 Token 一侧按"每 100 万 Token"。

## 方向

用量页回答用了多少、什么时候用（热力图、趋势）。费用页回答四件事：
- 花了多少；
- 钱花在哪种 Token 上；
- 和订阅比是多少倍；
- 哪些没算进去，以及怎么补。

## 页面

- **页头**：标题、时间范围、导出图标，导出由原来的文字按钮改为与用量页相同的图标。
- **总览**：
  - 估算区间作大字，旁边是累计估算的小曲线；
  - 下面四个数：缓存约省下、每百万 Token、日均、未计入的 Token；最后一项带"去核对"，跳到核对区。
- **费用构成**：
  - 两张 10 × 10 方格：
    - 左边每 100 万 Token（每格 1 万）；
    - 右边每 $100，按上限算，估算区间占斜纹格。
  - 方格旁用文字写出差异最大的两项和区间，例如"缓存读取 28 格 Token → 1 格费用"。
  - 下面是各项的金额、占比、Token、每百万均价和走势（范围不到 31 天按日，否则按周）。
  - 指向某一行时，两张方格只留这一项的颜色。格数按最大余数法凑满 100。
- **账单**：
  - 按月：每月的估算区间、较上月、已计入比例和一条细条（下限、区间，当月另有推算段）。
    - 点一个月，整页切到这个月，范围按钮旁出现"N 月 ×"。
    - 再点或点 × 恢复原来的范围。
  - 订阅对照：
    - 选了某个月就按那个月对照，否则按最近一个完整的月份；
    - 每个 Agent 一行：API 等价估算、月费输入框、倍数、一条细条（竖线是月费）。
- **去向**：费用明细表，结构同第一版，另加两处：
  - 每行加近期走势；
  - 展开后的每日 Token 图有单独的标题，和上面的缓存命中率分开。原来紧贴在命中率下面，容易被看成命中率的走势。
- **核对**：
  - 计价覆盖：已计入比例；未计入的用量按原因分组，每组列出涉及的模型，并给出唯一可做的操作——设置计费、核实价格或查看来源。估算区间单列原因，没有操作。
  - 缓存：整体命中率、约省下，以及前几个模型的命中率和省下的金额。
- 并排的两张卡片拉伸到同一高度。

## 数据语义

计算放在 `src/m1/cost-insights.js`，有单元测试。未知保持 null。

- **按月**：
  - 一个月的起点早于记录开始时，不比较。
  - 只有上个月完整在记录内，才显示"较上月"。
  - 当月和上月的同一天数比较，写成"同期"。
- **推算**：只对当月，且当月已过至少 7 天才显示。算法：
  1. 每个有用量的日子的估算 = 至今估算 ÷ 有用量的天数；
  2. 剩余天数里预计有用量的天数 = 剩余天数 × 有用量的天数 ÷ 已过天数；
  3. 整月推算 = 至今估算 + 第 1 步 × 第 2 步。

  上下限分别这样算。这等价于按已过日历天的平均外推；不会假设剩余每天都有用量。
- **构成的两种口径**：
  - 金额来自所有已计价记录的分项，加起来等于下限。
  - Token 和每百万均价只取完整计价、且四项都报告了的每日行，保证 Token 和金额说的是同一批用量。
  - 没有这类行时，左边方格留空，并写明"没有完整计价的用量"。
- **订阅倍数**：
  - 倍数 = 该月估算 ÷ 月费，下限和上限各算一次。
  - 只含已计入的部分，所以实际倍数只会更高。
  - 估算未计入时显示"未计入"；没填月费时显示"—"。
- **缓存**：
  - 整体命中率只汇总缓存读取和未缓存输入都报告完整的模型。
  - 来源没报告的写"未报告"；没有价格的，省下的金额写"无法估算"。

## 订阅月费的存储

- 保存在采集偏好 `preferences.json` 的 `subscriptions` 里，每个 Agent 一个美元金额，存两位小数。
- 只接受目录里的 Agent 和 0 到 100000 之间的数，其他值拒绝（`SUBSCRIPTION_INVALID`）。
- 清空输入框即删除这一项。
- 读写通过 `usage:subscription`；`usage:get` 返回已保存的月费。
- 不读取任何账号或账单，也不随统计导出。`docs/PRIVACY.md` 已补充说明。

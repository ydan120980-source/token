# 趋势图扫入与价格面板 · 2026-11-01

**状态**：所有者 2026-11-01 指出三个问题，Claude 修正。只用合成数据在源码模式下验证，打包版和真实数据都没有验证。

## 1. 所有者指出的问题

1. 费用页和用量页的趋势图，每次点击后的动效太快，而且不是从最左侧开始；
2. 切换 Agent 时有时完全没有动效；
3. 设置页的模型价格面板用不了：候选很多时面板超出窗口，看不到顶部的计费方式切换和底部的保存按钮。

## 2. 原因

- **趋势图**：图线外面套着一个裁剪框，换数据时裁剪框先从当前宽度缩回 0，再在图表进入视野时放开。进入视野的判断几乎马上触发，收缩被中途改成展开，所以展开要么从中间开始，要么停在满宽，看起来没有动效。同时图线本身在 0.3 秒内变形，显得很快。
- **费用趋势**：“每日 / 累计”“面积 / 折线”两个切换不算换数据，只做 0.3 秒的变形，不重新扫入。
- **价格面板**：kit `Sheet` 只有传了 `scrollable` 才限制在窗口内，价格面板没有传。

## 3. 修法

- **扫入**（kit `LineChart`）：换数据（`dataKey` 变化）时，裁剪框立即归零，新图形直接到位，再从最左侧扫到满宽；扫入用新的 `data.sweep` 弹簧（0.9 秒，无回弹）。扫入按比例进行，中途窗口宽度变化不会打断。从别的页面回来、图表已经稳定时不重放。
- **原地变形**（显示或隐藏某条线、实时新数据）：用 `data.reshape`（0.5 秒，无回弹），不再用 0.3 秒的数值档。
- **费用趋势的数据键**加入“每日 / 累计”和“面积 / 折线”，这两个切换也会重新扫入。用量趋势的数据键原本已经包含所有切换。
- **面板**：kit `Sheet` 默认限制在窗口内，正文滚动；只有确定很短的面板才传 `scrollable={false}`。

## 4. 验证

- 费用趋势在切换“累计”“折线”和切换 Agent 后逐帧取样：裁剪宽度都从 0 开始，约 0.9 秒到满宽（741px）。
- 价格面板在 1440×620 的窗口中：面板上下边距各 16px，正文可滚动，计费方式切换和价格输入都可见。
- 测试结果见第 5 节。

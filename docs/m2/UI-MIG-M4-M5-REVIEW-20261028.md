# 会话页、来源管理页的 Codex 迁移版复核 · 2026-10-28

**结论：两页的迁移版（M4 来源管理、M5 会话，分支 `ui/mig-m4-m8` 的 `247ffc1`）仍不合入。** 维持 2026-10-26 的审核结论；按现在的标准重新比较后，差距比当时更大。main 上这两页仍是旧渲染。

## 1. 怎么比的

两边用同一份合成数据，用像素门槛工具在 1440×900 下截取浅色和深色。会话页另外截了“全部”范围，因为合成数据的“今天”没有会话。

- 旧版：本分支，已带新外框、小组件栏、C 配色和 Apple 式卡片。
- 迁移版：`ui/mig-m4-m8`。

图在本机 scratchpad，没有提交。

## 2. 会话页（M5）

| 项 | 旧版（main） | 迁移版 |
|---|---|---|
| 外框 | 圆角面板 + 小组件栏 | 迁移版早于新外框，没有面板和侧栏 |
| 说明文字 | 已删副标题 | 仍有“按项目查看每个会话的用量与成本。只读取…”副标题 |
| 项目行 | 一张卡片里分组：项目行在上，会话行缩进在下，一行读完 | 每个项目一块灰底，里面另起一张带表头的表，“时间”“时长”都装进有边框的小块，层级多出一层 |
| 时间和时长 | 纯文本 | 带边框的胶囊和时钟图标，视觉噪音大 |
| 筛选 | Agent 图标条、范围、排序都在一行，和费用页一致 | 图标条没有容器，搜索框没有底色，三组控件高度不一 |
| 代码 | — | 有 46 行超过 400 字符，审核时无法逐项核对 |

## 3. 来源管理页（M4）

| 项 | 旧版（main） | 迁移版 |
|---|---|---|
| 需要处理 | 一张卡片，每条有分类标签、标题、数值行和两个操作 | 没有容器的长行，说明文字和数值挤在同一行 |
| 来源列表 | 每个 Agent 一行：图标、状态、事实一行、“读取位置”“解析能力”两个折叠按钮、管理和开关 | 每个 Agent 拆成两行：第二行只放“读取位置 · 解析能力”和一个箭头，列表长度翻倍 |
| 说明文字 | 已按“不要小字”删除 | 顶部有说明横幅，配置区有三段说明，“已发现”区还有说明 |
| 控件 | kit 的分段、开关 | 开关、按钮外形与 kit 不一致 |

## 4. 动效

迁移版的筛选和排序切换没有沿用旧版的指示条滑动，列表展开收起也没有高度过渡。旧版的这两处动效已经和费用页的数据档一致。

## 5. 处理

- 不合入，`ui/mig-m4-m8` 保留作参考。迁移版的数据层（Host 和计算）审核时已确认可用。
- 这两页以后重新迁移时，以现在的旧版为外观基准：卡片和配色用新 token，不加说明文字，筛选控件和费用页一致。先做 M7，再由所有者安排这两页。

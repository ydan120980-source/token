# Token 活动合并、首屏聚焦与趋势卡五项 — 2026-10-08

授权见 `docs/SCOPE-LEDGER.md` 2026-10-08（after `5ccc09a`）条。主线 `m2/agents-r4`，基于 `5ccc09a`。本记录为主线程源码验收，尚未打包新候选。

## Token 活动（合并"活跃时段"，新方向：时间导航）

- 一张卡片两栏：左边每日日历，右边每小时视图；日历跨满一年或窗口较窄时，右栏换到下方。
- **只画有记录的部分**：第一条记录所在周之前的整段折成一列虚线"未观测"，悬停说明日期段。之后没有记录的日子仍是虚线格"未观测到记录"，语义不变。
- **联动**：
  - 未选日期时，右栏是星期 × 小时汇总；点一个时段，左边日历只亮出在这个时段有用量的日子，其余变淡，同时展开该时段的 Agent 明细。
  - 点日历的一天，右栏换成这一天的 24 小时柱状图（今天尚未到达的小时画成虚线框，不算 0），悬停显示该小时的 token 和最主要的 Agent；下方的当日明细照旧打开。"‹ 回到星期 × 小时"或关闭当日明细返回。
- **标题行统计**（随 Agent/来源/模型筛选和日历范围变化）：活跃天数、当前连续（今天尚无用量不打断）、最长连续（悬停显示起止日期）、高峰三小时（跨午夜计算，悬停显示占比）。
- 两张热力图统一使用日历的配色（橙/蓝/绿/单色）；时段面板的范围改为跟随日历范围（最近一年 / 本年），不再跟随页面顶部范围，同一张卡里只有一个范围。
- 原"使用习惯"分区取消；"效率"改为"费用与构成"下方的四项横条。

## 首屏聚焦

- 页面在顶部时，大数字放大约 10%、近 7 天柱放大约 24%，资料行和今天卡片变淡并下沉；滚动约三分之一屏高后过渡到原布局，原布局就是静止状态。
- 只改缩放、位移和透明度，不改布局；`#usage` 横向裁切，放大不会产生横向滚动条。
- 界面动效为减少或关闭、切到其他页面、窗口隐藏时，始终是原布局。实现见 `focus.js`，只写四个元素的 `--focus`，不监听滚动做布局计算。

## 趋势卡（画法不变）

1. 刷新间隔移到"设置 → 自动刷新"；顶部刷新按钮的悬停提示显示当前频率。
2. 趋势卡的时间范围只作用于这张图：范围弹层里的"今天 / 7 天 / 30 天"不再改动页面顶部范围；自定义范围时出现"‹ 跟随页面范围"。
3. 底部三项改为页面其他位置没有的信息：较上一区间（等长、且上一区间完全在记录范围内才对比；累计范围为近 30 天较前 30 天；单日为较前一天，今天按同时段对比）、峰值日、主力模型及占比。
4. "估算费用（右轴）"叠加默认隐藏，点图例可显示；隐藏时右轴不画。
5. 图例的隐藏/显示在刷新、切换后保持（本机记住），例如隐藏缓存读取后可看清其余类别。

## 确认的问题

原成本表的静态金额区间也使用 cost-value 类，通用悬停处理错误地把它当作带 data-cost-lower/upper 的用量页动画控件。合成运行已复现悬停前 `$6.98 – $7.81`、悬停后 `$6.98$NaN`。处理器现在只接收带两项有限数值属性的动画控件；费用表已显示的上下界不参加该动画。

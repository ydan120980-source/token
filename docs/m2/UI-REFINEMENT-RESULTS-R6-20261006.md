# Agent Usage 界面优化 — 第六版候选验收

日期 2026-10-06，独立候选 `dist/agents-20261006-r6`，主线 `m2/agents-r4`。功能代码对应提交 `8cd560a`（小时级快照）与 `4076725`（界面与测试），授权记录见 `docs/SCOPE-LEDGER.md` 2026-10-06 "after r5" 条目。本记录为主线程验收，不代表独立审查通过。

## 变更

1. **今日按小时**。统计快照新增 `hourly` 行：最近 7 个本地日，按 Agent / 入口 / 来源 / 模型 / 小时聚合，字段与日行一致；预览白名单只接受 0–23 的整数小时。趋势范围为单日时按小时绘制，横轴截至当前小时；无记录的小时为零，已记录但字段未报告的小时仍为未知。事实栏改为活跃小时均值 / 峰值时段 / 活跃小时。超过 7 天的单日只有日汇总，图上注明。
2. **日期范围**。原生日期控件换成月历弹层：第一次点击即单日范围，第二次点击扩展为区间；未来日期不可选，有记录的日期带圆点，支持方向键与翻页键。弹层从触发按钮展开。
3. **活动热力图**。范围与配色下拉改为分段控件与色点（原生 select 仍是状态接口，配色按本机偏好记住）。月份标签跨到下一个月所在列，不再重叠换行。深色主题下色阶反转，用量越高越亮。
4. **当日明细**。未报告的分类显示为分类格中的"未报告"状态，取代单独的"未报告：缓存写入"文字。模型行改用与分类格相同的不重叠口径（输出不含推理，推理单列）。
5. **成本定价重构**。删除全目录价格表、模型映射表、筛选状态与"价格依据与计费说明"折叠块。新面板依次显示：已定价用量占比；"需要处理"列表（只列价格能解决的缺口：目录无此模型、仅有待核实参考价、缺少必要费率）；已用模型的计费依据、四项单价与用量。编辑面板提供"按目录模型计费"（映射）与"手动价格"两种方式。Agent 计费规则（模式、倍率、默认模型）保留为折叠区。目录来源与更新时间收为一句页脚，版本与摘要只在悬停说明中显示。已无调用的旧辅助函数一并删除。
6. **全局样式**（`polish.css`，最后加载）：细滚动条、统一焦点环、分隔线、半透明浮层、开关、来源胶囊与 Token 构成卡片。趋势卡仍保留 Agent / 来源 / 模型 / 刷新 / 范围控件（2026-10-04 授权）。

## 测试调整

- 应用启动时 `quota-ui.js` 会切换到额度页；`showView` 现在等待页面加载完成再切换视图（conflict、recovery 测试共用）。
- functional：两个缩放轮次共用同一统计目录，第二轮开始时映射已存在，缺口断言改为依据现有映射；已选中项带"✓"时不重复选取。下拉面板断言由"纯白"改为"不透明度不低于 0.8 且带模糊"。
- polish：1.5 倍缩放下，脚本直接设置 `scrollTop` 会停在小数像素，第一次滚轮只做像素对齐。改为先用一次滚轮到达底部，再验证滚动交接。
- 单元测试：新增小时行测试；计价视图测试按新面板重写。

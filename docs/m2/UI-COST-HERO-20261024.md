# 费用页首屏：A 与 C 两页切换；圆环切换不再被裁切 · 2026-10-24

## 所有者决定

看过 `UI-COST-V3-20261024.md` 附带的三份首屏设计稿后，所有者选定：A（数字与构成条）和 C（本月节奏）都要，做成可以左右点击、滑动切换的两页。B 不采用，费用走势卡片保持原样。

所有者同时指出：圆环与半环互相切换时，下方有内容被遮挡。

## 实现

**首屏组件（`cost-hero.js`）**
- 由组件自己管理节点（`data-island`），每次采集刷新时就地更新，不会重放入场动画。

**第一页：所选范围（A）**
- 范围按钮从左侧隐藏的入口移到卡片右上角：累计、30 天、7 天、今日、日历。
  - 前四个按钮与侧栏中的同名按钮共用同一个范围状态。
  - “日历”按钮打开原有的范围侧栏。
- 估算数字逐位滚动，后面跟着上限，下面一行是日期和较前期的变化。
- 数字下方是一条按 Agent 的构成条，只按已计价的金额分段：
  - 指向（或用键盘聚焦）某一段时，大数字滚动到该 Agent 的金额，并显示它占已计价的比例；
  - 没有价格的 Agent 显示为一段斜线纹，写明“未计入”，不按比例画成金额。
- 右侧三项各带一个小图：
  - **日均**：近 14 天的曲线，没有记录的日子留空；
  - **每百万 Token**：与前期对比的两根柱子；
  - **缓存约省下**：命中率圆环。

**第二页：本月（C）**
- 本页不受所选范围影响；Agent 筛选仍然生效。
- 显示本月至今的估算，并注明“第 N 天，共 M 天”和较上月同期的变化。
- 半环仪表：
  - 实色是已用的下限，浅色是估算区间；
  - 虚线是推算整月，中间写出推算金额；
  - 有用量的日子不足 7 天时，写“暂不推算”。
- 本月每天一根柱子：
  - 有用量但没有价格的日子画空心框；
  - 没有记录的日子画低矮的灰色底条，读出时显示“没有记录，不按 0 计”；
  - 未来的日子只画浅框，今天加外圈；
  - 指向某一天时，大数字滚动到当天的金额。

**切换**
- 方式：左右箭头、带文字的两个圆点（方向键可以切换）、拖动或滑动（越过两端时有阻力，按距离或速度决定停在哪一页）、触控板横向滑动。
- 过程：卡片区高度随页面变化平滑过渡；首次进入一页时，图形依次长出，数字从 0 滚动上来。
- 不在当前页的那一页设为 `inert`，不进入 Tab 顺序。
- 当前页记在本机的界面偏好里。
- 减少动态时只保留淡入，关闭动效时没有过渡。

**圆环切换时的遮挡**
- 逐帧截图证实：外框高度和弧段角度各自做动画、步调不一致，切换的前几帧里，圆环下半部被外框裁掉。
- 修改：
  - 外框高度改为每一帧按弧段和底轨实际画到的最低点计算；
  - 底轨也在半环与整环之间同步过渡；
  - 中心读数以圆心为基准平滑上移，不再先跳到外框底部、压在还没收起的弧段上。

## 验收

- `npm run verify`（lint 与 node --test）、`npm run audit:runtime`，以及受影响的界面套件，结果见合并提交说明。
- `cost-composition` 新增首屏检查：
  - 箭头、圆点、方向键和拖动都能切换页面；
  - 隐藏的那一页不可聚焦；
  - 没有记录的日子不显示为 $0；
  - 指向某天时读数随之更新；
  - 首屏与侧栏共用同一个范围。
- 全部使用合成数据和独立目录；没有打包，也没有做真实账号验收。

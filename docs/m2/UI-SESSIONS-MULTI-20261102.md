# 多会话：并排阅读、对比和整理 · 2026-11-02

> 2026-11-05：所有者取消了归档，这里关于归档的内容只是历史记录。见 `UI-AGENT-ADMIN-TABLE-20261105.md`。

**所有者决定（2026-11-02）**：要一个类似 Claude Desktop 的多会话查看、整理和对比功能，由 Claude 设计；不需要新排版更好。

**设计结论**：不加新页面。选择在现有列表上做，并排阅读复用阅读页，对比是阅读页右栏的一个标签。

下面只用合成数据、源码模式验证过。

## 怎么用

列表右上角点“选择”，每行出现勾选框，底部浮出操作条：

| 操作 | 限制 | 结果 |
|---|---|---|
| 并排阅读 | 2–3 个能阅读的会话 | 阅读页分成几栏 |
| 对比 | 2–3 个会话 | 打开第一个会话的右栏“对比”标签 |
| 移到分组 | 不限 | 选已有分组、新建或移出 |
| 置顶、归档 | 不限 | 全部已置顶或已归档时，按钮变成取消 |

单个会话也能在详情里改分组、置顶和归档。

### 并排阅读

- **进入**：操作条；或者正在读一个会话时，点标题栏的“打开其他会话”（快捷键 O），搜索后选一个，可以并排打开，也可以替换当前。
- **放不下时**：这个按钮仍然可用，只是只能替换这一栏。
- **高度**：标题区固定两行，每栏的正文上下边缘都对齐；查找栏盖在正文上方，不会把这一栏推低。测试断言了这两点。
- **每栏独立**：各自有滚动位置、查找、筛选、跟随和右栏。键盘操作只作用于正在使用的那栏。
- **关闭一栏**：其他栏的位置不变；Esc 关闭当前栏。
- **栏数**：每栏至少 440px，最多 3 栏。默认窗口放得下 3 栏。

### 对比（所有者同日修改：不做独立页面，改成右栏的小功能）

- **位置**：右栏的“对比”标签。当前会话加最多两个会话；并排时默认对比其他栏，也可以搜索添加。
- **入口**：右栏标签，或列表操作条的“对比”（2–3 个，至少一个能阅读），后者打开第一个会话并直接停在这个标签。
- **立刻显示**：估算、Token、用量构成、缓存命中、时长，都来自已保存的数据。
- **打开标签时读取**：轮次、工具、命令、失败、文件、压缩次数。逐个读取，离开标签就释放。
- **共同改过的文件**：两个以上会话都改过的文件，显示每个会话的增减行数，最多 12 个。
- **颜色**：条形只表示多少，不表示好坏；未知不显示为 0。

### 并排时的左右栏（所有者同日修改）

每栏不再各有目录和右栏，而是合成一个面板，同一时间只开一个：

- **弹出（默认）**：盖在所属那一栏上，其他栏不变窄。点其他地方或按 Esc 收起。
- **固定**：点面板上的图钉，面板成为最右侧一栏，不遮挡对话，内容跟随正在使用的那一栏。
- **保证可读性**：只有每栏仍能保持 440px 时才能固定。默认窗口两栏可以，三栏不可以，这时图钉不可用，继续弹出。
- **内容**：目录、概况、命令、文件、失败、对比六个标签。

### 宽度自己调（所有者同日要求）

| 栏 | 最小 | 默认 | 最大 |
|---|---|---|---|
| 外层菜单 | 148 | 176 | 280 |
| 阅读页目录 | 160 | 208 | 320 |
| 阅读页右栏 | 308 | 332 | 440 |
| 并排时固定的面板 | 340 | 352 | 440 |

拖动边缘调整，方向键也可以，Home 和 End 到两端，双击恢复默认。宽度只存在这个窗口的本地存储里。所有者说的“左侧菜单栏”可能指外层菜单或阅读页目录，所以两个都做了。

### 整理

- **分组**：人自己起名，最长 40 字。会话页多了“按分组”视图，没分组的排在最后。分组可以重命名和解散，解散不影响会话。
- **归档**：从列表隐藏，“显示已归档 N”可以再看到。**只影响会话页列表**，用量、费用等统计不变，也不动 Agent 的文件。

## 边界变化（`AGENTS.md`、`docs/PRIVACY.md` 已同步）

- **`session-labels.json` 新增 `group` 和 `archived`**：都是人自己的整理操作，不包含任何对话内容。不进统计、导出或查询接口。
- **新增 `usage:transcriptFacts`**：只在打开对比标签时读取记录，返回数字和改过的文件路径，不返回对话文字。结果不保存，离开标签后释放。测试断言了结果里没有对话文字。
- **同时打开多个对话**：读取方式和单个阅读相同，只是可以同时打开几个；仍然不缓存。

## 做了取舍的地方

- **不支持拖动分栏**：Claude Desktop 可以从侧栏拖动。这里的列表和阅读页不在同一屏，拖动没有落点，用按钮更直接。
- **不同步滚动**：两个会话没有对应的轮次，同步滚动没有意义。
- **对比没有 AI 总结**：所有者之前没有选这项，数据也不外发。
- **没有每日趋势叠加图**：同一 Agent 的会话颜色相同，叠在一起分不清；先用表格。

## 已知风险

**内存没有实测。** Codex 刚量过：单个 300 轮长会话加跟随，全进程约 571 MiB，已超过 500 MiB 目标（`RESULTS-HANDOFF-PERFORMANCE-20261102.md`）。并排三个长会话会更高，这是这个功能最大的风险，需要复测（交接已加）。

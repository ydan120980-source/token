## 背景

项目所有者参考了 cc-switch 的会话浏览器（按项目分组、标题、首末消息、完整对话），希望每个 Agent 能显示会话。会话功能按需要读取的内容分成四层：

| 层 | 内容 | 需要读取 | 决定 |
|---|---|---|---|
| 0 | 每个 Agent 的会话数 | 已有的哈希 `sessionKey` | 已在阶段 1 中批准 |
| 1 | 按项目分组的会话列表：Agent、时间、token、成本，外加"复制恢复命令" | 工作目录、原始会话 ID | **本文批准** |
| 2 | 标题、末条消息预览、全文搜索 | 会话正文 | 不批准；第 1 层用过之后，如果确实分不清是哪个会话，再单独决定是否只加标题。**2026-11-01 所有者批准只加标题，且只取 Agent 自己保存的标题字段**，见 [SESSIONS-NEXT-20261101.md](SESSIONS-NEXT-20261101.md)；预览和全文搜索仍不批准 |
| 3 | 完整对话、工具调用详情 | 全部正文和工具输出 | 不做。**2026-11-01 所有者放开**：打开时现读、只显示不保存，见 [SESSIONS-READER-20261101.md](SESSIONS-READER-20261101.md) |

## 决定

### 界面

- **今日卡片：** 每个 Agent 显示今天的会话数；每个模型行显示输出 token、缓存命中率、成本。口径与现有统计相同。
- **会话列表：** 按项目（工作目录）分组，组标题显示项目名，展开后看到完整路径。每个会话一行，显示 Agent、开始和最后活动时间、token、成本（未定价显示"未定价"）。组和行都可以按成本或时间排序；可按 Agent 和时间范围筛选，与现有筛选联动。
- **工作目录未知的会话**，统一归入"未知项目"组，不按路径去猜。

### 新增保存的字段，以及哪里不能出现

| 字段 | 保存位置 | 允许出现 | 禁止出现 |
|---|---|---|---|
| 原始会话 ID | 本机统计库，按会话保存一份，不挂在每条记录上 | 本机界面；恢复命令 | 统计导出；阶段 2 查询接口；日志；错误文本 |
| 工作目录（绝对路径） | 同上 | 本机界面 | 统计导出；阶段 2 查询接口（只给项目名，即目录的最后一级）；日志；错误文本 |

- 会话元数据和用量快照遵循同一条"完整替换"规则：新快照里没有的字段要删掉，不能沿用旧值（见 `AGENTS.md` 已知陷阱）。
- 会话正文、标题、消息内容一律不读，这一条不变。

### 恢复命令的安全要求

工作目录和会话 ID 都来自本机文件，用户会把恢复命令粘贴到终端里执行，因此：

1. 会话 ID 必须通过严格的格式校验（只允许字母、数字和 `-`、`_`），不合格就不提供恢复命令。
2. 生成的是 PowerShell 命令，例如 `Set-Location -LiteralPath '<目录>'; claude --resume <ID>`。目录用单引号字面量，内部的单引号写成两个单引号转义，不允许 `$()` 这类展开生效。要有测试：路径里放单引号、`$()`、反引号、分号时，生成的命令仍然安全。
3. 只复制到剪贴板，不由应用代为执行。

### 各来源的字段依据

工作目录和恢复命令逐个来源核对。依据分三级：**官方**（Agent 自己的源码或文档）、**旁证**（cc-switch 4.0.9 的公开源码，MIT 许可）、**未确认**。实现时每个来源都要用合成样本测试；真实数据只能通过 `validate:local` 核对。

| Agent | 原始会话 ID | 工作目录 | 恢复命令 | 依据 |
|---|---|---|---|---|

| OpenCode | `session.id` | `session.directory` | `opencode -s <ID>` | 旁证 |
| Gemini CLI | `sessionId` | 项目临时目录下 `.project_root` 文件的内容 | `gemini --resume <ID>` | 旁证；需新增允许读取 `.project_root` 这一个文件 |
| DeepSeek Harness | 会话 ID | 会话元数据中的可选字段 `cwd` | 未确认 | 官方：`packages/core/session/src/types.ts` |
| WorkBuddy | 项目 JSONL 行内 `sessionId` | 行内 `cwd`；数据库总量补充用 `sessions.cwd` | 未确认 | 本机结构核查（2026-10-15） |

| MiMo Code | `session_message.session_id` | 未确认（`session` 表的列未核对） | 未确认 | — |
| WorkBuddy | `session_id` | 未确认 | 未确认 | — |
| Cursor | `agent_id`/`run_id`（会话含义未确认） | 未确认；项目目录名是有损编码，不能还原路径 | 未确认 | — |

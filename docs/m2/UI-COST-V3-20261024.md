# 费用页 v3：读数代替浮层、环形与按月重做 · 2026-10-24

## 所有者反馈与范围

所有者在 Codex 接手后的费用页（`e50b349`）上提出：

- 悬停卡片遮挡界面；
- 详情弹窗不好看，需要重构；
- 折线图的设计与交互有问题；
- “花在哪”没有照 EasyUI donut 的过渡，右侧文字显示不全；
- “按月”图形太小，要照 EasyUI bar chart 重做；
- 两个模块高度不一致，单独展开时没有过渡，还留下大片空白；
- 订阅对照没法用；
- 截图中的细节问题；
- 首屏太模板化（本次只出设计稿，见“未做”）。

所有者另外提供了两个参考组件的录屏。录屏在本机用 Electron 解码，没有上传。关键帧显示：

- 半环与圆环之间切换时，弧段按角度移到新位置，图例随高度变化下移；
- 分组与堆叠之间切换时，柱子横向并拢、变宽，y 轴随之重算。

本次只改原生渲染层，没有引入 React、依赖或在线组件。EasyUI 组件只读取本机缓存的源码（`DonutChart.tsx`、`BarChart.tsx`），用来对齐几何参数和时长。

## 实现

**走势**
- 去掉原生下拉框和“展开/收起”，图表只有一个高度。
- 工具栏改为三组分段按钮：日/周/月、每期/累计、面积/折线。
- 图上方是读数和图例：静止时显示范围合计和各 Agent 金额；指向时换成那一天（或那一周、那个月）的数字。
  - 没有用量的 Agent 显示“—”。
  - 有用量但没有价格的 Agent 显示“未计入”。
- 光标处只留一个小胶囊，标出日期和合计，放在图的上边距里，不遮挡曲线。
- 没有记录的日期仍然是空缺，不补零。空缺两端用虚线连接，面积以同样的渐变延续，避免图形断成梳齿。
- y 轴改用 EasyUI 的取整步长乘四，并画出最上面一条线，数据上方不再空出四分之一。

**花在哪**（`cost-donut.js`，组件自己管理节点，`data-island`）
- 线宽 16px 的圆头弧段，段与段之间留 3.5px，并计入圆头。
- 入场：各段依次画入，间隔 90ms，每段 1 秒；中心的合计从 0 计数上来。
- 指向某一段：线宽回弹到 20px，中心文字滑入，显示名称、金额、占比和 Token。
- 点图例可以隐藏或显示一段，其余各段按角度重新排开。
- 半环与圆环之间按角度过渡，图形高度随之变化。
- 图例每行一项：圆点、名称、金额、占比。
  - 窄面板里环缩到 168px，占比挪到中心显示，名称不再被截断。
  - 没有价格的 Agent 仍然列出，显示“未计入”。
- 不压暗其他扇区，沿用所有者此前的要求。

**按月**（`cost-bars.js`）
- 柱子只有顶部是圆角，堆叠段之间留 1.5px。
- 分组与堆叠切换时，柱子从当前形状过渡到新形状（500ms）；入场时依次长出（800ms，按月错开 40ms、按 Agent 错开 25ms）。
- 指向某月时有一条跟随的底带，弹簧参数沿用 `uiMotion.follow`。
- 读数在柱图上方：月份、金额区间、本月推算整月，以及没有价格的 Agent 名称。图例同时显示该月各 Agent 的金额。
- 点图例可以隐藏一个系列；点某个月仍然筛选整页。
- 估算区间画成斜线纹；本月推算整月画成虚线框。
- 删除顶部的月合计行，y 轴改为 $100 / $1K 的短写。

**两栏**
- 两个面板等高（`--cost-duo-body` 408px）。
- 展开改为 flex-grow 过渡，被收起的一侧变成带竖排标题的窄条，不留空白；内容按新宽度重画。
- 标题行放入“费用构成 / 订阅对照”切换和展开图标（Tabler arrows-diagonal）。

**订阅对照**
- 每个 Agent 一行：
  - 名称和额度入口；
  - 倍数；
  - 月费输入框；
  - 一条共用比例的进度条：实色是 API 等价下限，斜线纹是上限，竖线是月费。
- 上方注明对照的是哪个月；长名称换行。

**详情抽屉**
- 宽度 440px，仍从左侧滑入。
- 顶部是图标、名称和元信息，下面依次是：
  - 金额，以及“已计入”和“较前期”两个标签；
  - 六项指标卡片，排成 3×2；
  - 用量构成：一条构成条，每个字段一行；
  - 每日 Token：读数写在图上方，悬停时隐藏终点数值标签，避免重叠；
  - 模型或使用方列表、计价信息；
  - 操作按钮固定在抽屉底部。

**核对**
- 仍有 Token 未计入时，覆盖率最多显示“>99.9%”，不再四舍五入成 100.0%。
- 估算区间这一步的标记改为“≈”。

## 验收

- `npm run verify`：fail 0，lint 无报错。
- `npm run audit:runtime`：通过。
- 受影响的界面套件全部在源码模式下、以最终代码通过：
  - 费用：cost、cost-composition、cost-layout、cost-compact、cost-rebuild；
  - 共享样式与交互：style-alignment、interaction-reliability、unpriced-guidance、workbench、budget-overview、visual、detail、functional、polish；
  - 采集与统计：agent-conflict、agent-recovery、statistics-worker；
  - 动效与用量（`morph.js` 有改动）：motion、usage。
- 首轮失败及处理：
  - 五个费用套件首轮失败，原因是仍断言旧结构（环形图、浮层提示、“展开”按钮、详情网格、7 项指标）。
  - 复跑时又发现两处产品问题，已修正：
    - 图例内容多于可视高度时，居中对齐会让第一行越过列表顶部，无法点到；改为 `safe center`。
    - 详情图按整个抽屉宽度绘制，刻度字号被缩小到 10.9px 以下；改为按内容宽度绘制。
  - 在 800px 窄窗口下，展开按钮按设计隐藏（两栏改为上下排列）；对应步骤改为先恢复宽窗口再检查。
- 为配合新结构更新的断言，测试意图保持不变：
  - 每个 Agent 一行；
  - 中心读数指向时改变、离开时恢复；
  - 不压暗其他项；
  - 悬停时节点不变，只播放一次入场；
  - 未知不显示为零；
  - 键盘可以操作；
  - 窄窗口和深浅色下不溢出。
- 全部使用合成数据和独立目录。没有读取真实来源或凭据，没有打包，也没有做真实账号验收。

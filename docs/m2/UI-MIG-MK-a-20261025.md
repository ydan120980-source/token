## 实现

| 组件 | 实现及固定行为 |
|---|---|
| TextField | 原fluid InputGroup/InputField；只增加password/pattern/autoComplete/spellCheck/onCommit。值改变后失焦或普通Enter提交；Enter后失焦不重复；Escape恢复焦点时草稿，保留外层Sheet的Escape关闭和回焦；IME确认/取消不触发提交或恢复。password不提供显示密码按钮，已有凭据仍由页面以空草稿传入。 |
| TextArea | Base UI Field加原输入语义颜色/字号/圆角；3/6行、mono/maxLength/disabled/error/spellCheck。Enter换行，未触发表单提交；错误文本用aria-describedby。没有改vendor。 |
| Combobox | 继续fluid dropdown/MenuItem；allowCustom时把未列出的原始输入作为首项，customLabel可替换默认文案；保留原始空格，不把搜索trim结果当提交值。关闭/焦点/IME沿原组件。 |
| Disclosure | 原fluid Accordion；actions与trigger为兄弟，不嵌套按钮；单独动作不会开关Disclosure。 |
| AgentFilter | radiogroup；icon/chip、全部文字、AgentMark、原生title；无记录项弱化但可选。方向/Home/End和IME保护；ghost预留字重宽度，moderate指示器、选择不改布局，resize清理。 |
| CopyButton | IconButton、Tabler copy/check；busy禁用且ref拒绝同回合重入；成功1600ms后复原，false/异常不显示check；卸载取消timer/失效异步结果，错误文案由调用页负责。 |
| StackBar | SVG+Motion；规定的高度、44px inline、16/30分段、三类marker及solid/hatched/light；active受控、焦点/方向/Escape；unknown只有底轨，明确0不标unknown。首次25%可见用data.enter，更新data.update从当前值转向，off/reduced几何直接终态。内部SVG几何不传给页面像素参数。 |
| StatusDot | 8px、bg-success、active和title/可访问名称；静止，无脉冲。 |

颜色使用静态查表，只映射裁决的ChartTone。新增category浅深值逐字取旧categories/categoryColor；heat映射只引用已有heat0–4。preview分类颜色改读同一token，数值/标签/数据聚合未改。M3 Meter保留。

TextField的恢复监听在Radix的document-capture关闭之前运行；不prevent/stop普通Escape。否则Sheet可能先卸载输入框，使恢复丢失。注册表为WeakMap，字段卸载时显式删除，不存储或记录凭据。

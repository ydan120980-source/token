## 首次失败与修正

1. 独立费用算例首次在 CSV 字符串断言遇到浮点尾数。规范化导出有效数字后通过；没有改变内部估算或用零掩盖未知。
2. 首次新UI套件在注入写入失败时，测试的 Electron evaluate 环境没有 require，测试在此处中止。改用该运行时支持的 process.getBuiltinModule 后复跑通过；产品故障注入和恢复断言保留。
3. 截图检查后去掉用户界面里的组哈希片段和价格指纹；同名项目用编号区分。补充操作后焦点、未保存预算输入保留，以及操作期间更新的补读；最终套件复跑通过。首次日志与终版日志均保留。

本机证据位于 artifacts/workbench-insights-20261018/，logs/为运行记录，ui-final/为终版工作台截图与结果，其他子目录为受影响套件的合成证据。不把证据或真实数据打入源码归档。

## 已知限制与发布交接

- 项目归属只能覆盖既有合同里有工作目录依据的会话；自定义来源与Cursor不猜测项目。项目CSV保留未知组，字段缺失不填零。同名项目编号只是本次列表的显示辅助，预算身份不依赖编号。
- 预算只覆盖已观测用量的 API 等价估算，不是发票、订阅余额、服务商额度或硬性消费限制；缺失历史、未定价与区间均影响判断。不自动停止任何 Agent。
- 本轮新工作台没有真实用量验收；上一轮17个真实来源样本属于旧轮次解析核对，不冒充本轮项目/预算真实验收。未做真实Windows输入法候选窗、屏幕阅读器或长时运行检查。501组压力是后端投影，不代表501组原生界面容量验收。
- 没有打包或制作新运行候选，不修改r15。发布负责人从合入后main按 CONTRIBUTING.md 执行完整头部检查（含crypto）、dist:win:dir/audit:package、打包版全部UI和中文空格路径解压字节核对及采集套件。新入口IPC和资产需纳入候选验收。
- 既有150%费用设置窗口意外关闭，本轮custom/usage/cost及工作台100%/150%未复现，但未证明旧现象根因修复。
- 不启动MCP/CLI查询服务、配置内容检查、DIY、编排或远程控制；没有复制Orbital代码、资源或引入其运行依赖。GitHub同步保持暂停。

## 1. 颜色

- **单一来源**：所有颜色都来自 `design/desktop-reference/tokens.css`，在 React 层通过 Tailwind 语义类名使用。不得出现十六进制、`rgb()`、`color-mix()` 或 Tailwind 调色板颜色（`bg-red-500` 等），`tests/m1/ui-design-guard.test.js` 会拦截。

| 用途 | 类名 |
|---|---|
| 页面底色 | `bg-background` |
| 卡片、面板 | `bg-surface-3`（`bg-card`） |
| 卡片内的凹陷区、输入底 | `bg-surface-2` / `bg-muted` |
| 弹出层（由 fluid 组件自己决定层级） | `surface-*`（不手写） |
| 主文字 | `text-foreground` |
| 次要文字 | `text-muted-foreground` |
| 分隔线、描边 | `border-border` |
| 选中底色 | `bg-selected`（导航选中、分段控件） |
| 按下、点亮底色 | `bg-active` |
| 强调文字（链接） | `text-accent-text` |
| 危险操作（删除、断开） | `text-destructive` / `bg-destructive-light` |
| 用尽、警示（仅限额度用尽） | `text-warn` / `bg-warn`、`text-warn-text` |
| Agent 身份色（额度视图） | `bg-agent-codex` 等 `*-agent-<id>` |
| Agent 身份色（费用图表） | `*-series-<id>`、`*-series-other` |

- **身份色只区分是哪个 Agent**：不能表示好坏、多少或状态。用量和费用的多少不着色。
- **警示色只用于“窗口已用尽”**：不能用来表示“用得多”。
- **新增颜色**：要么先在 `tokens.css` 里加 `--ff-*` 或身份 token，并在 `ui/src/theme/index.css` 里映射，要么停下来提问。这两个文件只由 Claude 修改。

## 2. 文字

- **字体**：`font-sans`（Inter + 思源黑体），等宽数字用 `font-mono` 或 `tabular-nums`。

**界面文字六级**（`--fs-*` / `--lh-*`）：

| 类名 | 字号 / 行高 | 用途 |
|---|---|---|
| `text-display` | 28 / 34 | 页面大标题（每页一个，即 h1） |
| `text-title` | 16 / 22 | 区块标题（h2） |
| `text-subtitle` | 14 / 20 | 卡片标题、行的主名称 |
| `text-body` | 13 / 20 | 正文、控件文字（默认） |
| `text-caption` | 12 / 16 | 说明、次要信息、表头 |
| `text-micro` | 11 / 14 | 角标、单位、坐标轴刻度 |

**数据数字**（只用于数字本身，单位用 `text-caption` 或 `text-micro` 跟在后面）：

| 类名 | 字号 | 用途 |
|---|---|---|
| `text-figure-xl` | 52 | 首屏的那一个主数字 |
| `text-figure-lg` | 40 | 卡片主数字（额度剩余、余额） |
| `text-figure-md` | 28 | 次级数字、弹窗里的数字 |
| `text-figure-sm` | 20 | 一排并列事实里的数字 |

- 所有数字都加 `tabular-nums`。
- **字重**：只用 `font-normal`、`font-medium`、`font-semibold`。标题用 `font-semibold`，数字用 `font-semibold`。
- 不得使用 `text-xs`、`text-sm` 等 Tailwind 默认字号，也不得用任意值（`text-[15px]`）。

## 3. 尺寸、间距、圆角

**控件**：一律由 kit 组件决定，页面不得改控件的尺寸。

| 档位 | 控件高 | 分段项高 | 图标 | 用途 |
|---|---|---|---|---|
| 默认 | 36（`h-9`） | 28 | 16 | 全部默认 |
| 紧凑 | 28（`h-7`） | 24 | 14 | 只用于表头、工具条、筛选条，且要在页面计划里列出 |

**圆角**：只用以下五个类名，任意值一律不允许。

| 类名 | 半径 | 用途 |
|---|---|---|
| `rounded-lg` | 8 | 控件、行内块 |
| `rounded-xl` | 12 | 弹出层、卡片里的子块 |
| `rounded-2xl` | 16 | 卡片、面板 |
| `rounded-full` | — | 圆点、胶囊、头像 |
| `rounded-none` | 0 | 取消圆角 |

**间距**：用 Tailwind 的 4px 刻度，固定规则如下。

| 位置 | 值 |
|---|---|
| 页面内边距 | 沿用旧页面外框，React 页面不另设 |
| 页头和第一块内容之间 | `gap-6`（24） |
| 区块之间 | `gap-8`（32） |
| 区块标题和内容之间 | `gap-3`（12） |
| 卡片内边距 | `p-6`（24）；紧凑卡片 `p-4`（16） |
| 行内元素间距 | `gap-2`（8）；控件之间 `gap-3`（12） |
| 列表行 | 用 kit 的列表行或表格行，行高由组件决定（36），行与行之间用分隔线，不用卡片 |

**层级**：
- 不允许卡片里再套卡片；卡片里的子块用 `bg-surface-2 rounded-xl`。
- 阴影由 kit 组件按 fluid 的 surface 层级决定，页面不得写 `shadow-*`。

## 4. 组件清单（kit）

**放置规则**：
- 页面只能用 `ui/src/kit/` 导出的组件。kit 组件在 fluid 组件外再包一层，固定本规范的选项。
- 页面（`ui/src/pages/**`）不能直接引用 fluid、Radix、Motion，设计检查会拦截。
- kit 的 API 以执行计划 M1 为准。

| kit 组件 | 基于 | 规定 |
|---|---|---|
| `Button` | fluid Button | 四种样式：`primary`（每个区域最多一个）、`secondary`、`tertiary`、`ghost`。危险操作用 `ghost` 加 `tone="danger"`（文字为 `text-destructive`）。只有图标的按钮必须有 `aria-label`。 |
| `IconButton` | fluid Button `size="icon"` | 工具条和标题栏的图标按钮。 |
| `Segmented` | fluid Tabs（`TabsList`/`TabItem`） | 范围切换（今日 / 7 天 / 30 天 / 累计）、单选的视图切换。选中指示器的动效为 `spring.moderate`。 |
| `SubTabs` | fluid TabsSubtle | 区块内的轻量分类（全部 / 需要处理 …）。 |
| `Select` | fluid Select | 所有下拉单选。不再用原生 `<select>`。 |
| `Menu` | fluid Dropdown | 更多操作菜单。 |
| `Switch` | fluid Switch | 所有开关。文字在右侧。 |
| `Checkbox` / `RadioGroup` | fluid CheckboxGroup / RadioGroup | 多选和单选列表。 |
| `Slider` | fluid Slider | 阈值、数值调节。 |
| `TextField` / `SearchField` | fluid InputGroup | 输入框和搜索框（带清除按钮）。 |
| `Sheet` | fluid Dialog | 所有弹窗：详情、编辑、连接登录、导出。尺寸 `sm` 400、`lg` 540、`xl` 880。进入动效 `spring.slow`，退出动效 `spring.slow.exit`。替代现有 6 个 `<dialog>`。 |
| `Disclosure` | fluid Accordion | 展开和收起（来源详情、会话分组）。 |
| `Badge` | fluid Badge | 状态标签。颜色只能是 `gray`，或警示时用 `amber`；不得用颜色表示好坏。 |
| `Banner` | fluid Banner | 页内通知（错误、需要处理）。 |
| `DataTable` | fluid Table | 表格（费用明细、模型列表）。 |
| `ListRow` | 新建，用 kit 基础类组合 | 一行：左侧图标或身份点，主名称（`text-subtitle`），次要信息（`text-caption`），右侧数值或操作。行与行之间用 `border-border` 分隔。 |
| `Card` / `Panel` | 新建 | `bg-surface-3 rounded-2xl p-6`。标题区用 `SectionHeader`。 |
| `PageHeader` | 新建 | 标题（`text-display`）、一行说明（`text-caption`），右侧放操作。 |
| `SectionHeader` | 新建 | 区块标题（`text-title`），右侧放 `Segmented` 或操作。 |
| `Value` | 新建 | 显示一个可能未知的值，规则见第 6 节。 |
| `Figure` | 新建 | 大数字：figure 字号、`tabular-nums`、逐位滚动（`data.enter` / `data.update`），单位放在后面。 |
| `AgentMark` | 新建 | Agent 图标（`design/desktop-reference/assets/agents/*` 的官方图标）或身份点（`bg-agent-*`）。 |
| `EmptyState` | 新建 | 空状态：一行说明加一个操作，不画插图。 |
| `Toast` | 新建，基于 Motion | 底部提示。进入动效 `spring.moderate`，退出动效 `spring.moderate.exit`。 |
| `CarouselDots` | fluid CarouselDots | 首屏翻页的圆点。 |
| 图表：`RingChart`、`BarChart`、`LineChart`、`Timeline`、`Heatmap` | 新建，用 SVG 加 Motion | 视觉和交互照费用页现状（2026-10-27 更正，`UI-UNIFY-COST-REFERENCE-20261027.md` 第 3 节：弧段、柱形、空缺、刻度、估算和推算的画法），不得另行设计。数据动效用 `data.*`。颜色只用身份色和 `text-muted-foreground` 网格。 |

- **图标**：只用 Tabler（fluid 的 `IconProvider` 已设好 `tablerIcons`）。新图标从 `@tabler/icons-react` 引入，不得自己画。Agent 图标用现有官方图标资源。

## 5. 动效

`ui/src/design/motion.ts`（及其转出的 `spring`）是唯一来源，页面不写任何动效，所有动效都在 kit 组件里。2026-10-29 起按 Apple 动效体系（HIG“Motion”、WWDC 2018《Designing Fluid Interfaces》）重定，见 `UI-MOTION-APPLE-20261029.md`。

| 档位 | 进入 | 退出 | 用途 |
|---|---|---|---|
| `spring.fast` | 弹簧 0.1s，无回弹 | 0.08s | 焦点环、颜色和底色变化、淡入淡出、开关的选中底色、提示 |
| `spring.moderate` | 弹簧 0.2s，无回弹 | 0.14s | 分段指示器、开关滑块、下拉和菜单展开、展开收起、提示条 |
| `spring.slow` | 弹簧 0.32s，回弹 0.12 | 0.2s | 弹窗、首屏翻页、侧栏面板、大面积切换 |
| `spring.momentum` | 弹簧 0.4s，回弹 0.15，带松手速度 | 0.2s | 只用于甩动或拖拽松手之后（轮播、可拖排序） |
| `data.enter` | 弹簧 0.5s，无回弹 | — | 图表或数字首次出现：柱子长出、圆环展开、折线绘出、数字滚动 |
| `data.update` | 弹簧 0.3s，无回弹，不错开 | — | 同一图表的数据变化；从当前画出的几何继续，可以打断 |
| `data.follow` | 弹簧 0.15s，无回弹 | — | 跟随指针的高亮带或标记 |

手势工具（同一文件）：`project(速度)` 按 Apple 的减速公式推算甩动的落点；`rubberband(越界量, 尺寸)` 让越过边界的拖拽越来越重；`velocityTracker()` 取最近约 100ms 的指针样本算松手速度。

2026-10-27 起的费用页数据档数值（0.8s / 0.5s，`cubic-bezier(0.23, 1, 0.32, 1)`，错开 0.04s、上限 0.4s）和 2026-10-25 的三档数值（0.08 / 0.16 / 0.24s，慢档少量回弹）作废。

**规则**：
- **大小定速度**：东西越大，动效越慢。弹出用弹簧，退出用短渐变（`*.exit`），不得把进入动画倒放当退出。
- **数据档只给数据用**：`data.*` 只能用于图表和 `Figure`，控件、面板、弹窗不得用。
- **一起出现时错开**：只在首次出现时，同时出现的兄弟元素用 `staggerDelay(i)`，每个间隔 0.015s，总共不超过 0.12s；数据变化不错开。
- **回弹**：反馈、控件、数据不回弹；面板和弹窗保留 `spring.slow` 的少量回弹；甩动或拖拽松手后用 `spring.momentum`，并把松手速度接给弹簧。
- **一切可打断**：动效都从屏幕上当前的值开始，不让人等动画播完。
- **中心读数切换**：淡入并上移 4px，用 `spring.fast`。
- **文字粗细变化不能挤动版面**：用 fluid 的 ghost-span 做法（fluid 组件已内置）。
- **CSS 过渡**：只允许 `duration-80`、`duration-160`、`duration-240`，只用于颜色、底色这类即时反馈，并且只能写在 kit 组件里。
- **设置中的“动效”选项**已经接上（第 0 阶段）：
  - 减少：没有位移，变化用 `reducedFade` 交叉淡入（图表形状、数字、轮播翻页）；
  - 关闭：所有动效直接到终点。
  - kit 组件里的 CSS 动画同样要遵守 `body[data-motion]`。
- **禁止的效果**：发光、悬停时上浮或放大、视差、无限循环（加载指示除外）。

## 6. 数据显示

`CONTRIBUTING.md`“数据语义铁律”在界面上的落实：

- **未知值**：可能未知的值一律用 `Value` 显示。
  - 未知时显示“未知”，未定价时显示“未定价”，并给元素加 `data-value="unknown"`；不得显示 0、“—”或空白。
  - 冒烟测试会检查（`semanticViolations`）。
- **不跨 Agent 相加**：不同 Agent、不同账号、不同资源池的数量不相加。现有页面里允许的合计（例如 WorkBuddy 同一账号的积分合计）沿用原逻辑，不新增。
- **精确小数**：金额和额度用现有格式化函数输出（`window.displayValues`、`window.pricingLabels`、`window.costTable`、`window.usageMath` 等），不得在 React 层重新实现四舍五入、单位换算或定价。
- **部分数据**：数据是部分的或不完整时，保留现有提示文案和标记（如 `+`、“至多”、范围值）。
- **文案**：迁移只改展示形式，不改文案。任何文案改动都要单独列出，交给 Claude 审核。

## 7. 悬停和读数（所有者 2026-10-28 更正）

2026-10-27 那次“全站按费用页读数、不用悬停卡片”的统一已作废，以 `UI-HOVER-20261028.md` 为准：

- **迁移的页面照搬旧版**：旧页面的悬停卡片和读数原样带过来，包括形状、内容、跟随方式和键盘操作。不按别的页面统一。
- **新功能都有悬停卡片**：概览、小组件侧栏，以及迁移后新加的元素，凡是有数据的标记都要有悬停卡片。
- **一次一张**：悬停卡片和图表提示共用同一层（kit `useSharedChartTooltip` / `useHoverCard`），内容用 kit `TipCard`。
- **读数位置**：图上方或中心的读数照旧。静止时显示范围合计，指向时显示那一点的值。
- **键盘等价**：可以聚焦的元素，聚焦时打开同一张卡片，Esc 关闭。图表用方向键移动指向点。
- **fluid 组件自带的悬停反馈保持组件原样**：包括菜单和列表跟着指针移动的高亮、按钮悬停底色。
- **页面不写悬停**：页面代码不得写 `hover:`。需要悬停行为时，做成 kit 组件，或者放在对应的图表组件里，页面只传卡片内容。
- 悬停时不抬起、不放大、不发光。

## 8. 无障碍

- 所有交互都能用键盘完成。焦点环用 `--focus-ring`（fluid 组件已内置），不得去掉 `outline`。
- 对话框打开时把焦点移进去，关闭后把焦点还给触发它的元素（冒烟测试已覆盖）。
- 只有图标的按钮要有 `aria-label`；图表要有 `aria-label` 总结，或者附一张可读的数据表。
- 深浅两色下，文字对比度都至少 4.5:1（大数字 3:1）。只要用的是本规范的 token 就能满足；不得用透明度把文字调淡。

## 9. 自动检查（`npm run verify` 必过）

`tests/m1/ui-design-guard.test.js` 扫描 `ui/src`，跳过 `vendor/`、`theme/`、`design/`。

**全部代码都禁止**：
- 颜色字面量；
- Tailwind 任意值和任意属性；
- 默认字号、调色板颜色；
- 规定以外的字重、圆角；
- `!important`；
- 动效参数字面量（`transition={{`、`duration: 0.3` 等）；
- 规定以外的 CSS 动效类；
- `dangerouslySetInnerHTML`、`innerHTML`；
- 在 `ui/src/theme/` 以外新建样式文件。

**`pages/`、`islands/`、`data/` 另外禁止**：
- 直接引用 fluid、Motion、Radix 或 Base UI（只能用 `@ui/kit`）；
- `hover:`；
- `style={}`；
- 声明过渡。

**例外**：写在 `ui/design-guard-allow.json` 里，必须注明文件、规则、完全匹配的文字和理由。例外只能由 Claude 添加，执行者需要例外时停下来说明。

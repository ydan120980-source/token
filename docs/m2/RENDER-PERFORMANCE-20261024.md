# 首屏渲染与 WAL 开销修复 · 2026-10-24–25

所有者本轮明确：窗口移动粘手不属于本项目，排除；本轮负责后端和渲染性能，保留 Claude 的布局、颜色、字体、字号、数字滚动、卡片滑动和图表动画形式。按月分组柱宽与排版交回 Claude，不以改设计或关闭动画代替修复。基线为本地 main `3f8e107`，此前 `perf-review-20261024-r1` 的结果不算本轮验收。

## 原因与修复

- 额度首屏的高度随轮播动画变化，外层 ResizeObserver 每帧重画余额阶梯图。原版隔离合成回归一次进入余额发生 73 次图形 morph。现在只在实际宽度、额度事实或分钟刻度变化时更新几何，保留首次线条生长动画；跳过重画仍恢复模板更新后的悬停读数。
- quota/provider 通知分别重建额度卡片与首屏。显示更新合并至一帧，额度读取合并在途通知；用一份脱敏输入签名跳过相同事实，隐藏页只更新必要摘要。拖动取消必须绕过签名缓存以恢复原 DOM 顺序。真实变化仍进入界面，不增加网络、定时器或账号查询。
- 轮播轨道永久保留 transform/will-change，数字永久保留 mask/transform。现在卡片运动时仍用相同滑动与缓动，静止后换回布局定位；滚动数字结束后以同尺寸普通字形显示。动态减少/关闭立即收尾，节点移除清理计时器。字体、字号、卡片样式不变。
  - 补充断言在首轮候选复现静止后再次变化从 0 起滚：45→46 时个位起点约 −4px，而旧值 5 的偏移应约 −68px。现恢复隐藏列旧偏移后才启用目标过渡；运动中的列继续从插值位置续接。数字滚动形式保持不变。
- 费用圆环中心悬停立即替换金额，只有短暂外层动画。现在沿用既有计数缓动，从实际显示的中间数值继续到新目标，快速跨 Agent 不跳回旧起点；未定价仍显示未计入。
- 费用页派生聚合缓存只保留当前 rows 引用与筛选键；圆环、月图和首屏相同输入不重启动画。新快照引用（含同 sequence 重新计价）会失效。
- 补验发现用量页隐藏时，新快照只标记该页待绘制，却未通知当前费用页。现在数据通知独立于用量图绘制，保存价格后费用页立即刷新；显式已计价的零不再被圆环/月图转成未计入。

## 后端只读数据库路径

本程序自己的统计账本是 JSON；来源 SQLite 仅在受限读取后投影到 sql.js 内存。WAL overlay 原实现每次提交复制整个页 Map，增长 WAL 形成平方级短命分配。改为先校验帧和最终提交边界，再线性应用已提交字节；不写来源数据库，不改变文件格式、页/输出上限、盐与校验和规则。

新增测试覆盖多次提交、未提交覆盖与残缺尾部、损坏提交、缩小数据库、非法头、超限和大提交量；原有真实 SQLite 合成 WAL 与独立查询的一致性测试继续执行。4,000 次合成提交、约 2.14 MB WAL，旧实现三样本约 266–272 ms，新实现约 4.4–5.4 ms。此为同机 overlay CPU 测量，不是整体程序速度或 RSS 的等比例保证。未修改真实数据库、账本或连接。

## 回归和边界

新增 `render-performance-ui-test.js`，检查真实 rAF 间隔、进入余额的几何绘制次数、重复通知、变化通知到达、4px 点击抖动仍打开详情、圆环中间金额、同 sequence 零价重算、100/125/150% 静止字形及账本字节不变。沿用现有 Electron/Playwright；Browser 插件与 CodeGraph 此会话不可用，采用针对性源码检查。

保留首轮证据：沙箱临时文件原子重命名 EPERM 是环境限制，改在普通权限隔离 fixture 下执行；原版高频重画的失败是预期复现。修复版首轮分别发现拖动取消顺序、余额悬停读数与隐藏用量页数据通知的缓存边界，修复后复跑。不得将这些写成首轮全通过。

最终完整检查首轮的 Windows Job 参数用例返回 `JOB_CLEANUP_UNCONFIRMED`；该用例与完整 verify 随后分别复跑通过，未改变进程治理实现或测试门限。原生、压力、加密与运行时审计通过；全部输入为隔离合成数据。

首轮候选 `render-performance-20261024-r1` 的 40 个打包界面套件首轮 38 个通过。费用用例原来只等待 CSS/WAAPI，未等待新增的 rAF 数字计数，读取了过渡中间值；补齐计数完成等待后在同一 ASAR 复跑通过。工作台用例从 23:59:50 运行到次日 00:00:04，其当天合成记录在导出日范围时已是前一天；未改产品或用例，午夜后同一 ASAR 复跑通过。记录保留首轮失败及文件时间，不当作首轮全通过。随后补充数字续滚断言并修复旧值起点，最终候选重新构建并独立验收。

源码样本：余额进入重画降为 1 次，7 对相同通知在观测窗口内重画为 0，通知阶段 P95 约 3.4 ms；余额首次切换仍记录约 86 ms 的单帧最大间隔、P95 约 6.7 ms，不能声称所有场景稳定 60fps。最终包结果在独立 RESULTS 中记录。所有者 2026-10-25 要求停止追加套件，因此最终包完成 35 项界面检查后停止，不再执行额外桌面性能、10 分钟连续刷新和解压副本采集；不报告新的长期内存测量结论。

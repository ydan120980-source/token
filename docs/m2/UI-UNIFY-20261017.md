# 界面统一：合入分支的设计复核（2026-10-17）

`feat/package-and-ui-polish`（另一个会话的提交，合入 main 为 `56ed4bf`）新增了会话检查器、用量占比前 6 项折叠、心流时段、环比、来源与设置页样式等改动。项目负责人认为这些改动与 P0–P6 的风格不统一，要求逐项复核并统一。本记录是复核结论和统一后的规则，实现以 `feat/ui-unify` 的提交为准。

复核方法：用合成 fixture 和独立的 usage/quota 目录启动真实窗口，对 r14（`6390d89`）、合入后和统一后三个版本在浅色、深色下分别截图对照；再按 `tokens.css` 核对合入分支新增 CSS 用到的颜色、字号、字重和圆角。

## 修正的错误

- **会话检查器打不开。** 没有工作目录的会话归在"未知项目"下，组 key 是 `'\0unknown'`。这个 key 要写进 `data-group` 属性再读回来，而 HTML 解析会把 NUL 换成 U+FFFD，读回的值永远对不上，所以这一组的会话点了没有反应。key 改为 `':unknown'`（Windows 路径不会以冒号开头）。原测试只点了有工作目录的会话，所以没有发现；sessions 套件已补上这种情况。
- **检查器和 Token 提示把未报告的字段当 0。** 原实现用 `r[key] || 0` 求和，来源没有报告的缓存读取或写入会显示成"0 Token"，命中率显示成"0%"。现在所有日期都没报告的字段显示"未报告"；只有部分日期报告的，在数值后注明"部分未报告"。命中率只在缓存读取和输入都完整时计算，否则显示"—"。
- **检查器的构成与行内数字范围不一致。** 原来总量和费用取自当前页面范围，构成却对全部日期求和。现在都按页面范围（今天、7 天、30 天、全部）计算。
- **重复且描述不实的"连续心流时段"。** 它和卡片头部的"高峰三小时"是同一个函数在同一份数据上算出来的；提示里写的"近一周"也不对，实际范围是页面范围。已删除这一行，以及时间轴上对应的高亮。
- **推理计数冲突的提示写了无法确认的原因**（"上游流式传输历史偶发计数偏差，已隔离审计"）。改为陈述事实：这些记录的推理 Token 多于输出 Token，数据自相矛盾，不计入估算。
- **结构上的无障碍问题。** 项目行是一个 `<button>`，里面又嵌了 `role="button"` 的打开、复制按钮；会话行是 `<li role="button">`，里面也嵌了按钮。嵌套的可交互元素无法被键盘和读屏正确识别。现在项目行由"折叠按钮 + 并列的操作按钮"组成，折叠按钮用 subgrid 与行内列对齐；会话行的时间单元格就是这一行的按钮。点击行内任意空白处，照旧打开明细或折叠。

## 统一的样式

| 原实现 | 统一为 |
|---|---|
| 检查器自成一套：卡片里套卡片和"宫格"小卡、虚线分隔、iOS 系统色（`#007aff #af52de #34c759 #ff9500`）标 Token 分类、蓝底白字按钮 | 沿用价格编辑器的面板（`.price-editor`：表面、标题区、圆形关闭按钮、底部操作区）；数字在发丝线列表上；分类色用图表的 `--input --output --read --write`；恢复命令用 `.primary` 按钮 |
| 今天卡片的模型连线按 Agent 着色（十个硬编码品牌色），末端发光圆环，悬停加粗 | 发丝线色的中性树形连线，不着色、不发光、悬停不变化 |
| 环比做成胶囊，上升橙色、下降绿色，切换范围时数字重新淡入 | 和"记录""日均"同样的文字事实（"较前 7 天 +12.3%"），不着色：用量多少无所谓好坏；去掉每次切换都会重播的动画（与 P6 "切换范围不重播"一致） |
| 用量占比：卡片内又加一个搜索框；"其他 N 个"和"展开其余 N 个"两个入口做同一件事；▾▴ 字符；两张卡片强制等高，占比卡下半截空白 | 去掉搜索（下方"模型明细"已有搜索）；"其他 N 个"是唯一的展开入口，展开后只有一个"收起"按钮，用全站统一的箭头；两张卡片各按内容高度排列（P6 的决定） |
| 设置行、隐私卡片、来源行在悬停时变底色 | 只有可操作的元素有悬停反馈 |
| `:active` 用 `color-mix(… #000)` 加深，深色外观下反而更暗 | 用 `--fill-strong` |
| 新增 `--ease-apple`、`--ease-apple-subtle`，与 `--motion-ease` 几乎相同 | 并回 `--motion-ease` |
| 字重 450、550 | 回到 500 / 600 |
| 删掉了总量后"Token"标签的字号与颜色 | 恢复 |
| 会话行"跨天"标签与时长标签重复，时间被截断 | 去掉"跨天"，调宽时间列 |

统一后，渲染层用到的 6 位十六进制颜色和非标准字号与 r14 完全一致（逐项计数核对）。

## 保留的改动

会话检查器（入口、内容、复制和打开操作）、用量占比前 6 项折叠、环比数据、来源路径点击复制、设置导航搜索的分区提示、来源状态胶囊、今天卡片的列宽校准、工作树打包脚本。

## AGENTS.md 的 taste-skill 一节

合入分支在 AGENTS.md 加了一节，要求所有界面工作遵守 `design-taste-frontend`。该 skill 自己的说明写明不用于仪表盘和应用界面，节中要求的"Bento grids"正是检查器卡片套卡片的来源。这一节改写为"UI direction"：设计依据是 `UI-REDESIGN-PLAN-20261014.md` 和后续 `UI-*` 记录，取值来自 `tokens.css`；保留原节里有用的两条：数据视图以可读密度和对比度优先，代码不写占位。

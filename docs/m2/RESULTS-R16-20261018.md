## 首轮失败与修正

- interaction-reliability 首轮等待“来源设置已保存，读取位置检查失败”超时。测试虽已启动打包 EXE，故障注入仍通过工作树绝对路径加载另一份 Service/Store，因此没有让运行模块失败。改用运行进程的 `app.getAppPath()` 定位模块，断言不降低，100%/150% 全套复跑通过。运行包产品字节未改。
- 额外反向 ASAR 核对的一次性检查先后误用扩展名筛文件、非本机分隔符查元数据；修正为本机路径和 ASAR 文件元数据后通过。这是检查方法修正，没有漏打包文件。
- 首轮运行时共享与测试进程重叠，部分资源被 Windows 占用而不能改为硬链接。结束测试后重试完成，最终共享复核通过，内容哈希未变。
- 首轮日志全部保留，没有将复跑记作首轮通过。

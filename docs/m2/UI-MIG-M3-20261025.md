## 与审核记录不同或补充的地方（均已实现）

1. **kit**：
   - AgentMark 补上官方图标的色调规则（Claude 染品牌橙，黑色图标在深色下变浅灰；theme 辅助类 `ff-mark-*`）；
   - Disclosure 撑满容器；
   - ScrollArea 只在确实溢出时显示淡化（`data-overflow`）；
   - Form 增加 `onInvalid`，并在输入法组字期间不提交；
   - `kit/ime.ts` 增加文档级的输入法保护，规则与旧版一致，M9 后由它接手；
   - Sheet 的关闭按钮改为中文“关闭”：vendor dialog 新增 `closeLabel`，已登记在 VENDOR.md。
2. **旧样式**：`motion.css` 的“减少 / 关闭动效”规则排除 `.ff-scroll-fade`；`motion.js` 取消动画时跳过滚动驱动的动画。滚动淡化跟随滚动位置，属于位置提示，不是动效。
3. **`cost-page.js` 改了两行**：打开价格弹窗前先关闭费用明细的原生弹窗。原因：原生模态弹窗会盖住 React 弹窗，并让它无法操作。
4. **文案调整**：
   - 采集开关的标签改为显示当前状态（“运行中 / 已暂停 / 只读快照”）。旧版按钮上写的是动作，另有一个状态徽标，现已去掉徽标。
   - 旧版的 `collectionHelp` 一直带着 `hidden`，从未显示过，已删除。
5. **行为差异**：
   - “关于”里点击某个来源时调用 `sourcesUi.focus`：跳到来源管理并展开该来源。旧版只滚动，不展开。
   - 搜索不再高亮匹配行，没有匹配项的分类改为禁用。
   - 点击分类后，在 1 秒内保持选中该分类；页面在顶部时选中“常规”。

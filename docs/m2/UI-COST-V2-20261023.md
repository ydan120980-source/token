# 费用页重做（2026-10-23）

## 所有者决定

所有者在三套设计稿中选定：
- **主体：** 方案 A（仪表格）；
- **左侧栏：** 方案 C 的“可选范围 + 日历”；
- **订阅卡片和过渡动画：** 方案 B（章节）的样式，并继续补充细节和功能。

实施过程中所有者追加要求：范围选择和日历都能展开、收起。

设计稿上，Gemini 与 Codex 的配色几乎相同，因此改用紫色区分。由此为费用图表新增一套逐 Agent 的系列配色：
- 定义为 `tokens.css` 中的 `--series-*`，分浅色和深色两组；
- 只用于费用图表，额度页的 `--agent-*` 色调保持不变；
- 与 `--agent-*` 一样，颜色只用来区分 Agent，不表示好坏。

本增量只改渲染层：
- 数据仍来自 `cost-table`、`cost-insights` 和用量行；
- 读取、定价、导出和月费保存的语义均不变；
- 未知的值仍显示为未知，不按 0 计。

## 分步

第 1 步与第 2 步一起合入（`9596f6e`），第 3 步另行合入（`ce5e2d8`）。原因是第 1 步把主栏变窄后，旧“费用构成”表的列会溢出卡片；第 2 步正好用环形图替换了它。

### 第 1 步：左侧栏与总览

**页面结构**
- 页头只保留“费用分析 / 项目与预算”和导出。
- 范围文字（例如“累计 · 2 个 Agent”）兼作左侧栏的折叠开关。左侧栏收起后，主栏占满宽度；收起状态会被记住。

**日历**
- 点两天即选定一个范围；选起点后，悬停或聚焦的日期会预览范围；Esc 取消；方向键按天、按周移动。
- 有用量的日期下方带一个小点；未来的日期和采集开始之前的日期不可选。
- 每周一行的选区画成一条两端圆角的色带。
- 日历可以单独收起，收起后只留快捷范围，状态同样会被记住。

**快捷范围**
- 顺序为“累计 / 30 天 / 7 天 / 今日”，与用量页一致。
- 选了自定义范围或某个月份时，会出现一个可清除的胶囊（沿用 `#costMonthChip`）。
- 自定义范围的对比区间是它之前等长的一段。

**Agent 勾选**
- 列出当前范围内每个 Agent 的已计价金额；部分未计价的金额后带“+”，完全未计价的显示“未计入”徽标。
- 取消勾选后，该 Agent 从整页数字中移出：总览、走势、花在哪、按月、订阅和明细。
- 至少要保留一个 Agent；全部勾选等同于不筛选。

**“明细只看未计入”**：只列出没有估算或只计入了一部分的条目。

**总览**
- 大数字：估算区间以下限为主，上限缩小跟在后面；含未计价用量时带“+”。
- 三个胶囊：已计入比例（带小圆环）；未计入的 Token（点击跳到核对）；较上一区间的变化。
- 三个数字块：日均、每百万 Token、缓存约省下。

**入场动画**：各区块第一次进入视野时升起一次（方案 B），只在完整动效下播放。

### 第 2 步：走势与花在哪、按月、订阅

**走势（`cost-stack.js`）**
- 按 Agent 堆叠已计价估算，最大的 Agent 放在最底层；超过 120 天时按周汇总。
- 没有任何已计价用量的日期留空；含未计价用量的日期在横轴下方画一道短竖线。
- 新的范围或 Agent 组合会从左向右画出；点图例显示或隐藏某个 Agent，或切换每日 / 累计，都从当前图形平滑过渡到新图形。
- 悬停或方向键会显示竖线、各条带顶部的圆点和提示。提示列出各 Agent 的金额、合计，以及哪些 Agent 的用量未计入。
- 点击或回车会把整页范围切到那一天（或那一周）。
- 保留原有的展开 / 收起，以及图表的类名。

**花在哪**
- 环形图只包含已计价金额，可按 Agent 或按类型查看；按类型时每行注明它在 Token 和费用中各占多少，估算区间单独列一行。
- 指向任一扇区或列表行时，两者同时高亮，圆心显示该项的名称、金额和占比。
- 点 Agent 行，整页只看这个 Agent。

**按月**
- 柱子改为圆角，进入视野时依次长出；指向一列时其余列变淡。
- 原有语义不变：实色是已计入，斜纹是估算区间，虚线框是本月推算，点一列整页只看这个月。

**订阅（方案 B 的卡片）**
- 每个 Agent 一张卡片。
- 月费在卡片里直接填写，仍按原规则保存。
- 回本倍数大字显示；没填月费时显示“—”并提示填写，完全未计价时显示“未计入”。
- “API 等价”与“月费”两条对照条用同一刻度，入场时长出。
- 额度用量按钮链接到额度监控。

## 第 3 步：明细与核对（另行合入）

**版式**
- 左侧栏只陪着上半部分：总览、走势、花在哪 / 按月、订阅。
- 费用明细和核对移到下方，占满整页宽度。
- 左侧栏只在上半部分内吸顶，到明细处停住，不会盖住表格。

这样调整的原因：主栏放在左侧栏旁边时只有约 580px，放不下明细表的九列，模型名一列被挤没了。占满宽度后，原有按宽度切换列数的规则照常生效。

**计价覆盖（方案 A 的核对）**
- 环形图显示已计入的 Token 比例，旁边列出从读取到全部计价的步骤：
  1. 读取了几个 Agent 的用量；
  2. 几个模型有价格；
  3. 每一种未计入的原因各一步，标明 Token 数量和占比、涉及的模型，以及“不按 0 计”，并附原有的“设置计费 / 核实价格 / 处理方法”按钮；
  4. 估算区间；
  5. 计价覆盖是否已到 100%。
- 环形图在区块进入视野时扫出。

**明细**
- 展开一行时，详情轻微下落、淡入。
- 其余保留：行内展开、排序、筛选、分组、走势小图。

**AGENTS.md**：在界面方向中补充了 `--series-*` 配色的所有者决定。

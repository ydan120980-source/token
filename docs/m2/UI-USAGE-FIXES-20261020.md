# 用量页修正（2026-10-20，界面重做 A 步）

所有者在 2026-10-20 试用后确认了 A～F 的界面待办。A 是用量页的三个问题，本记录是它的结论。

## 修正

- **展开"API 等价估算"时，"记录 / 日均"跳到下一行。**
  - 原因：区间放不下时用 `transform: scale` 缩小。变换只改变看到的大小，不改变布局宽度，所以这一行按未缩小的宽度排版，"记录 / 日均"被挤下去，而且没有过渡。
  - 修正：区间改为按字号缩小（`font-size` 与展开宽度用同一时长和缓动），看到的宽度就是布局宽度。分隔线改用 em，整段区间一起缩放。
  - 按钮展开时至少保持收起时的宽度，指针不会因内容变小而移出、反复展开收起。
  - 测量移到切换状态之前，关闭动画时也能量对收起时的尺寸。已换到下一行的"记录 / 日均"不再占用估算这一行的空间。
- **热力图有不显示的方格。**
  - 有记录但在当前筛选下为 0 Token 的日子没有任何背景，在白色卡片上完全看不见；没有记录的日子只有 42% 的 `--heat0`，几乎看不见。
  - 修正：有记录的 0 Token 日用图例最低一格的颜色（`--heat0`）。没有记录的日子是"未知"而不是 0，画成描边的空方格，与 0 区分。
- **选择"每小时"里的时段后，每天的热力图太淡。**
  - 原因：不匹配的日子整体降到 20% 不透明度，0 Token 的格子看不见，有 Token 的格子也很淡。
  - 修正：匹配的日子保留原色和描边环；其余有记录的日子统一变成实心的空色格，没有记录的日子仍是描边方格。
  - 试过按级别保留 30% 色调，但高用量日混出的灰褐色比低用量日更显眼，读起来是反的，所以没有采用。

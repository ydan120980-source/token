# 费用页重新设计（2026-10-20，界面重做 C 步）

所有者在 2026-10-20 要求费用页按新设计重排，不沿用原有排版。本步按所有者确认的待办 C 项完成。

## 页面顺序

估算 → 走势 → 费用构成 → 按月 → 订阅对照 → 费用明细 → 核对（计价覆盖、缓存）。"项目与预算"仍是单独的标签页。

## 改动

- **走势**：折叠和展开用同一个图表组件，原地展开，不再弹出浮层盖住内容。
  - 以前折叠时是一张没有坐标轴的小图，像贴上去的；现在用同一张参考图（青绿色 `--cost-chart-color` 保留）。
  - 图按卡片实际宽度绘制：折叠时较矮，保留两条网格线；展开时较高，有四条网格线和更多日期。
  - 展开或收起时，绘图区高度平滑过渡，下面的内容随之移动，不跳动。
  - 可切换每日（超过 120 天按周）和累计。没有计价用量的日期留空，不画成 0。
  - 卡片宽度变化时重新绘制。
- **费用构成**：
  - 去掉悬停时让其他格子变暗的交互。
  - 两个 100 方格图换成同一刻度上的两条百分比条（Token、费用），配一句说明 Token 占比与费用占比差别最大的那一项。
  - 下方表格用固定的列宽下限，卡片内留出内边距，左侧色点和右侧"每周"走势列都不再被截断。窄窗口时隐藏后两列。
- **按月**：
  - 改为每月一根柱：实心是已计入，斜纹是估算区间，虚线框是本月推算整月。每根柱下面写较上月的变化。
  - 点一根柱，整页只看这个月；再点取消（与原来的行为相同）。
  - 底部一行合计、计入比例和本月推算。
- **订阅对照**：每个 Agent 一行，依次是 API 等价、月费、倍数、额度用量。
  - 额度用量直接读额度监控的数据，例如"5 小时 剩 64% · 每周 剩 38%"，点击跳到该 Agent 的额度卡片。
  - 没有连接额度时显示"额度未连接"。
  - 额度变化时，`quota-cards.js` 发出 `quota-change` 事件，订阅对照随之更新。
  - 额度卡片上仍然不放月费。
  - 底注说明额度用量反映的是此刻的剩余比例，与所选月份无关。
- **费用明细**：
  - 表头不再换行。
  - 展开后的明细不再固定高度，三栏随内容增高，没有内部滚动条，也没有横向滚动区域。使用方超过 8 个时显示"另有 N 个"。
  - 走势用页面同一个图表组件，整行宽度显示该条目的每日 Token，替换原来的"末段 7 天"和"查看完整范围走势"。
- **样式**：
  - `cost.css` 删除了方格图、浮层走势、旧按月行和固定高度明细的规则，新规则都从 `tokens.css` 取值。
  - 新增 `--on-category`：类别色条内文字的颜色。
  - `cost-chart-ui.js` 的 `html()` 新增可选的 `frame`（指定绘图尺寸）和 `bare`（不带标题和折叠按钮）参数；原有调用方式不变。

## 不在本步范围

- 页面底部的"历史费用估算"和"费用核对事项"保持原样：前者属于设置页定价整合（F），后者并入来源管理的"需要处理"列表（D）。
- 计价覆盖与缓存两张卡片保持原样。

## 验证

源码模式，合成数据：
- `verify`、`audit:runtime` 通过。
- cost、cost-rebuild、cost-compact、cost-layout、billing-query、unpriced-guidance、workbench、style-alignment 八个界面套件通过。
- 截图核对了 1320 和 960 宽度、浅色和深色。没有横向滚动，没有页面错误。

## 测试调整

- cost-compact 原先断言明细固定 316px 高、内部可滚动，与所有者的要求相反。现在改为断言：明细随内容增高，没有元素内部滚动；25 个模型和 10 个使用方全部列出；长标题的完整文字可在悬停提示中看到；走势图与明细同宽，标签字号可读。
- cost-layout 原先断言 GPT 的原始排版（估算右侧的小图、成对卡片）。现在改为检查：各区块的先后顺序、费用构成单元格不超出卡片、明细表头只有一行、桌面宽度下所有列都在、走势原地展开并把下方内容推下去、金额标签在曲线上方、核对两张卡片并排。
- cost、cost-rebuild、style-alignment 改用新的构成条、按月柱和走势卡片的选择器。原有的重叠与截断检查保留，并扩展到按月柱和构成表格。

未验证打包版与真实数据。

# 可配置 JSONL 来源采集契约（2026-10-17）

状态：项目所有者已批准本轮完整实施计划。此记录补充原来源契约：用户通过本地选择器明确选择的自定义 JSONL/NDJSON 可按本契约读取，不放开未知目录自动内容扫描。原十来源行为不变，额度仍仅 Codex。

## 首版范围

Claude JSONL 格式复用、自定义逐请求映射、标准逐请求用量事件。来源名称与稳定 ID 分离；草稿不读取，选择后仅在预览或明确启用时读取。无 SQLite/CSV/压缩/通用累计差分，无可执行插件、认证读取、上传、会话正文或恢复命令。

## 字段与语义

只保留调用/会话 ID 的 HMAC、时间、模型/服务商、非负安全整数用量和诊断；正文不保存不返回。映射只支持字段路径和等值/集合过滤，不支持原型属性、脚本和命令。调用 ID 与时间必需；未报告字段保持 null，输入缓存和输出推理包含关系显式声明。重复调用用现有快照选择规则，计价统一计算。

## 读取与提交

仅 .jsonl/.ndjson；目录、认证文件、链接、产品目录保护沿用 policy；单行上限 1 MiB，样本最多 200 行/1 MiB；全范围预览受现有扫描限制。拒绝与内置及其他自定义来源重叠，停用不解除保护。预览绑定配置、文件戳记与账本序号，应用重新核对；完整文件替换观测，缺失/失败文件保留旧规则。配置、来源版本、逐文件 HMAC 索引和记录一次原子写入；失败不改变内存。来源级上一代回退不覆盖其他来源。

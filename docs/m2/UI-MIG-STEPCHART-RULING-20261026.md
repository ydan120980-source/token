# StepChart 刻度与起点补充裁决 · 2026-10-26

所有者在 §9.4 问题中明确批准两个刻度属性及所述起点语义，记录后继续 MK-b–M8。

在原 §4.8 接口上仅补充：

```ts
ticks?: { value: number; label: string }[];
axis?: { at: number; label: string }[];
```

由旧 UMD 原样提供三条数量刻度和四段时间轴的五个标签，首项“今天”。未提供时不生成标签、不把未知补 0；M6 传入完整旧标签。steps 首项 at=start 只承载原 c.now 初始余额，不画到期菱形；后续 amount 为各点后的余额。其它几何、互动及近点合并规则不变，不在组件里格式化数量、金额或日期。

其它范围仍按统一裁决；新增列表外接口仍需按 §9.4 停止提问。验证并入 MK-b 的组件展示、几何、未知语义、键盘与两主题/off/reduced 门槛。

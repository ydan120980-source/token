# 费用页图表与悬停精修 · 2026-10-24

所有者本轮授权：按提供截图和 EasyUI 两个参考组件改善费用/额度悬停、费用明细、订阅排布与日历，并正式打包供人工检查。

- 保持现有 Electron + 原生 SVG 渲染层，未引入 React、Framer Motion 或在线组件安装。
- 参考 [Interactive Area Chart](https://easyui.site/components/interactive-area-chart) 的 2px 圆头曲线、18% 至透明渐隐、1100ms 进入、550ms 可打断模式/图例切换，以及 520/42/0.6 的悬停位置弹簧。图形仍保留本产品的多 Agent 堆叠和未知日期空缺；单调曲线不使非负统计值产生负向过冲。
- 参考 [Donut Chart](https://easyui.site/components/donut-chart) 的细环、扇区留缝、顺序进入、当前扇区加粗和中心读数变化。根据所有者明确要求，其他扇区及月份保持原亮度。小占比扇区保留角度裁切，圆头不会盖住邻区。
- 每日/每周费用提示仅列该日/周实际出现的 Agent；有使用但未计价仍明确显示“未计入”。累计模式列截至所选日期有使用的 Agent。未使用不补零。
- 费用与额度提示沿用同一稳定淡入生命周期，使用半透明、背景模糊材质；费用提示和明细小图跟随位置可中断，不随每次移动重播淡入。
- 订阅保留现有卡片、上方说明、月费编辑和额度入口；用一条共同比例尺及月费标线，费用范围与月费在下方独立换行，避免挤压图形。
- 费用明细构成条提供分项金额/占比；走势提供日期/Token、游标和渐隐面积。聚焦整行后方向键、Home/End 查看，Esc 隐藏，Enter 仍打开详情。
- 详情层压紧指标和构成行，金额与 Token 在同一数据行；滚动条轨道留出圆角内边距，保留键盘滚动、焦点约束、遮罩/Esc/边缘拖动关闭。
- 日历月份/星期/日期按同一网格中心对齐；所有者随后澄清日期快捷按钮保留，因此继续提供原来的累计/30 天/7 天/今日，并保留月份切换、两天选区、折叠及选区清除，不照搬第二张参考图的底部选项。

本次不查询真实账号、不读取真实用量来源或外部认证资料；所有验收用隔离合成目录。交付验收与限制记录于 RESULTS-COST-EASYUI-20261024.md。

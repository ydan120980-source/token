# Agent 管理改成表页，全量修复；移除归档；来源卡片折叠；卡片统一正方形 · 2026-11-05

所有者看了 11-05 的预览版后提的问题，并说“你来做”。只用合成数据，源码模式。没有读真实的 Skill、配置或会话，所以**误报减少的幅度只有合成证据**，真实机器上还剩多少“要看”没有测过。

## 决定

- **移除会话归档。** 取代 `UI-SESSIONS-MULTI-20261102.md` 里的归档。旧文件里的归档标记读取时丢弃，那些会话全部回到列表，标记在下一次保存时离开文件；名称、分组、置顶、阅读位置不受影响。
- **能在表页做的都放表页，模型定价页是参照。** Agent 管理的五个分类改成：汇总与一键处理、搜索与筛选、就地展开的行。只有编辑指令文件正文这种大操作才开 Sheet。
- **一键处理只做可恢复的停用。** 不删文件，不批量改 `SKILL.md`，不联网。每一项单独加密备份，有自己的恢复记录，也能一步撤销。这是我的建议，所有者没有反对；要删除或自动补前言需要另行决定。
- **定位只收 id。** 渲染层不能传路径。打开文件只限 `.md .json .toml .yaml .yml .txt`，不跟随链接，拒绝认证文件名，所以不会启动程序。
- 额度卡片全部正方形，任何窗口宽度都一样。

## Skill 判断改为按各 Agent 自己的规则

之前用写入用的严格解析器判断健康，它不接受列表、嵌套、注释、多行等常见写法，一律报“前言解析不了”。现在：`config-health-syntax.frontmatter` 仍是写入的关口；清单用 `src/m1/skill-front.js` 逐行读顶层字段，不执行、不解析标签和引用。

| 规则 | Codex | Claude Code | Gemini CLI | OpenCode | 依据 |
|---|---|---|---|---|---|
| 必须有 name 和 description | 是 | 否，用目录名和正文第一行 | 是 | 是 | 各自官方文档；Gemini 为 `skillLoader.ts` |
| 前言写法不标准 | 没法确认 | 文档说仍加载，字段作废 | 有宽松回退，不提示 | 没法确认 | 同上；Codex、OpenCode 的解析器没有读到 |
| 第一层以下的 SKILL.md | 能找到（递归，上限 6 层） | 文档只写第一层，没法确认 | 找不到（`*/SKILL.md`） | 文档只写第一层，没法确认 | Codex `ext/skills/src/loader`；Gemini 同上 |
| 同名 | 两个都会出现在选择里 | 只用其中一个 | 只用其中一个 | 文档要求不重复 | 官方文档；Gemini 这一条是推断 |

查阅于 2026-11-05。“没法确认”不计入“要看”。Codex 文档没有提 `~/.codex/skills`，它是否仍被读取没有确认，清单继续列出这个目录。

已知没做：OpenCode 文档说它也读 `.claude/skills` 和 `.agents/skills`，清单仍只把 `.config/opencode/skills` 算作它的，同一目录没有被计到多个 Agent 名下。

## 每种问题怎么处理

`problem()` 带一个 `remedy`，`tests/m1/agent-inventory.test.js` 检查每条都有。

| 问题 | 处理 |
|---|---|
| Skill 缺前言或缺必需字段（必需的 Agent） | 一键，默认选中；也可以手动补 |
| 同名 Skill 中要让出的那个（当前目录外的，或较旧的） | 一键，默认选中；留下的那个只提示 |
| 插件文件不见了 | 一键，默认选中 |
| MCP 结构错误（启动不了） | 一键，默认选中，限 Codex、Claude |
| 插件 `plugin.json` 解析不了 | 一键，默认不选 |
| MCP 命令不在 PATH | 一键，默认不选：Agent 的 PATH 可能不同 |
| 明文密钥、地址带密钥、http、环境变量没设 | 手动，给步骤和定位 |
| Hook 结构错误、命令找不到 | 手动：开关只能关整层 Hooks，太宽 |
| 目录里没有 SKILL.md、放得太深、前言未结束 | 手动 |
| 配置文件解析不了、指令文件过长或为空、Gemini 扩展缺清单 | 手动 |
| 文件太大、读不了、检查没完成、插件在目录外 | 只提示 |
| 写法存疑（没加引号的冒号等） | 只提示，算“没法确认” |

Skill 的开关扩展到四个 Agent（移到 `.agent-usage/disabled-skills/<agent>`），包括 Codex 的 `.codex/skills`；Gemini、OpenCode 的 MCP 和 Hooks 仍只读。开关不能移动嵌套的 Skill，这些只能手动。目录内可管理的 Skill 上限从 64 放宽到 512。

## 其他修改

- **来源卡片：** “展开后缩不回去”在源码版和解包版都**没有复现**（点读取位置胶囊都能收起），所有者也没说点的是哪里，所以按能想到的入口都补上：内容末尾有“收起”，“查看”可开可合，Esc 收起，收起后焦点回到胶囊。去掉 `col-span-full`，展开不再改变卡片的宽度和位置。路径可在资源管理器中显示，主进程只认当前读取的位置。`invalid-reasoning` 这类代码改成定价页的说法，有记录时不再写“未安装”，去掉写着“点击复制”的错误提示。
- **会话列悬停：** 三个按钮换成一个“更多”菜单（置顶、并排打开），只占时间原来的位置。按住拖动不变。
- **文件栏：** 去掉状态图标（名字颜色和悬停卡片说明），每级缩进从 20px 减到 12px，文件名完整换行，文件夹不再显示增减数，增加平铺显示。
- **概况：** 上下文压缩、附带的文件、引用的记忆、Token 最多的轮次都能折叠，超过 5 条时其余收起。
- **额度卡片：** 正文可以收缩；有副行时主数字减小；副行让名字先占位；只重复卡片名的别名不再占一行；券条变矮，金额不折行。超长值的卡片仍可能比正方形高，因为“不截断”优先。

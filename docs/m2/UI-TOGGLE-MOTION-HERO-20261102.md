## 所有者的问题、原因和做法

| 问题 | 原因 | 做法 |
|---|---|---|
| 费用走势选择和取消 Agent 没有过渡 | 隐藏的序列直接从图里删除；重新显示时直接出现。序列的路径结构还会跟着变，无法平滑变形。 | `LineChart` 新增 `hidden`：隐藏的序列留在图里，数值压到 0 并淡出，所有路径的结构保持不变，其余序列和坐标轴一起移动。合计和读数仍只算显示的序列。 |
| 用量趋势选择和取消成分没有过渡 | 同上：隐藏的序列数值被换成空值，路径直接消失。 | 同上。 |

| 费用首屏的悬停经常没有 | 条只有 12px 高，光标稍有偏差就碰不到，有的细段宽度接近 0。 | 每段上下各多 10px 响应范围，段间缝隙也算，细段至少 8px 宽；指向时其余段变暗。 |

| 按月没有滑动 | 合成数据上没有复现：选中月份后，滚轮在图上和图例上都能滚动，滚到头后带动整页。 | 把两栏高度从 408px 提到 520px，按月的内容通常不用再滚动；放不下时仍可滚动。 |

## 概览页的悬停

“首页”可能指费用首屏（所有者的截图是这一块），也可能指概览页，所以两边都查了。

概览页合成数据上 18 个悬停卡片、两轮逐个指向，全部能打开，没有复现“经常没有”。代码里找到一条会导致这个现象的路径：页面任何滚动都会关掉卡片，而卡片只在光标进入元素时打开，光标留在原地就不再出现。现在光标在元素上移动时会重新打开（核对：打开、触发滚动后关闭、移动 2px 后重新打开）。

悬停卡片也不再因为无关的滚动关闭：只有真正带动卡片所依附元素的滚动才关闭它（之前任何滚动都会，包括另一个列表自己滚动）。

所以概览页只是修了可能的原因，不能保证已经解决所有者看到的现象。

## 顺带修掉的问题

`cost-live-readout` 套件暴露了一个真实的跳动：浏览器的滚动锚点选中了两栏面板里的内容，面板内部内容一变，整页就跟着滚动约 64px，光标下的元素随之移开。面板高度固定，里面的变化不影响页面，所以面板现在不参与滚动锚定（`overflow-anchor: none`）。

合成探针 `probe21`（改动前）和 `probe22`（改动后），1440 宽，深色：

- 没有页面错误。

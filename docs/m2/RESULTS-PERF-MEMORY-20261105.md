## 独立会话解析进程试验（已撤回）

所有者随后明确“流畅和点击响应优先于内存”。按此复核，本方向不进入默认产品实现：三栏首读从 151 / 302 / 439 ms 升为 239 / 505 / 760 ms；跟随重读约从 114–138 ms 升为 216–259 ms。最大帧间隔从 253 升为 277 ms。虽然扫描省约 73 MiB，启动进程的代价使读取更慢，产品源码和新增产品文件均已恢复，补丁、生命周期测试和全部实测保留在本地证据目录 `rejected-utility-latency`。

原统计 Worker 继续独占账本。单会话读取先由它验证会话键与来源，再交给应用拥有的 Electron utility process；正文不再经统计 Worker 中转。解析仍按记录、空闲和原有堆预算退役，退出事件确认之后才完成释放；没有跨记录正文缓存。扫描与单记录读取共享应用队列，扫描前结束已有单记录解析器。Node 测试继续使用线程实现；产品路径使用独立进程。

# 来源与计算链路专项维护（2026-10-18）

项目所有者批准依次推进：来源解析与去重核验、历史与费用一致性维护、真实来源只读核对及运行候选验收交接。基线为本地 main `3649857`，由当前主线程在独立工作树实施。

范围包括十个已有来源及三个自定义 JSONL 格式；不增加品牌、格式、全盘发现、可执行解析器或账户额度。真实读取仅经 validate:local，在现有采集契约批准的路径及字段内进行。不能将合成结果标记成真实验证，也不能将投影汇总校验标记成原始日志语义验证。

先建立不调用产品归一化或计价函数来产生期望的合成算例，再检查文件与规则变化、回退、费用覆盖和导出。确认的缺陷记录复现及回归证据；尚未验证的来源列出原因。

本轮真实核对使用隔离输出，不改运行中的统计、偏好或验证标记，不读取认证，不写来源，不保存正文或原始身份。运行候选打包、桌面及解压副本验收仍由发布负责人按 CONTRIBUTING.md 执行；本轮准备交接清单，不以源码检查替代发布验收。r15 保留，GitHub 同步暂停。

## 解析、历史与费用增量

- 新增手写预期桶账本：十个内置来源及三个自定义格式；不使用产品归一化、快照选择或计价函数生成预期。
- 修复 WorkBuddy：历史明细已保留时，即使明细文件缺失，也不再累计同会话总量。旧账本已有重叠时，启动时先备份再移除总量补充。合成复现从应有 120 错计为 240，修正后含重启保持 120。
- 修复常规采集保存失败：在临时状态中合并，失败恢复原状态、缓存快照和持久化摘要；重试能够正常保存。此前注入 EACCES 后，内存查询暴露未落盘的新记录。
- 联合验证自定义规则替换、缺失文件旧规则保留、另一来源隔离、手动价格与倍率、来源回退和重启。未增加品牌或格式。

## 真实验证入口变更

`npm run validate:local -- --output <隔离输出目录>` 仅输出报告，不再自动更新 APPDATA 下的验证标记或创建正式 Store。`--home <合成 home>` 用于验证该工具本身，显式 home 不继承真实 Agent home 环境覆盖。

每来源最多考察 12 个候选，完成最多 3 个可比较文件，单样本上限 64 MiB；反向文件名字典序选择。总时间预算 120 秒，外部 worker 在 180 秒终止，跟踪并终止当前原生子进程。输出不能与来源范围重叠，SQLite 比较前后包含 WAL 戳记。读取内容、身份及路径不进入报告。文件抽样不证明跨文件身份正确或全量历史正确。

独立比较算法只认证明确支持的形态：Claude/WorkBuddy/OpenCode/MiMo/Gemini/Cursor SDK/ZCode inclusive/Antigravity transcript 的桶；Codex 无回退且请求和累计一致时的末次累计总量；DeepSeek v2–v4 完整日志的逐尝试桶（跳过继承部分，校验序列）。DeepSeek 仅共用 Zstandard 帧边界工具和 Node 原生解码器，不调用产品用量提取/归一化；压缩与解压样本均有 64 MiB 上限。总量相等但桶不同会比较失败。冲突、工具桶、继承基线、计数重置等明确保留未验证。Cursor CSV 暂无独立比较器，不借用产品解析器生成期望；Antigravity 模型配对不因桶比较通过而标为已验证。

本轮不读取未指定的自定义真实目录。配置式接入的完整流程以隔离合成用例和来源向导检查验收；真实来源覆盖另列结果，不能替代发布候选验收。

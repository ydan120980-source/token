# 额度页首屏：三页左右切换 · 2026-10-24

## 所有者决定

所有者认为额度监控首屏（倒计时 + 时间线）作用不大、缺少交互，要求重新设计，并做成和费用页一样可以左右点击、滑动切换的形式。看过设计稿 `.cache/mockups/quota-hero` 后，所有者选定三页全部采用、按原顺序排列，并要求“减少文案，多一些图形”。

本记录取代 `UI-QUOTA-TIMELINE-20261023.md` 和 `UI-QUOTA-GROUPS-20261023.md` 中关于页头的部分。卡片、筛选、详情表和需要处理一栏不变。

## 实现

### 共用的切换组件

- **抽出 `ui-carousel.js`**：费用页首屏里的切换逻辑抽成共用组件，费用页和额度页都使用它。
  - 切换方式：箭头、带文字的圆点（可用方向键）、拖动或滑动（按距离或速度决定停在哪一页）、触控板横向滑动。
  - 不在当前页的内容设为 `inert`，外框高度跟随当前页。
  - 逐位滚动的数字也放在这个组件里。
- **样式位置**：通用样式改为 `ui-carousel-*`、`ui-roll-*`，从 `cost.css` 移到 `pages.css`。
- **费用页不变**：外观和行为不变，测试使用的类名保留。

### 额度首屏（`quota-hero.js`）

`quota-hero.js` 由组件自己管理节点（`data-island`）。数据模型由 `quota-cards.js` 的 `heroModel` 生成，只统计当前显示的卡片。

**现在**
- 每个 Agent 的额度池画一组同心圆环：外圈是最短的窗口，白色刻线表示时间还剩多少。
- 每个池只有一个窗口时（例如 Gemini 的各个模型），合成一组，每个池占一圈。
- 左侧默认读出“最快恢复”（已耗尽且最早恢复的窗口）或“最紧”（剩余最少）的窗口：
  - 大数字逐位滚动；
  - 下面是倒计时，以及“时间 / 额度”两根对比条和节奏估算。
- 指向任一圈，读数切换到该窗口；点击打开该 Agent 的详情。
- 读数区高度固定，圆环不会因为读数变化而移位。
- 状态的画法：
  - 已过重置时间的窗口：虚线圈，不显示数值；
  - 已耗尽：弧为空，底圈用警示色；
  - 未知：只有底圈。
- 余额类连接缩成小胶囊，点一下跳到“余额”页。
- “已连接 N/总数”和“1 天未更新”保留为两个按钮。

**接下来**
- 每个窗口和每批到期各占一行时间轨。
  - 行的顺序：同一张卡的行放在一起，最紧急的卡排在前面。
  - 超过 7 行时折叠，显示为“+N”按钮。
- 时间针的操作：拖动、点击轨道、点击圆点或菱形直接跳到那一刻、方向键（Home / End 回到现在 / 跳到范围末尾），指针悬停时预览。
- 每行右侧显示时间针那一刻的值：
  - 过了重置时间的窗口显示“↻ 100%”（按“已用”读数时显示 0%），不推算期间的用量；
  - 到期的积分从余额中扣除，显示剩余多少。
- 左侧统计到那时有多少个窗口重置、多少批积分到期。
- 没有报告时间的连接只用一排图标表示。
- 24 小时 / 7 天 / 30 天的范围选择和偏好设置不变。

**余额**
- 每个按金额计的连接一块，各自使用自己的单位，跨 Agent 不相加。
- WorkBuddy 同一账号的积分包合计，沿用已有的例外，并带一条按到期时间分段的条。
- 没有额度项的连接写“没有额度项”，悬停提示说明这不代表额度为 0。
- 有到期时间的积分画成阶梯图：
  - 余额在每批到期时下降一级；
  - 不限期的部分画成虚线底线；
  - 相距很近的几批合成一个菱形；
  - 指向菱形时读出这一级到期多少、几个积分包、之后还剩多少。
- 同时有几个这样的账户时，可以用图标切换。

### 数据语义

- 未知始终显示为未知；时间可以比较，不同 Agent 的数量从不相加。
- 颜色只用来区分 Agent；耗尽状态沿用已有的警示色。
- 当前页记在本机偏好 `agentusage.quotaCards.v1` 的 `slide` 字段。

## 验收

- `scripts/m1/quota-v4-ui-test.js` 改为检查新的首屏，深色和浅色两种主题：
  - **现在**：读数、指向圆环后读数跟随、虚线圈；
  - **接下来**：行数、轨道上不放文字、时间针跳到末尾后的重置数和到期批数、到期后的余额、窗口显示为满额、范围设置保存、点击行打开详情；
  - **余额**：各块的值、阶梯图的读数；
  - **切换**：拖动翻页、当前页保存；
  - **对比度**：只检查当前页。
- 其余检查不变：需要处理一栏、共用卡片、筛选、详情表、拖动排序。
- 全部使用合成数据和独立目录；没有打包，也没有做真实账号验收。

## 概况栏

页面标题下方新增一条概况栏 `#quotaOverview`，宽度与三张卡片对齐，包含四项内容：

| 项 | 内容 | 没有数据时 |
| --- | --- | --- |
| 已连接 | 连接数，以及已连接 Agent 数 / Agent 总数 | 整条概况栏不显示（页面上没有已连接的卡片） |
| 需要处理 | 状态带警示的连接数和名称，点击依次定位到这些卡片 | "无 · 所有连接状态正常" |
| 最近重置 | 最早一个将来的重置时间，以及所属卡片和额度项 | "未知 · 服务没有报告重置时间" |
| 最低剩余 | 百分比窗口中剩余最少的一项 | "未知 · 没有可比较的百分比额度" |

- **统计范围**：只统计页面上显示的已连接卡片，隐藏的卡片不计入。
- **不相加**：各窗口和资源池之间只比较，不相加，不把未知当 0。"无限"的窗口不参与最低剩余的比较。
- **过时数据**：卡片上标"待刷新"的窗口，重置时间已经过时，不能算作最近重置；它的剩余百分比可以作为最低剩余，但会注明"待刷新"。
- **定位提示**：点击"需要处理"后，页面滚动到对应卡片，聚焦它的详情按钮，卡片外圈显示 1.6 秒警示色细框。完整动画模式下平滑滚动，其他模式直接跳转。
- **样式**：
  - 概况栏是单层表面（`--card`），里面不再套卡片，四项之间用细竖线分隔。
  - 只有"需要处理"在有内容时是按钮，所以也只有它有悬停反馈。
  - 额度页宽度不足约三张卡片时（`@container quota (max-width: 760px)`），改为两列。窗口有最小宽度，按窗口宽度写的媒体查询不会生效，所以改用容器查询，和其他页面一致。

## 需要处理的卡片在前

# 阅读页：文档版式和第一组功能（2026-11-02）

**状态**：已实现，合成数据源码模式下核对；打包和真实数据未验收。所有者 2026-11-02 决定：按方案 A 加右栏开关，问题用 B 的气泡并提高对比度，先做第一组；打开阅读时收起外层菜单；默认窗口改成最适合阅读的尺寸。方案见 [UI-READER-PROPOSAL-20261102.md](UI-READER-PROPOSAL-20261102.md)。

没有扩大读取范围。这次新增的是复制和导出的粒度：单条消息、代码块、选定的几轮。它们和原来一样只在本人点击时发生，AGENTS.md 的边界已同步。

## 版式

- **外层菜单**：打开对话时收成图标栏，回到列表时恢复。标题栏按钮和 Ctrl+B 可以在这次阅读中展开；这个操作不改变你保存的菜单状态，下次打开对话会再次收起。
- **默认窗口**：1480 × 960，超出屏幕工作区时取工作区大小。这是目录（224px）、720px 正文和右栏（288px）并排所需的宽度。窗口大小目前不记忆，每次启动都是这个尺寸。
- **正文**：白底卡片，宽 720px；回复不再带图标，标题栏已写明 Agent。
- **问题**：右侧气泡，底色从 `--soft` 改为新变量 `--ff-bubble`（浅色 #dcdce2，深色 #4a4a50），字重 medium。
- **目录**：每轮带时间，失败的轮次有标记，长间隔写在两轮之间。

## 第一组功能

| 功能 | 行为 |
|---|---|
| 时间和间隔 | 每轮标时间，跨天时带日期；两轮相隔 30 分钟以上写“隔了 N 小时”。没有时间的条目什么都不写 |
| 问题留在视野里 | 问题滚出顶部时显示一行“第 N 轮 + 问题”，点一下回到这一轮开头。它盖在内容上，不挤动正文 |
| 全部 / 只看对话 / 只看失败 | 只看对话隐藏执行过程，只看失败只留有失败的轮次。查找或右栏跳到被隐藏的内容时回到全部 |
| 位置轨 | 每轮一段，长度按文字量估算，标出当前轮、失败和查找结果；按下或拖动可跳转，指向时显示这一轮的问题 |
| 上一个 / 下一个会话 | 按当前列表的筛选和排序，只含能阅读的 Agent，折叠的分组也算在内 |
| 接着做 | 标题栏复制恢复命令；不能恢复的会话不显示 |
| 复制和导出 | 代码块、单条消息、回复、整轮都能复制；导出菜单可选“选择几轮导出”，在目录里点第一轮和最后一轮 |
| 键盘 | J / K 换一轮，[ / ] 换会话，/ 或 Ctrl+F 查找；Esc 依次清空查找、关闭查找、返回列表 |
| 右栏 | 时长（按记录里的时间）、模型、Token、估算，失败和跑过的命令，点一条跳到那里。开关状态记在本机 |

位置轨不用真实像素，因为长会话后面的轮次还没绘制，高度只是估算。所以它能定位到轮，定位不到轮内某一行，滚动条也隐藏了。

代码块只有在显示的是完整文字时才有复制按钮：长回复只发前 1200 字，这时复制到的会是半截。

## 2. 第 1、4 项的修法

- **面板常驻**：额度页把三张面板放到页面内容之外，页面隐藏时面板仍挂载，`window.quotaUi` 打开面板在任何页面都有效。
- **回到页面不重放**：kit 新增 `ViewContent`（`ui/src/kit/settled.tsx`）。页面隐藏时仍不渲染内容（保留 Codex 的内存收益），只有第一次进入播放进场动效；之后再进入，Motion 的初始动画跳过，kit 图表（`usePlot`）直接处于已进入状态。页面停留期间的数据变化照常有动效。用在概览、额度页下半部分和会话页。
- **判空**：`window.sessionsHost?.summary()`、`window.sessionsHost?.count(...)`，缺失时显示未知。

## 3. 所有者指出的界面问题

### 3.1 图表悬停改为 Apple 的选中方式

所有者认为用量页近 30 天柱图的悬停不符合 Apple 设计：悬停时整列套一个圆角框，框的上下角和柱子的圆头对不齐；提示卡跟随指针，盖住旁边的柱子。

改为 Swift Charts 的选中方式（`RuleMark` 加 annotation）：

- 指向的柱子加深，从柱顶升起一条细线，不再套列框；
- 提示卡放在图表上方，水平对准这根柱子，并限制在图表宽度之内，所以不会盖住任何数据，也不会伸出卡片；
- 卡片位置只随指向的柱子变化，不随指针抖动；键盘聚焦得到同一张卡片，Esc 关闭。

范围：kit `BarChart` 的柱状图（近 30 天、单日每小时、概要卡片和费用页的每天柱）和 `Heatmap`（每天日历、星期 × 小时）。共用提示层新增 `annotation` 位置（`charts/common.tsx`）。

这一条修改了 `UI-HOVER-20261028.md` 第 2 节第 1 条在图表上的适用范围：用量页的图表不再照搬旧版跟随指针的提示卡，改用上面的方式。悬停卡片的内容、一次只开一张、键盘等价这几条不变。Codex 在 M12 按 `RELEASE-M11-VISUAL-QUESTIONS-20261029.md` 第 10 项加的每小时整列渐变、投影和相关 token 一并撤掉。

### 3.2 遮挡

| 位置 | 原因 | 修法 |

### 3.3 费用构成的图例

原来的图例是“圆点、名称、金额、占比”一行一项，与右侧“按月”的图例几乎一样，而且列表在卡片底部被截断。

改为两列小块（`ChartLegend` 新增 `tiles` 样式）：上一行是 Agent 的官方图标和名称，下一行是金额和占比；按类型查看时用色点代替图标。点击隐藏、悬停联动圆环、键盘方向键与原来相同。

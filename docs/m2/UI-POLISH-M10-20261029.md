# 打包后体验修正与首页、右栏重组 · 2026-10-29

**状态**：所有者在打包版（Codex `codex/m9-shell-closeout`，`91d4424`）上试用后，提出了一批修正和两项结构调整。Claude 在分支 `ui/m10-polish` 上完成，分支基于 `91d4424`，合入 main 时 M9 收尾的五个提交一并进入。全量测试和打包验收交给 Codex，见第 4 节。

## 1. 所有者的决定

- **首页**：概览页不常用。把可自定义的小组件搬到概览页，替换原来的三个数字、今天的活动和额度节奏。代理卡片保留，并缩小。
- **右栏**：小组件栏基本用不上，但保留它的接口（标题栏按钮、停靠和浮动、设置页不显示）。内容换成每页固定的概要。
- **概要的形式**：所有者随后补充，概要以一张大卡片的形式重新设计，不复用小组件。
- **动效**：用量页近 30 天和每小时柱状图沿用旧版的方式，并用新版的组件库实现；所有走势图的悬停和动效对标旧版。

本记录替代 `UI-PALETTE-QUOTA-SUMMARY-PROPOSAL-20261027.md` 中“小组件侧栏，不绑定页面”的条款：小组件现在在概览页上，右栏是按页面固定的概要。

## 2. 修正

| 问题 | 原因 | 处理 |
|---|---|---|
| 侧栏底部采集卡片超出侧栏 | 外框底部区域是换行的纵向 flex，宽度随最宽的子项（长用户名的资料行）变大 | 改成不换行，子项 `min-width: 0` |
| 用量页“Token 活动”上方一大片空白 | 用量概览容器带 `min-h-screen` | 去掉 |
| 概览页“今天的活动”下方空白 | 和右边的额度节奏卡等高 | 这两块已被小组件取代 |
| 多处鼠标靠近出现横向滚动条 | 表格和日历比容器宽 1–2px，Windows 显示滚动条 | 全局不显示横向滚动条，仍可用滚轮或触控板滚动 |
| 会话详情卡的关闭按钮被窗口按钮挡住 | 浮动卡从窗口顶部 16px 开始 | 卡片从标题栏下方开始 |
| 详情卡太宽 | 浮动卡沿用 540px | 浮动卡改为 440px（小号 360px） |
| 费用页“花在哪”的图例名字被逐字折断 | 图例名字用 `wrap-anywhere`，列太窄 | 名字单行省略，完整名字在提示里；图例列至少 224px，放不下时换到圆环下方 |
| 今日卡片每隔几秒闪一下 | 数字的位数一变，整串数字从透明淡入；采集时今天的数字每几秒变一次 | 位数变化时只换数字，不再淡入 |
| 用量页悬停卡顿、不跟手 | 所有图表共用一个提示层，每次鼠标移动都让页面上每个图表重渲染；悬停状态放在整段页面上 | 每个图表只读取和自己有关的提示状态，鼠标移动只重渲染提示层；悬停状态放进各图表自己的小组件 |
| 近 30 天和每小时柱状图的动效 | 新版用逐帧脚本驱动的弹簧和错开出现 | 改回旧版方式：柱子高度用 CSS 过渡（420ms，`--motion-ease`），不错开；悬停时填充在 140ms 内变化；完整动效之外只保留填充变化 |
| 代理卡片太大 | 卡片最小 260px，并随窗口变宽无限变大 | 卡片宽度限制在 248–288px，窗口宽时多排一列 |

走势图（折线）本来就沿用旧版的交互：虚线游标、对齐到最近的点、提示跟随指针。它的卡顿和柱状图同源，已一并修好。

## 3. 首页和右栏

- **概览页**：页头之后是小组件区，标题“小组件”，带布局选择和“编辑”。小组件按列向下排，高度不同也不留空。编辑、拖动排序、尺寸、设置、小组件库和多套布局都和原来一样，保存的布局继续有效。小组件区下面是代理卡片和未连接列表。
- **右栏概要**：每页一张大卡片，只读。卡片分节，节与节之间留白，不加分隔线。每节内容如下：
  - **额度**：
    - 下一次恢复的时间和剩余时长；
    - 各额度窗口及其恢复时间；
    - 连接：需要处理的项目、正常和未连接的数量。
  - **用量**：
    - 今天的 Token、估算费用和昨天的 Token；
    - 今天各 Agent 的用量，带占比条；
    - 近 7 天每天的柱子。
  - **费用**：
    - 本月至今的费用和按日均推算的整月费用；
    - 本月各 Agent 的费用，带占比条；
    - 近 14 天每天的柱子；
    - 未计价的 Token 数，并注明没有计入金额。
  - **会话**：
    - 今天的会话数；
    - 今天各 Agent 的会话数；
    - 最近 4 个会话。
  - **来源**：
    - 有记录的来源数和采集状态；
    - 各来源的状态、记录数和最近一次成功的时间。
  - **设置页**：不显示右栏。
- **数据语义**：未知显示“未知”，未计价显示“未计价”或“未定价”，都不显示成 0。

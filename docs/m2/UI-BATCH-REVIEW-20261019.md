# 界面复核：r15 之后的渲染层改动（2026-10-19）

2026-10-17 至 10-19 间，渲染层 43 个文件由后端会话改动（基线 r15 `ab767bf`）。按 2026-10-19 的分工，界面结构与展示层由 Claude 复核。本记录是第一步（已有界面）的结论；额度和安装的新界面另行处理。

复核方法：用合成 fixture 与独立 usage/quota 目录启动真实窗口，对 r15 与当前 main 在浅色、深色下逐页截图，再对新增区域单独截图；同时按 `tokens.css` 统计组件样式中的硬编码颜色、字号、`!important`、阴影与悬停规则。

## 结论

总体指标没有退化：组件样式中的硬编码颜色和像素字号数量与 r15 相同，`!important` 未增加；新样式表都从 `tokens.css` 取值。用量页与 r15 一致。费用页的青绿色趋势图是所有者提供的参考图（`UI-COST-REBUILD-VERIFICATION-20261018.md`），保留。

## 修正

- **开关关闭时看不到轨道。** `.switch-track` 的未选中背景在 P5 清理冗余 CSS（`55632b2`）时被误删：当时分析的页面里所有开关都处于打开状态。恢复为 `--fill-strong`。影响来源页读取开关、定价自动同步，以及下面的"显示已知悉"。
- **核对事项**（费用、预算、会话、来源四处共用）：
  - "显示已知悉"原为浏览器原生复选框，改用全站的开关组件，选择器与行为不变。
  - 证据行在模型缺失时以"· 影响 N 条记录"开头。改为把可选片段按" · "拼接，空片段不留分隔符。
- **订阅对照**：未填月费时，倍数列（80px）里写了 9 个字的提示，被挤成两行。倍数列恢复 r15 的"—"（悬停提示原因），说明移到卡片底注："填写月费后显示倍数"。
- **定价的匹配建议**：
  - 目录费率直接拼接浮点数，出现 `$0.0078000000000000005`。显示时保留 6 位有效数字；只改显示，不改参与计算的值。已用模型列表的费率同样处理。
  - "选择此模型"用浏览器默认按钮（白底、描边、阴影），改为与"处理方法"内按钮相同的填充胶囊。
  - "匹配建议"的标题带分隔线，看起来像一个独立的行；改为与"处理方法"相同的胶囊标题。候选行把操作按钮放到右侧，名称、理由、依据和费率在左侧。

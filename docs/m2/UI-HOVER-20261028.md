## 2. 规则

1. **迁移的页面**：旧页面有的悬停行为原样带过来，包括卡片的形状、内容、跟随指针的方式和键盘等价操作。不按别的页面改。
2. **新功能**：概览、小组件侧栏，以及迁移后新加的元素，凡是有数据的标记都要有悬停卡片，指向时这一项有反馈。
3. **一次只开一张**：悬停卡片和图表提示共用窗口里的同一层（kit `useSharedChartTooltip`），一次只显示一张。
4. **键盘等价**：可以聚焦的元素，聚焦时打开同一张卡片，按 Esc 关闭。只能用指针指到的细小标记（图块、色段、日历格），它们的内容已经写进容器的 `aria-label`。
5. **页面不写悬停**：设计守卫照旧。页面只往 kit 组件里传卡片内容（`TipCard`），悬停逻辑和 `hover:` 样式只写在 kit 里。
6. **不变的规则**：悬停时不抬起、不放大、不发光；数据语义照旧，未知不显示成 0。

## 3. 实现（kit）

- **`TipCard`**（`ui/src/kit/hover-card.tsx`）：卡片内容，照旧版图表提示的结构排列：
  - 标题，旁边可以加一个附注；
  - 每行一个色块、一个名称和一个值，当前指向的那行加粗；
  - 最后可以加一行说明。
- **`useHoverCard()`**：
  - `bind(key, content)` 绑定指针进出、聚焦、失焦和 Esc；
  - `layer` 渲染共用的那一层；
  - `active` 是当前打开的那一项。
- **共用提示层**（`charts/common.tsx` `WindowTooltip`）：从胶囊改回卡片（`rounded-xl bg-surface-5 shadow-surface-5`），与旧版 `.chart-tooltip` 一致。
  - 上方放不下时放到下方。
  - 大图表在指针处的读数（`CursorReadout`）仍是胶囊，因为旧版费用走势就是胶囊。

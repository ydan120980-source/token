# 额度监控：每个 Agent 一张卡片（2026-10-20，界面重做 B 步）

所有者在 2026-10-20 确认：额度监控改为每个 Agent 一张卡片，参照所有者提供的参考卡片（图标、名称、读取时间；每个窗口有名称、重置倒计时、大号剩余百分比和分段条；余额用钱包式）。原有的"账号额度连接与覆盖范围"和"来源与额度"两个列表从本页移除。实现过程中，所有者要求改用固定尺寸的正方形卡片。订阅费用不放在额度卡上，在费用页的订阅对照里处理（C 步）。

## 页面结构

- **已连接**：每个账号一张 296 × 296 的正方形卡片，包括 Codex 和其他 Agent。
  - 头部：Agent 图标、名称、套餐标签。右侧的刷新按钮同时显示读取时间，例如"8 分钟前"。
  - 主体：
    - 最多两个大号窗口。名称用实际的 `durationMins`（5 小时、每周），没有时长时用模型名或服务商给的名称；`role` 不当作"5 小时/每周"。窗口下方显示重置倒计时；已过重置时间显示"待刷新"，被阻断的状态显示其名称（已耗尽、已到期等）。
    - 其余窗口显示为小行，放不下时提示"另有 N 项"。
    - 余额以钱包形式显示：组成在上，服务端报告的总余额放大显示。DeepSeek 的"总可用余额"是接口直接返回的值，不是本应用相加得出的。
  - 底部：状态与"详情"。品牌图标作为淡水印。
- **未连接**：每个 Agent 一张 200 × 200 的小正方形，放在"未连接的 Agent"标题下，直接说明状态：
  - 未连接：写明读取方式，卡片上有连接按钮。Codex 在找不到 CLI 时改为"选择 codex.exe…"。
  - 暂不支持：没有经过核实的读取方式，没有按钮。
  - 未连接的 Agent 不显示任何百分比。
- **详情面板**（沿用价格编辑器面板）：
  - 每个账号逐池列出全部窗口和余额，以及每项的生命周期、新鲜度、重置时间和有效期。
  - 账号操作：刷新、重新提供凭据、取消、复制状态栏配置、移除连接。
  - "读取方式"说明：原先放在列表里的长段说明移到这里。
  - 连接或再连接一个账号。
- 页头保留自动刷新和"刷新全部"。底部一行说明额度与本机用量分开读取、不同资源池不相加，并链接到来源管理。

## 数据规则（依 `QUOTA-RESOURCE-BACKEND-20261019.md` 的界面范围）

- 逐池显示，不相加百分比、金额或不同资源包。十进制金额字符串原样显示，不转成数字。
- 未知显示"未知"，分段条为空；明确无限显示"无限"。未知不显示为 0。
- Codex 卡片同时读两份数据：V2 行提供资源，V1 行提供最新的忙碌与错误状态，任一份都足以显示卡片。

## 结构调整

- `quota-cards.js`（新）负责所有卡片和详情面板。
  - `quota-ui.js` 只保留 Codex 登录、刷新、移除和页头控件。
  - `provider-quota-ui.js` 只保留连接对话框和账号操作。
  - 以上两者都通过 `window.quotaCardsUi` 触发重绘。
  - 全局名不能叫 `quotaCards`：它会解析为 `id="quotaCards"` 的元素，`quota-ui.js` 初始化时会因此报错退出。
- `source-connections-ui.js` 只为来源页提供连接状态；每个 Agent 的额度能力与连接状态显示在来源管理页对应行内。
- 额度相关样式合并到 `pages.css` 的一个区块，取值来自 `tokens.css`（新增 `--text-quota`、`--quota-card-size`、`--quota-idle-size`）。`refinement.css` 和 `nowdex.css` 里旧的额度规则已删除。

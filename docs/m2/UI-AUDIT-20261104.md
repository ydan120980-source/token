# 按两个参考视频做的界面审计 · 2026-11-04

**状态：已实现，只用合成数据在源码模式下测过。** 没有打包验收，也没有量连续曲率圆角的绘制开销。

所有者发了两个视频，说觉得有用就全量吸收：

- 第一个是 AlignUI 的一次改版，顺序是审计、布局、组件、令牌。
- 第二个讲圆角的两条规则：内圆角 = 外圆角 − 内边距，以及连续曲率圆角（`corner-shape: superellipse(1.25)`）。

## 先量再改

`scripts/m1/ui-geometry-ui-test.js` 在默认窗口 1480×960 下走完六个页面和阅读页，找出坐在父元素角上、却和父元素不同心的子元素。量出来只有几处，所以这轮改令牌和 kit，不逐页重做。这个套件留下来防止回退。

## 改了什么

| 规则 | 改动 |
|---|---|
| 连续曲率 | 一个令牌 `--corner`，用在所有实角上。胶囊和圆形不变，半径数值不变 |
| 内圆角 = 外圆角 − 内边距 | 紧凑分段控件的滑块 8→10（内缩 2）；概览旧分段的按钮 9→7（内缩 3）；填充搜索框的焦点环跟随外框 12。默认尺寸的分段控件内缩 4，8 本来就对 |
| 对齐 | 设置页“Agent 计费规则”“Codex 用量维护”与卡片其他内容左对齐（kit `Disclosure` 的 `flush`）；模型表的服务商一行与模型名对齐；空的结果行不再占高度 |
| 克制的标记 | 每日小图上“今天”的标记从 1.5 px 黑框改成 1 px 中性色细环 |
| 用分隔符代替括号 | 阅读页的“5 次工具调用（2 次失败）”改成“5 次工具调用 · 2 次失败” |

## 没有照搬的

- **圆角加大到 24**：所有者批准的规范是 8/12/16。
- **彩色状态标签**：项目规则是用量不分好坏，颜色只用来区分 Agent 和种类。
- **头像、徽标**：这个产品没有对应内容。
- **侧栏项高度改成 32**：改过之后默认窗口几乎看不出差别，而且涉及旧的版式基线，这轮撤回了。

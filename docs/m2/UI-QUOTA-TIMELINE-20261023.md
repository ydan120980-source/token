# 额度时间线与口袋修正（2026-10-23）

所有者 2026-10-23 指出：额度页头部文字显示不全，时间线图形潦草且有遮挡，不符合 Apple 设计风格；DeepSeek 卡片应采用与 WorkBuddy 相同的口袋样式；顶部统计卡片没有交互。本增量只改额度页渲染层，不涉及读取、刷新、凭据或额度语义。

## 同日的所有者决定

- GPT 的 EasyUI 全量组件替换（引入 React 和构建链）不是所有者想要的，已由所有者暂停。11 个参考组件的交互、动效和细节，将逐项吸收到现有的原生渲染层：用量页做细节优化，费用页整体重做。
- Meteors 与 Dot Shader 只用在空状态或加载状态，不出现在数据下方；减少动态效果时停用。
- 共享 main 中另一批未提交的界面改动（Radix 色板、去掉“·”等）按所有者要求撤回。这批改动没有写入历史：已存入 `git stash`，补丁另存于 `.cache/backup/`。

## 改动

时间线：
- 每条时间线分三列：名称与数值、图形轨道、时间。轨道上只画图形（胶囊、重置圆点、到期菱形），文字一律放在固定列里，因此不会再出现时间压住胶囊或标签互相重叠的情况。
- 节奏估算只保留在卡片和悬停提示中，不再写在轨道上。
- 同一张卡片的几条时间线归为一组：第一行显示 Agent 标志和名称，下面一行写窗口名；后续各行只写窗口名，组内不画分隔线。
- 名称列宽 196px，时间列宽 84px，均为 token。
- 标记最左只到 6px，不会被“现在”竖线切掉。
- 间距小于一个菱形宽度的到期日合并成一个菱形；各批次的明细放在提示里。
- 指针移到轨道上时，一条竖线贯穿所有时间线，轴上的气泡标出该位置对应的时刻（借鉴 Interactive Area Chart）。悬停或聚焦某条时间线时，在它的标记上方弹出详情，沿用用量页热力图的提示样式。
- 每条时间线是一个按钮，点击打开对应卡片的详情。

页头：
- “接下来”列表每行显示时间、Agent 标志和窗口名，全名放在悬停提示中；每行也是按钮，点击打开详情。
- “已连接”统计会跳到“未连接的 Agent”区域；“超过 1 天未更新”统计会依次定位到这些卡片。数值为 0 或全部已连接时，对应统计不可点击。

口袋：
- 票据底部留白增至 22px，口袋上沿的凸起只会落在留白内，不会压到票据文字。
- 凸起加宽，标签收短为“N 个积分包 / 已返回 N 包”，宽度不超过凸起。
- 总额本身不可用时（例如 DeepSeek 服务不可用），其组成部分以相同状态显示为票据，卡片因此与 WorkBuddy 同样式。

# 多会话的排版和拖动 · 2026-11-04

**状态：已实现，只用合成数据在源码模式下测过。** 没有真实记录验证，没有打包验收，没有内存复测。

## 所有者的要求（原话）

> 首先我想让你冲设计一下多会话时的左右侧菜单栏和概览栏的的排版设计，当前还是有些占空间，打开后看不到会话内容了，还有上方的排版，当前的双层排版还是有些占空间，其次我想加入 Claude desktop 同款的长摁可自定义拖动的多会话功能，而且拖动时带虚化的完整功能 ui 和 motion，可以做吗

## 改了什么

### 左右栏归窗口，不再遮挡（`reader.tsx` 的 `SessionReader`）

- 左栏（目录 / 会话）和右栏（概况、命令、文件、失败、对比）每个窗口各一个，内容跟随正在使用的那一栏。单栏和并排是同一套结构。
- 两栏把会话往中间推，不盖在上面。这取代了 `UI-QUICK-SWITCH-20261102.md` 和 `UI-READER-NAV-20261104.md` 里“盖在当前栏上 / 固定在右侧”的做法，固定按钮也去掉了。
- 每栏至少留 320 px。两栏同时开放不下时，后打开的留下，另一个暂时让开，有地方后自动回来，不改记住的选择。窗口小到连一栏都放不下时，这一栏才盖在上面。默认窗口不会走到这一步。
- 左栏的搜索、筛选在切换当前栏时不再清空，因为列表只有一份。

### 顶部压成一行

- 并排时每栏的头是一行 44 px：logo、名称、显示范围（全部 / 只看对话 / 只看失败）、查找、更多、关闭。其他操作进“更多”：上一个 / 下一个会话、导出、跟随、接着做、移动这一栏。
- 项目、轮次、工具调用这些数字移到名称的悬停卡片；右栏“概况”里也有，键盘能看到。
- 头放进卡片里，不再单独占一层背景。
- “会话列表”和左栏开关放到标题栏面包屑后面，右栏开关放到标题栏右侧。不管开几栏，这些按钮都只有一份。
- 单栏也用同样的卡片和标题栏开关，但头保留两行字的名称，空间够。

### 长按拖动（`ui/src/kit/pane-drag.tsx`）

- 能按住的：并排时的栏头、左栏“会话”里的任意一行。按住 260 ms 后浮起；这之前移动超过 6 px 就算放弃，不影响点击和滚动。
- 拖栏：真实的那一栏整体缩小、虚化、跟着指针走，所以能看到它原本的完整内容；原位留一个空位。滚动位置和已读内容都不丢，因为这一栏的元素没有离开它的格子。
- 拖列表里的会话：显示一张同样虚化的栏形占位。**它不是真内容**：约定是打开时才读记录，松手前不读。
- 目标区：指针所在那一栏的左、右、上、下或中间。一块磨砂玻璃滑到落点，上面写“放到右边”“交换位置”“在这一栏打开”。不能放的方向退回中间。
- 松手：从屏幕上现在的位置飞入落点，并带上指针的速度。其他栏滑到新位置，只动位置不拉伸文字。`Esc` 或在栏外松手就放回原处。
- 排列是若干列，每列最多两栏，最多三栏。只在这次打开期间有效，不写入任何文件。
- 拖动过程中不重新排版，只有落下时才排一次，长对话不会因为移动指针而卡。这一点是按实现推断的，没有单独测帧。

### 键盘和减少动画

- 拖动的等价操作在“更多”里：向左移、向右移、放到旁边一栏下方、单独成一栏。
- 减少动画时不做弹簧和飞入，改成淡入；开启“减少透明度”时目标区不用磨砂。

## 判断（不是所有者原话）

- **Claude Desktop 的细节**：我没有它的录屏，这里按“按住、浮起、虚化、落点提示、飞入”实现，不保证和它一模一样。所有者发录屏后可以再对。
- **按住的范围**：栏头和列表行。正文要留给选中文字。
- **上下分栏**：所有者说“自定义”，所以加了每列上下两栏。没有加栏之间拖动改大小。

## 已知限制

- 拖动后 Tab 键的顺序还是打开的先后，不是视觉顺序。改 DOM 顺序会丢滚动位置，所以这轮没改。
- 目标区只对指针可见，读屏软件走“更多”里的移动项。
- 触屏长按没有测过。

## 和 Codex 分支的关系

`codex/perf-memory-20261104` 正在改 `reader.tsx` 的滚动区（第 682–702 行附近）。这轮避开了这些行和 kit 的导入行，新组件从 `@ui/kit/pane-drag` 单独引入。合并时 `agent-ui.js` 需要重新构建。它的 `multi-reader-workload.js` 没有改动，但左右栏移到窗口后脚本的定位必须跟着变，这轮已经改了这个文件，还没有运行。

## 行为与数据含义

- 日明细中没有任何正数用量、总 Token 为零的 `unknown` 模型行隐藏；原始记录、记录数和导出仍保留。具有非零用量的未知模型继续展示与明确标价状态，不能以隐藏替代映射。缺失分类项退出主分类网格，以“未报告：缓存写入”等集中说明；持久层仍为 null，不填零、推算价格或删除记录。
- 趋势浮层及子元素透传指针，取消悬停冻结。鼠标移动、按住拖动查看日期和滚轮都传到画布/页面；超过 6px 的拖动不会在松手时打开日明细，单击与键盘回车仍可打开明细。浮层最多显示六项，更多模型到现有模型明细查看，避免另一个滚动区域。缺失日期和未知费用的原有语义不变。
- Agent / 来源 / 模型是整个用量页的共同筛选，顶部累计、今天卡片、活动、趋势和明细一致。顶部显示具体 Agent 与时间范围，非全量时提供“查看全部”。趋势单独设置日期时显示“自定义范围 · 仅此图”；全局时间按钮仍控制概览，并清除趋势自定义范围。
- 原来的累计 Token / 活跃天数 / 可用来源三块改为大金额下的紧凑 Token、用量记录数、今日相对当前区间已记录日均。记录数不声称消息/请求数。近七天 Token 活动条可选日期进入明细；缺失日期用虚线底标，已记录零有小条，不能把未记录当零。近七天独立于累计/30天/今日概览时间选择，沿用当前 Agent / 来源 / 模型筛选。
- 额度条首次可见时使用已有 820ms cubic-bezier(.42,0,.2,1) 加减速；同条距最近实际播放一分钟后再次进入可重播。短时间重复切页静止，隐藏时停止动效，数值更新从当前视觉进度继续，未知窗口不播放。减少/关闭动态直接呈现最终值。冷却只是呈现状态，不触发请求；自动刷新仍为每分钟、启动默认关闭，保留错误冷却。

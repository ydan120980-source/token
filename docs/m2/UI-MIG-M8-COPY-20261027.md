## 保留边界

标题和数值标签（例如“API 等价估算 · 已计价部分”）、日期范围、比较值、定价依据与单位、模型/Agent 标识、预算自然周期与范围、未定价 Token 数、历史起点和价目映射属于读数或状态，保留。

覆盖缺口、部分未报告、未知/未计入、没有价格、没有记录、未连接额度、预算无法完整判断、空状态、错误和操作结果是状态而非通用说明，保留。删除说明不改变未知≠0、账本不写入、来源字段不可补算等业务约束；它们继续由纯计算与交互测试验证。

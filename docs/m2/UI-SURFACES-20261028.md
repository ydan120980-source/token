# 卡片与底色（Apple 式）、默认页、费用页小字 · 2026-10-28

**状态**：已实现，并用合成数据测试。依据是所有者 2026-10-28 的意见：“每个卡片的边界做的略粗糙，还有卡片和背景颜色的设计，包括所有功能页，全量优化一下，模仿 apple 的卡片边界和颜色设计”，以及“设成默认页，然后继续删费用页小字”。

## 1. 底色分三层，卡片用阴影托起

| 层 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| 窗口底色 `--bg` / `--sidebar` | `#ececee` | `#111112` | 侧栏、标题栏、小组件栏所在的底 |
| 页面 `--panel` | `#f5f5f7` | `#18181a` | 圆角页面面板，即 Apple 的分组背景 |
| 卡片 `--card` | `#ffffff` | `#232326` | 所有卡片和小组件 |
| 填充 `--soft` | `#ebebee` | `#2c2c2f` | 控件轨道、卡片内的块 |

- **卡片边界** `--card-edge`：浅色主题去掉 1 像素细线，改为三层阴影：0.5 像素的极淡轮廓、1 像素贴边阴影、14 像素柔和扩散。深色主题用顶部内高光、极淡外沿和向下的阴影。
- 旧渲染的卡片、费用页的参考模式、kit 的 `Card` 和小组件都读这个 token。kit 的 `Card` 和 `WidgetCard` 原来用 `ring-1 ring-border` 细线，现在改用 `shadow-card`。
- 深色的 `--ff-surface-*` 按同样三层重排。`surface-2` 改为比卡片亮一档的填充，与浅色主题的 `--soft` 用法一致。
- 页面面板和小组件栏之间的间距从 8 加到 16（`--summary-gap`）。
- 文字对比度：`--muted`（`#66676b`）在 `#ececee` 上约 4.9:1，在 `#f5f5f7` 上约 5.3:1，都不低于 4.5:1。

## 2. 默认页

应用启动时打开“概览”。同一会话内重新加载时，仍回到加载前的页面。

## 3. 费用页说明小字

在参考模式内删除以下内容：
- 首屏的“按公开价目，不是账单”；
- 日均事实里的“无记录的日子留空”；每百万 Token 事实的“只按已计价的 Token”；
- 走势图的“轴下短线标出”和“指向图表查看 · 拖动选范围”；
- 按月图的操作提示；
- 计价覆盖里的“未知不按 0 计…”；“涉及模型与说明”改为“涉及模型”；
- 详情页的“未记录的日期不补零”和页脚说明；
- 订阅对照的公式说明；
- 项目与预算的副标题、“仅本机估算，不控制 Agent”、“不随上方选择筛选”、“未知项目不按路径猜测”，以及历史说明句。

保留的是状态和数值，例如“近 14 天”、“已计入 93.1%”、“未定价 N Token · 历史起点 …”。`cost-smoke` 原来断言这些说明存在（M8 按 1:1 对标恢复的），现在改为断言它们不存在。

## 4. 设置 › 小组件

原来行内的输入框会把标签显示在输入框上方，排版很乱。现在“重命名”和“新建布局”都打开一个小 Sheet。

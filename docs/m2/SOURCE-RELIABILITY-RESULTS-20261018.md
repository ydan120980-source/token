## 产品变化

- 设置定价的未计价列表增加可见的下一步摘要与“处理方法”。缺价格、缺字段、缓存写入计费和冲突分别说明；无法从原始文件恢复的历史明确保留未知。
- 费用页计价覆盖可直接打开对应模型的处理方法；帮助内按具体 Agent 提供来源入口，自动展开读取位置并定位焦点。多来源按影响量排序时，来源 ID 与名称保持对应。
- 缓存写入的可选手动费率入口要求先确认实际服务商不收费；套餐或额度不构成零费率依据。界面测试确认设为零后仅费用重新计算，缺失 Token 数量仍为 null，statistics.json 字节不变。
- 修正来源页面无参数重绘清空已保存状态的问题；补充文件忙碌、超时和解析失败的可读提示。
- 计价算法、数据质量保护、桶包含语义、调用身份及自动读取范围不变；没有新增品牌解析器、依赖或后台联网。

## GitHub 公开格式实验

固定 oh-my-pi `076a85e`、Triss `8baae4d` 的公开格式，自行编写合成记录，不复制用户会话、不执行上游程序。两个来源通过现有配置式映射走完预览、应用、Token 与独立金额核对、重复刷新、配置私密导出和重启；共 257 Token、合成费率下 USD 0.000771，与独立算式相符。

Triss 合同允许 call_id 为空，实验明确拒绝此类记录入账。缺稳定身份不生成随机替代。配置示例不含路径或样本身份，需用户重新选择本机目录并预览。这是固定结构的合成兼容证据，不等同真实安装、所有 provider 或所有版本的兼容验收。

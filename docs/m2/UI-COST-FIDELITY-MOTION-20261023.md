# 费用页交接完成与图表提示稳定性（2026-10-23）

## 所有者要求与范围

接续 `UI-COST-V2-20261023.md`。所有者本次明确要求开始处理此前的候选，并指定：

- 主体沿用 A，范围栏和日历沿用 C，范围与日历分别可以展开、收起；
- 订阅卡片和章节过渡沿用 B；
- Agent / 模型明细使用 A 的侧滑详情，整合现有真实字段；
- 本次明确选择**左侧**详情层；A 原型实际从右侧进入，因此这里只镜像进入方向和拖动方向；
- 额度时间线和费用走势提示统一到用量趋势的表现，修复重绘、快速移动时的闪烁；
- 修复环形图端点覆盖、长订阅名、半宽计价覆盖、缓存展开过长，并检查窄窗口、深色和键盘操作。

这是现有原生 HTML/CSS/classic JS 渲染层的维护。没有 React 替换、新依赖、读取范围或账号能力扩展。单主线程实施，没有创建或续跑子代理。未恢复已撤回的色板 / 字号等 UI 改动。

## 实现

### 图表提示

- 额度与费用提示使用与用量趋势相同的 `.chart-tooltip` 浮层材质、主题颜色及 90ms 位置缓动；入场复用 `uiMotion.enter(..., 'tooltip')`，完整动效淡入 100ms，减少动态淡入 150ms，关闭动效立即显示。
- 同一次进入只播放一次淡入；切换日期或额度轨道只更新内容与坐标。相同内容保留原节点。
- 十个 Agent 的高提示框不再被折叠图表或卡片裁切，位置同时受当前视口约束；只有图表高度正在展开 / 收起时临时裁切图形，高度过渡结束或取消后恢复。
- `data-chart-tooltip` 标记的空模板槽交由悬停状态维护，`uiMorph` 不用模板中的空内容、hidden、class 和 style 覆盖它；费用光标与额度轨道在内存重绘后恢复到当前项目。
- 离开、Esc、滚动、视图清理时关闭提示。浮层不参与指针命中，避免挡住底下的轨道和图表。
- 录屏附件路径在本次执行环境中不存在，因此没有逐帧复现原录屏。源码确认了重绘会覆盖提示状态的路径；本次用合成数据的真实鼠标、键盘和强制重绘证明修复后的稳定性，不把它表述为原录屏唯一根因已确诊。

### A 的左侧详情

- 宽 400px、距窗口边缘 12px、圆角 22px；420ms、`cubic-bezier(.32,.72,0,1)` 的横向进入。沿用现有 price-editor 的 surface 与原生 dialog 行为。
- Agent 和模型共用同一详情层：估算上下限、Token、占比、每百万 Token、缓存命中 / 约省下、日均、较前期、用量构成；保留计费依据、未计入原因、模型 / 使用方列表、每日 Token、计费编辑、复制和用量跳转等适用操作。
- 长名称完整换行；模型 / 使用方长列表独立限高且可用键盘滚动；详情层整体受窗口高度约束。
- Esc、关闭按钮、遮罩以及向左拖动边缘均可关闭；拖动保留位移和速度阈值。关闭先清理选择状态，避免尺寸重绘重新打开详情；焦点返回原行。
- 原精简图表的 Esc 逻辑会寻找它并不拥有的“收起图表”按钮；现在清理图表提示并请求关闭所在详情层，保留完整图表原来的返回折叠按钮行为。

### B / C 以及紧凑核对

- B 的订阅倍数字号 56px，章节入场 700ms / 18px，比较条填充 1100ms，均由 tokens.css 管理；减少动态 / 关闭动效按全局设置生效。
- 订阅名称可以换行，较窄卡片把月费放到名称下方，避免挤掉名称；仍是原有本机月费保存接口。
- 订阅卡片外层去掉旧 card 的边框和重复内边距，对齐 B 的独立卡片结构。
- 最终截图复查还确认了通用 `.cost-block > .card` 的选择器优先级：订阅外层用同等优先级的专用规则覆盖阴影，并以实际 computed boxShadow 断言防止外框回归。
- 窄窗口保留 C 的横排范围 / Agent 设计；在适合两列的窄宽度下，将“只看未计入”放在 Agent 下方，减少额外空行。范围与日历的折叠及记忆保持不变。
- 环形图按悬停时的最大线宽预留圆头间距，并把每个扇区限制在自己的角度内，防止邻接覆盖；极小扇区仍由对应列表行保留金额和占比。
- 计价覆盖改成 96px 圆环 + 关键摘要，步骤占下面的整行；模型与原因说明可按项展开。只有未计入 Token 确实为 0 时才显示“全部 Token 已计入”。
- 覆盖和缓存卡片按各自内容高度排列。缓存展开后保留所有行，在 380px 列表中滚动；切换按钮提供 aria-expanded / controls，列表可聚焦。
- 额度旧读数不再整块降低到 .55 透明度；改用已有 muted 文本色。过期说明、状态和时间仍然可见，数据语义不变。

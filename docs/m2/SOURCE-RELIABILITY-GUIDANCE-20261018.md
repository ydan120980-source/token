# 来源可靠性与未计价处理指引（2026-10-18）

所有者授权继续真实来源覆盖、连续运行/故障恢复、未计入估算的可操作诊断；自定义来源另授权从 GitHub 公开格式选样实验。主线程独立实施，无委派。

- 已批准内置来源只经 validate:local 做只读、聚合报告的核对；不读取认证、不改来源文件或应用日常数据。OpenCode 使用既有只读内存 SQLite 镜像及 WAL 处理，在 SQL 层限定样本行数和用量投影，不导出正文；原 JSON 64 MiB 抽样上限保持，数据库镜像仍服从产品既有大小与时间限制。
- Antigravity 模型配对只验证明确同数且可解码的样本，缺库、变化、数量不同保持未验证，不推断多余调用的模型。
- GitHub 格式实验固定仓库版本，按公开结构编写独立合成记录与字段映射。不运行第三方代码，不导入公开用户的会话正文，不新增品牌解析器；结果称公开格式兼容实验，不称本机真实自定义来源验收。
- 未计价列表提供可见原因、处理步骤、不能恢复历史的限制和匹配的来源/计费入口；缺字段与缺价格分开。未知不补零，不撤销冲突保护，不自动修改费率或调用身份。
- 稳定性检查使用隔离的 usage/quota 与合成 home，验证刷新、追加、截断、取消、失败恢复、重启和费用投影一致性。真实与合成证据分开。
- 只提交代码、文档和验证记录，不生成 dist 交付代次、源码 ZIP 或运行候选，不同步 GitHub，不启动其他工作台阶段。

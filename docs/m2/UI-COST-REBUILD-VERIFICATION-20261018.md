# 费用整页重构：源码验收（2026-10-18）

本轮依据 `UI-COST-REBUILD-20261018.md`，从本地 main `622ab78` 的独立 worktree 开始；方向提交 `9b96d85`。费用页的分析、月份、订阅、展开明细、覆盖、缓存、项目预算和维护操作共同检查。

## 复现与修复

| 实际问题 | 处理 |
|---|---|
| 月度大幅环比会与“已计入”数字挤在一起 | 明确每列的可用宽度，数字可换行，窄窗口换成分行的月份信息；不以 `overflow:hidden` 隐藏错误 |
| 展开明细依赖三列固定布局，字段、长名称和费率挤压 | 改为可重排的两列/单列明细，完整模型名独立展示；紧凑列表隐藏的次级指标在展开区始终可查看 |
| 手动输入每百万 `$30` 的价格，明细显示 `$30,000,000` | `uiPricingEditor.model().rates` 已是每百万费率，移除重复的 `×1e6`；增加 UI 精确断言。计价核心与账本未改 |
| 多层样式按 `nth-child` 隐藏费用列，标题与数据容易失配 | 费用页集中管理自己的容器规则与命名网格区域，移除 `containers.css` 内旧费用覆盖规则 |
| 卡片圆角、边缘与分节字体不统一 | 对照用量页实际样式，统一字体家族、大小、字重、行高、文字色、卡片圆角、阴影和表面色；保持共同设计 token |
| 按月与缓存列表只显示固定前几项，缺少继续查看的入口 | 新增较早月份及全部缓存模型的展开/收起；缓存未知记录也可完整查看，长名称提供完整提示 |
| 紧凑构成表直接隐藏 Token 与费率 | 次级值换到第二行，并明确标注 Token / 每百万；方格中不足一格的非零估算区间写“不足 1 格” |
| 订阅未设置时只有一条无解释的横线 | 显示“填写月费后查看对照”；保留本机月费编辑、倍数、失败恢复和持久化行为 |

费用构成、覆盖和缓存采用同一组分类色或中性灰；不把用量多少着色为好坏。费用卡片按内容高度排列，避免左边月表因右边列表更长而产生大块空白。用量页本身未重做。

## 趋势图与参考对照

新增 `cost-chart.js` 的纯几何与 `cost-chart-ui.js` 的共享图形组件。费用页原来的简易折线替换为以下实现：

- 以所有者提供的图中内层图表为目标，标准尺寸 **446×218**；参考裁剪区域为原图 `(72,15)–(518,233)`，不包含外层窗口投影。
- 线色采样为 **`#07836B`**，表面为 `#FAFAFA`；圆滑单调三次曲线、渐隐填充、四条网格、四个日期标签、末端点与金额采用同一几何坐标。
- 概览默认显示最近七天的每日已计价费用；累计估算趋势仍可展开查看。明细中末段七天和完整范围走势都保留，完整范围至多展示 90 个观测位置，横轴标签最多四个。
- 支持鼠标查看日期/数值、方向键/Home/End 切点、Escape 返回收起按钮；收起状态在同次运行的采集刷新后保持。图表入口复用既有输入法保护。
- 未报告日期断开曲线，已知零仍在基线上，小额非零刻度不显示为零。金额区间与“已计价部分”在读数中保留；不推断未记录日等于零。

参考曲线的中间数值由图片重建，末端 `$31.84` 来自可见标注。100% 渲染的七点合成场景中，比较 369 列实色曲线像素：平均垂直差约 **0.48 px**，最大 **1.5 px**。完整图像的像素差并非零，字体栅格化和插值细节仍有差异；不以“尺寸和色值相同”宣称整张原图逐像素相同。实际用量曲线始终来自账本，不套用参考图的合成数值。

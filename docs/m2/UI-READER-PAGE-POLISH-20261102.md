# 阅读视图进页面，会话行和费用页修整 · 2026-11-02

**状态**：所有者 2026-11-02 看过界面后提出的修改。已实现，只用合成数据在源码模式下核对过；没有打包验收，也没有用真实数据核对。

## 所有者的要求和做法

| 要求 | 做法 |
|---|---|
| 费用页和会话页的详情卡片改成左右滑入 | 所有贴边的 `Sheet` 从自己那一侧滑入滑出，不再原地放大。居中的弹窗不变。减少动画时只淡入淡出。 |
| 费用明细排版有问题，“构成”快被压没了 | “构成”固定 80px 宽；金额和备注不换行；模型名一行显示，过长时按下面的规则滑动；表格改用紧凑行距，让 1440 宽且开着概要栏时也放得下，不必横向滚动。 |
| “花在哪”下方的 Agent 划不动，订阅对照也划不动 | 原因是面板固定 408px 高并裁掉溢出内容，里面又没有可滚动的区域。`PaneGroup` 的内容区现在可以滚动，放不下时边缘淡出；滚到头后滚轮继续带动整页。去掉了图例里套着的那层滚动区。 |
| 阅读对话不要做成弹窗，给足空间 | 所有者给了两个选择，这里选嵌入主页面，理由见下。 |
| 每个会话的横排内容太多，文字显示不全，删掉没用的 | 会话行只留：Agent 图标、名称、最近活动时间、Token、估算、阅读和复制恢复命令。删掉的模型、会话 ID、持续时间和打开目录都还在详情卡片里；项目行删掉路径和模型汇总，路径放在悬停提示里，打开目录和复制路径的按钮保留。 |
| 会话名字太长时两侧淡出，悬停时慢速匀速滑动 | 新增 kit 组件 `Marquee`：放不下时结尾淡出；鼠标指向或键盘聚焦时，停 0.5 秒后以每秒 32px 匀速循环滑动，这时左右两侧都淡出；离开后回到开头。减少动画时不滑动，完整文字在悬停提示里。 |

静止时左侧不淡出，否则会盖住名字的第一个字；开始滑动后两侧才都淡出。这一点和“左右两侧”的字面要求略有不同。

## 为什么嵌入页面，不单开窗口

- **不增加新的边界**：单开窗口要多一个渲染进程，还要重新处理 preload、统计通道、主题同步和窗口生命周期，阅读记录的 IPC 也要多放开一个发送方。嵌入页面沿用现有的发送方校验，不新增任何通道。
- **空间足够**：阅读时右侧概要栏让开（只是隐藏，所有者的显示设置不变），内容区在 1440 宽窗口里约 1208px，正文最宽 1024px。
- **“只显示不保存”不变**：离开阅读视图时对话内容随组件卸载释放。切到别的页面再回来，会重新读取记录。

如果以后仍然想要独立窗口，需要单独决定，并重新核对上面的 IPC 边界。

## 阅读视图的行为

- 占满页面，顶部一行放返回、Agent、名称和轮次，以及目录、导出和查找；对话在下面单独滚动，目录固定在左侧。
- 打开时从右侧滑入，返回时列表从左侧滑入，并回到原来的滚动位置，焦点回到打开它的那一行。
- `Esc` 先清空查找，再按一次返回列表；正在用输入法选字时不处理。

## 核对

合成探针 `probe20`（1440 深色、1180 浅色）：

- **滑入**：费用和会话详情卡片打开时，水平位置从窗口外 -468px 一路移到 16px，宽度不变。
- **费用明细**：“构成”80px，金额都是一行，1440 宽时表格 814 / 814、1180 宽时 843 / 843，都没有横向滚动。
- **花在哪**：费用构成内容 560px、可见 368px，能滚到最后一项；订阅对照内容 899px，真实滚轮滚动了 300px，页面本身没动。
- **阅读视图**：页面上没有 dialog；页面 1208×878，整页不滚动，对话内部滚动；概要栏隐藏；目录跳转落在目标轮的顶部（偏差 0）；返回后列表回到 120px 的滚动位置，焦点在“阅读对话”按钮上。
- **名称滑动**：悬停约 0.5 秒后开始，位移每约 370ms 增加 12px，即每秒 32px。
- **控制台**：没有页面错误。

界面套件（源码模式）通过：sessions、cost、cost-smoke、cost-composition、cost-layout、widgets、overview、ui-mkb-gallery。没有跑其余套件；`interaction-reliability` 只改了选择器，没有运行。

贴在窗口边上的 `Sheet` 用新增的 `spring.edge`（节奏与 `spring.slow` 相同，不回弹），否则回弹时它会离开窗口边缘；浮动的详情卡片仍用 `spring.slow`。

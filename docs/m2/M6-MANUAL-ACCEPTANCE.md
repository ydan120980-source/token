# QuotaDock M6 真机实测核对单

使用待审阅的 Tauri NSIS 包和对应的 SHA-256 回执。记录测试日期、Windows 版本、显示缩放、Tauri 应用版本和前一安装版本。每项记为通过、失败或未测。提交截图和日志前遮盖账号名、设备码、仓库名和会话内容。手动安装预览的回执标为 `manual-preview`。

| 验收项 | 实机操作 | 通过条件 |
| --- | --- | --- |
| GitHub 设备授权 | 用获准的 GitHub App 完成设备登录，选择自己拥有且允许该 App 写入的私有测试仓库，点击立即同步 | 设备码只在授权期间出现。仓库中生成本机的汇总文件，内容仅包含约定的日期、内置 Agent、模型、用量和金额字段。断开账号后本地授权失效 |
| Windows 手动升级 | 使用隔离安装身份运行上一 Tauri 版本。核对预览 NSIS 的 SHA-256，退出旧版后手动覆盖安装 | 启动版本正确，应用自有账本、偏好和可续期授权恢复 |
| Windows 静默升级（签名通道） | 使用隔离安装身份运行上一 Tauri 版本，从测试更新源下载已签名的完整 NSIS 包，点击重启并更新 | 下载显示进度，安装过程无需交互，重新启动正确版本并恢复原应用状态。此项随签名通道单独验收 |
| Windows 开机自启 | 初次启动核对开机自启默认为关闭。开启后注销并重新登录 Windows，然后关闭开关再复测 | 开启时只启动托盘，未打开主窗口。关闭后重新登录时应用不再自启。Electron 的登录项不受影响 |
| 系统通知 | 允许 Windows 通知。用有授权的额度账号触发一次阈值或需要重登的提醒，点击通知 | Windows 显示通知，点击后进入对应页面。同一状态连续刷新不重复提醒 |
| 供应商登录与安装 | 在设置中逐项启动受支持的网页登录、设备授权和官方 CLI 路线。选一个受支持工具走应用自有目录的安装、检测及取消流程 | 返回的是同一账户的已验证读数。重启后可按路由规则恢复，取消后受管子进程退出。记录各路线实测结果 |
| Electron 回退 | 在隔离测试目录保留旧版状态，完成 Tauri 手动导入。关闭或卸载 Tauri 后用原安装身份重新打开 Electron v0.1.8 | Tauri 恢复获准重封的凭据，无法继承的账户提示重新登录。Electron 旧目录与导入前的逐文件 SHA-256 一致，原程序正常读取 |

正式交付包信息及自动化验收状态随 [迁移计划](../../MIGRATION_PLAN.md) 更新。

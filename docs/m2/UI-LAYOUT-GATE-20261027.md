# 页面对照门槛（逐像素） · 2026-10-27

**适用范围**（所有者 2026-10-27 更正，`UI-UNIFY-COST-REFERENCE-20261027.md` 第 4 节）：工具和流程分两种用途：
- **本步不改的页面**：必须和改动前逐像素一致。适用于 M8、M7 及之后任何渲染层改动里没有迁移的页面，以及不打算改变外观的改动。
- **本步迁移的页面**：迁移目标是统一到模板库和费用页，不再要求与旧版一致。它的图对只用来出前后对照图交 Claude 审核，不作通过条件，也不需要列进允许差异。

**要求**：每个页面、每个交互状态、浅色和深色两种主题都要拍、都要比。

## 1. 工具

`scripts/m1/ui-pixel-gate.js`：

```text
node scripts/m1/ui-pixel-gate.js capture <checkout> <out> [--views usage,cost] [--themes light,dark] [--size 1180x850] [--scenes <file> --side before|after]
node scripts/m1/ui-pixel-gate.js compare <before> <after> <out> [--budget 0.002] [--approved <file>]
```

**capture 怎么拍**：
- 从任意检出（旧版或新版）启动应用，所有检出用同一份条件：
  - 同一份合成数据：用量来自 `tests/m1/ui-style-fixture.js`，额度来自 `tests/m1/quota-hero-fixture.js`；
  - 渲染层和数据都冻结在 2026-10-26T11:51:00Z；
  - 暂停采集，动效设为关闭。
- 每个页面拍三种图：
  - `top.png`：窗口刚打开时的样子；
  - `page.png`：把整页放进一个高视口拍下，固定元素在它们真实的位置；
  - 每个场景一张 `scene-<名称>.png`。
- 主进程时钟产生的日期时间文字（文件变化时间、检查时间）两边用同样的色块遮住。除此之外不得遮挡或隐藏任何内容。

**compare 怎么比**：
- 逐像素比较，每个颜色通道差 24/255 以内视为抗锯齿误差。
- 一对图通过的条件：尺寸完全相同，且差异像素占比不超过预算（默认 0.2%）。
- 每对图都输出一张差异图（红色是不同的像素），并汇总成 `report.md` 和 `report.json`。

## 2. 流程（每个迁移步骤）

1. **基线**：开始实现前，从本地 main 的干净检出拍基线：
   ```text
   capture <main> artifacts/ui-gate/<步骤>/before --views usage,cost,quota,sessions,sources,settings
   ```
   每种尺寸各拍一次：`1180x850` 和 `1440x900`。场景照第 4 节，用 `--side before`。
2. **候选**：在自己的分支上实现，用同样的参数拍 `after`，场景用 `--side after`。
3. **比较**：
   ```text
   compare before after artifacts/ui-gate/<步骤>/diff --approved docs/m2/ui-gate/<步骤>-approved.json
   ```
   - 不通过的图对必须修到通过。
   - 不得调大预算、增加遮挡或删除图对。
4. **其他页面**：迁移的页面以外，所有页面的图对都必须原样通过。这一步证明没有动到共用样式。
5. **记录**：把 `report.md` 抄进该步骤的页面记录，并写明基线和候选的提交号、尺寸和主题。

## 3. 允许的差异

只有下面两类差异可以列进 `docs/m2/ui-gate/<步骤>-approved.json`：
- 裁决记录批准过的文案或语义修改。例如 G2 把“—”改为“未知”，或 G3 的 S1–S9。
- 图表换实现后无法消除的抗锯齿差异。前提是线条和柱子的位置与旧版相差不超过 1 像素。

条目格式：`{ "<图名>": "<理由，引用裁决条款>" }`。

审批规则：
- 列表由 Codex 起草，Claude 逐条看过并列的前后两张图后批准。
- Codex 不得自己批准，也不得先合入再补批准。
- 没有列在里面的差异一律当作缺陷处理。

## 4. 必拍场景

场景文件放在 `docs/m2/ui-gate/<步骤>-scenes.json`。同一个场景要给旧版和新版各写一组步骤：
- `before` 写旧版 DOM 的选择器，`after` 写新版的；
- 两组步骤必须到达同一个状态；
- 截图之前不得移动鼠标去触发悬停。

**M7 用量**：
- 四个时间范围：累计、30 天、7 天、今日。
- 近 30 天条带：选中最后一天，展开日明细。
- 活动日历：
  - 选中一天，看小时格；
  - 切换年份；
  - 切换配色（橙、蓝、绿、单色各一张）。
- 用量趋势：
  - 构成、总量、模型三种模式；
  - Token、费用两种指标；
  - 每日、30 日均、累加三种数值；
  - 日期范围弹层打开；
  - Agent 筛选选中一个 Agent；
  - 按键盘方向键选中一点后的读数。
- 今日表格展开会话。

**M8 费用**：
- 时间范围：累计、30 天、7 天、今日，以及日历选一个区间。
- 日期范围侧栏打开。
- Agent 筛选选中一个 Agent。
- 花在哪：费用构成、订阅对照两个页签。
- 按月区块放大到整行。
- 费用明细：按模型、按 Agent 两种分组；打开一行的明细侧页。
- 计价覆盖、缓存两个区块。
- 项目与预算：项目列表展开一个项目；预算表单有值、无值各一张。
- “明细只看未计入”勾选。

场景名用英文小写加连字符，例如 `trend-models`、`cost-sheet`。

项目聚合金额使用费用页的两位小数显示；非零且小于半美分显示 `<$0.01`。预算阈值属于用户配置，保留六位以内的精细显示，更小的非零阈值显示 `<$0.000001`。不改变底层值、预算比较或导出数值，也不把小额、未知或未报告填成零。

界面仍为原有静态 HTML/CSS/JS，无依赖变化。新增视觉取值在 `design/desktop-reference/tokens.css`；预算选择器通过显式 `data-insight-control` 复用共同组件，自定义来源映射控件继续使用原有方式。费用样式保持 `#cost` 限定，避免影响用量页同名类。

测试均使用合成 home、独立 usage/quota 目录，未读取真实 Agent 来源。证据位于本地未跟踪目录 `artifacts/ui-style-alignment-20261018/`，不是正式交付包。

- `npm run verify`：ESLint 通过，单元测试 `fail 0`。
- `npm run audit:runtime`：通过。
- 新增 `scripts/m1/style-alignment-ui-test.js`：浅色/深色、100%/150%、1280×900 和 800×600；比较费用与用量分段按钮的实际样式，验证预算主操作颜色、选择浮层鼠标与键盘、Escape 后焦点、弹窗、无横向溢出、预算保存后账本字节不变。用量、费用分析、项目预算、来源详情、会话面板和处理指引均有截图。
- 受影响源码界面套件：cost、workbench、custom-sources、sessions、unpriced-guidance、interaction-reliability、functional；均通过。覆盖费用范围与编辑、向导、预算失败恢复、导出、会话未知项目、输入法合成事件保护、滚动打断、原生对话框返回焦点、减少动态效果与窄窗口。
- workbench 另核对小于一美分的费用展示以及 `$0.001` 预算阈值保留精度；重新估算、失败后重试和账本不改写继续通过。

截图对照保留 `before/` 与 `final/`；最终同时检查浅色费用和预算、深色费用构成及会话面板、来源字段覆盖、处理指引和窄窗口费用分析。原始截图与合成数据的数字、时间、会话信息不同；共同组件的实际样式一致通过断言验证，不能由此宣称原图逐像素一致。

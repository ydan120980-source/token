## 详情面板

每个连接一段，从上到下依次是：

1. 名称和状态（需要处理时显示警示圆点）。
2. **三个关键数**：
   - 主数字：第一个窗口的剩余，或钱包合计；
   - 接下来：最近一次重置、恢复或到期；
   - 最近成功读取：多久之前，悬停显示具体时刻；超过 1 天显示警示色。
3. 出错说明，以及 WorkBuddy 的精确合计（沿用原有的 `.quota-sheet-total`）。
4. **资源**：
   - 积分包很多时（没有百分比窗口，且金额项超过 6 个），不再按包逐个罗列，而是按到期时间分三组。组标题写个数和精确合计（BigInt 小数相加，与卡片规则一致）：
     - 7 天内到期；
     - 可用：按到期先后排，前 5 个直接显示，其余收进"另外 N 项"；
     - 已到期、冻结或不可用：整组默认折叠。
   - 其他情况仍按资源池分组，每组超过 8 项时折叠。
   - 每一行在已知占比时有一条细条：百分比，或剩余 / 总量。
5. **连接**：套餐、有效期、最近尝试、保持登录、重复连接说明和操作按钮，元素与原来相同。
6. 卡片设置：名称、前移 / 后移、隐藏，保持可见，不折叠。

同一 Agent 有多个连接时，面板顶部列出各连接名称，点击即跳到对应的一段；需要处理的连接用警示色。面板使用该 Agent 的色调。

## 卡片

- **筛选**：卡片区上方是"全部 / 需要处理 / 正常"三档，各带数量，选择保存在本机卡片偏好里。
  - 已隐藏的卡片不受筛选影响，仍然隐藏。
  - 某一档没有卡片时，显示一行说明。
  - 点击"需要处理 N"会依次定位卡片；如果当前停在"正常"，会先切回"全部"。
- **整卡点击**：点击卡片上按钮以外的任何位置都会打开详情。按住拖动、刚拖完松手、或正在选中文字时不会打开。
- **长按拖动**：
  - 按住 350 毫秒拿起卡片；移动超过 6px 就不算长按。
  - 拿起的卡片跟随指针，带浮层阴影。经过其他卡片时，那张卡片让出位置；完整动效模式下以 180 毫秒滑动过去。
  - 松手后保存顺序，Esc 放回原位。
  - 目标位置按卡片的布局位置判断，不按画面上的位置，所以正在滑动的卡片不会影响落点。
- **键盘**：焦点在卡片内时，按 Alt + 方向键前后移动一位，状态栏读出"已移到第 N 位"。
- 筛选掉或已隐藏的卡片，在保存的顺序里保持原位。
- 这些顺序、筛选、时间线范围都是本机显示偏好，存在 `agentusage.quotaCards.v1` 中，不改变任何连接或额度。

## 新增测试

`scripts/m1/quota-v4-ui-test.js` 覆盖了第二步和第三步。它启动真实 Electron 窗口，使用隔离的合成目录，并在主进程把三个额度读取接口替换为合成连接；不使用凭据，也不请求服务商。在 100% 深色和 150% 浅色两种设置下各跑一次。

断言的内容：

- **页面顶部**：
  - 显示"最快恢复"；
  - 泳道条数正确，待刷新的窗口合并为一条；
  - 时间线范围的选择会保存，超出范围的重置写在条尾。
- **需要处理条**：两个连接，各带修复按钮。
- **卡片**：
  - 合并卡带有全部成员的编号，写"1 / 2 个连接需要处理"，有两张票据，合计"3,114 积分"，显示"7 天内到期 120 积分"；
  - 出错卡显示需要处理的形态；空卡写明"这不代表额度为 0"；
  - Codex 卡有两条时间刻度，显示节奏判断，额度条使用 Codex 色调。
- **筛选**：每一档显示的卡片正确，选择会保存；点击需要处理条时会先清除当前筛选。
- **整卡点击打开的详情面板**：
  - 顶部有连接切换；
  - 三个关键数；
  - 两个分组，标题带精确合计；
  - 两处折叠；
  - 每行按包名显示。
- **长按拖动**：拖到第三位并保存；拖完松手不会打开详情；Esc 取消拖动；Alt + 方向键移动后读出位置。
- 页面没有横向溢出，每张卡片的内容都没有被裁切，页面没有报错，usage 和 Codex 缓存的字节不变。

开发过程中修了两处问题：

- **拖动落点不准**：起初用"指针下面画着哪张卡"来判断目标，被挤开的卡片正在滑动时会判错位置，新套件因此首轮失败。改为按卡片的布局位置判断，并给卡片区加 `position: relative` 作为测量基准。
- **详情面板一打开就滚过了标题**：原因是打开时把目标连接那一段滚动到视野内。改为只有目标不是第一段时才滚动。

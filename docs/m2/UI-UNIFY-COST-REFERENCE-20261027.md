# 迁移目标更正：统一到模板库，费用页补位 · 2026-10-27

**状态**：所有者 2026-10-27 决定，Claude 记录。先 M8 后 M7、设置页不放摘要两项由所有者当日确认。本记录替代第 7 节列出的条款；其余迁移规范、裁决和数据语义照旧。

## 0. 所有者决定

| 项 | 决定 |
|---|---|
| 迁移目标 | 撤回“让 Codex 逐像素还原旧版”。现有各页的界面和动效本来就不统一，重写成 React 时先用确定的模板库统一，不再照搬各页旧样子。 |
| 统一的依据 | 模板库是 fluid-functionalism（经 `ui/src/kit/`）。模板库没有的部分，向费用页现在的界面和动效对齐。 |
| 摘要栏 | 右侧摘要栏加到全部页面（设置页除外），显示每个功能页的缩减精华，不是新功能。 |
| 额度页 | 先保留接口和外排版，等新设计定下后再重做；在此之前不做设计改动。 |

## 1. 依据的优先顺序

1. 模板库有的，用模板库：按钮、分段、下拉、菜单、开关、输入、Sheet、展开收起、表格、徽标、横幅、提示。
2. 模板库没有的，照费用页：图表、读数和图例、大数字滚动、首屏翻页、两栏展开收起、Agent 图标筛选、日期范围层。依据 `UI-COST-V3-20261024.md`、`UI-COST-HERO-20261024.md`、`cost-page.js`、`cost-hero.js`、`cost-donut.js`、`cost-bars.js`。
3. 两边都没有的：停下来提问（计划第 9.4 节）。

## 2. 不变的部分

- 功能、数据、操作、状态、键盘。
- 数据语义：未知≠0、不跨 Agent 相加、精确小数、部分数据标记。
- 文案按 G5：统一引出的新文案先交 Claude 审。
- Host 接口、事件、本机偏好格式、测试钩子。

  - 每个读数都有键盘等价操作。
  - 替代 UI-SPEC 第 7 节和裁决 G6 前两条。
- **数据动效**（`ui/src/design/motion.ts` 已改，数值取自 `cost-bars.js`、`cost-donut.js`、`motion.js`）：
  - 入场 0.8s，变化 0.5s，缓动 `cubic-bezier(0.23, 1, 0.32, 1)`；
  - 错开每个 0.04s，上限 0.4s；
  - 形状切换从当前几何继续，可以打断；

  - 弧段 16px 圆头，段间 3.5px，指向时 20px；

  - 图表视图切换用分段按钮；
  - Agent 筛选全站用图标条（替代 M7 Q3 的 chip）；
  - 可翻页的首屏照费用首屏。

## 4. 迁移顺序和门槛

- **先 M8（费用）后 M7（用量）**：参照页先进 kit，图表组件按它调准；M8 不依赖 M7（M8 盘点第 56 行）。
- **M8**：图表、读数、首屏、两栏的外观和动效保持现状；控件换成 kit 后按 kit 的样子。差异逐项列出交审。
- **M7**：按第 1、3 节统一，不要求与旧版一致。
- **逐像素门槛改为两种用途**：
  - 本步不改的页面必须原样通过；
  - 迁移的页面只出前后对照图，供审核，不作通过条件。

## 5. 摘要栏（全站）

> **2026-10-27 稍后，已被替代**：所有者把按页面的摘要栏改为一个可自定义、不绑定页面的小组件侧栏，见 `UI-PALETTE-QUOTA-SUMMARY-PROPOSAL-20261027.md`。本节的位置和尺寸仍然有效，内容部分作废。

**规则**：
- 每页放自己的精华；没有内容的页面不显示标题栏按钮。
- 只读加跳转，不放页面上没有的操作。
- 每页 2–4 节，读同一份 Host 数据，未知显示“未知”。
- 用统一的摘要组件，随该页的迁移交付。

| 页面 | 精华（草案，随该页迁移交 Claude 定稿） |
|---|---|
| 额度 | 下一次恢复；需要处理；未连接的 Agent（已有） |
| 费用 | 本月至今估算和推算整月；范围内花得最多的 Agent（各自金额，不相加）；未计入提醒 |
| 用量 | 今天各 Agent 的 Token；近 7 天走势小图；进行中的会话数 |
| 会话 | 进行中的会话；最近 3 个会话 |
| 来源 | 需要处理的来源；上次采集时间和状态 |
| 设置 | 不放（所有者 2026-10-27），设置页不显示标题栏按钮 |

**接入方式**（外框已有，见 `UI-LAYOUT-SPEC-20261027.md` 第 1 节）：
- 页面把自己的视图名加进 `#summaryPanel` 的 `data-summary-views`；
- 在 `#summaryPanel` 里放自己的岛 `<div data-island-host="<page>-summary">`，只在该页是当前视图时渲染内容；
- 提醒圆点用 `window.uiShell.summaryAttention(count, label)`。

## 2. 配色 C 的取值

Agent 色。浅色主题用 OKLCH L≈0.645、C≈0.155，按色相排开；深色主题明度更高、彩度更低。

| Agent | 浅色 | 深色 |
|---|---|---|
| Claude Code | `#da673d` | `#f29676` |
| MiMo Code | `#d98800` | `#f2b366` |
| Antigravity | `#61b44f` | `#93d585` |
| WorkBuddy | `#19ad84` | `#6ecdab` |
| ZCode | `#00a5be` | `#33c6d9` |
| Codex | `#3391e7` | `#73b6fa` |

| Gemini CLI | `#c665b1` | `#e292cf` |
| OpenCode | `#82868e` | `#a6abb3` |

- 蓝的深浅（类型、单色模式）：浅色 `#1e579f #487bc0 #75a1dc #a5c7f5 #cbe0fc`；深色 `#afd4ff #81ade9 #5d88c2 #3f6496 #2d496d`。
- 落到 token 上：`--agent-*` 和 `--series-*` 都改成上表的值，合成一套，旧名称先作为别名保留；`--input/--output/--read/--write/--reason` 和 `--category-*` 用蓝的深浅；`--cost-chart-color` 改为墨色。
- 状态色（warn 等）不变。颜色只表示是哪个 Agent，不表示好坏。
- 对比度：浅色主题下 Agent 色对白底是 2.6–3.9:1，MiMo、Antigravity、WorkBuddy、ZCode 低于 3:1。这几种颜色总是和名称、图标一起出现，不单靠颜色传达意思。

## 4. 小组件侧栏

**位置**：沿用 `UI-LAYOUT-SPEC-20261027.md` 第 1 节，宽 304；窗口宽度 ≥ 1120 时固定在右侧，更窄时浮在页面上方。每个页面显示同一套小组件，设置页不显示侧栏。

**顶部**：标题、布局切换（如“日常”）、“编辑”按钮。

**编辑方式**：

| 操作 | 方式 |
|---|---|
| 排序 | 拖动 ⠿；键盘上聚焦 ⠿ 后按 Alt + ↑↓ |
| 尺寸 | S / M / L |
| 设置 | ⚙ 打开，可改颜色（跟随 Agent / 单色 / 墨色）、背景（默认 / 浅灰 / 着色 / 反色）和范围（Agent、时间，不受当前页面筛选影响）；额度窗口还可以选“在标题栏显示读数” |
| 移除 | ✕ |
| 添加 | 打开组件库，按分类浏览，预览就是实际的样子 |
| 布局 | 可以保存多套，在“设置 › 侧栏”里管理，也可以恢复默认 |

**小组件库**：13 个，每个用一种自己的图形，避免第一版里“数字 + 分段条 + 每天小柱”在多个摘要里重复出现。第三版在图形下面恢复了第一版的**文字说明和明细行**：带箭头的行点开后在原位展开，展开内容包括模型、费用类型构成、按 Agent 拆分、原因说明等；会话小组件则是直接点会话本身展开。

**数据规则**：

- 只读本机已保存的数据，不新增数据来源。
- 未知显示“未知”，未计价不显示 $0，额度不跨账号相加。
- 对比胶囊（如“比上月同期 ↑12%”）用中性色，不用红绿表示好坏。
- “采集中”只表示采集的状态，不暗示数据是实时推送的。
- Agent 图里的连线表示“这台机器读取了这个 Agent 的数据”以及连接状态，**不是**调用关系；应用不采集调用关系，编排也不在当前范围内。
- 漏斗图没有采用：现有数据里没有天然的漏斗关系。

**动效**：都用现有档位。

| 场景 | 动效 |
|---|---|
| 进入编辑 | 工具条依次出现，`spring.fast`，错开 30ms；不抖动 |
| 排序 | 拖动时让位用 `spring.moderate`（FLIP） |
| 改尺寸、移除 | 高度变化用 `spring.moderate` |
| 改颜色、背景 | 0.2s 渐变 |
| 添加 | 新小组件用 `data.enter` 淡入，图形依次展开 |
| 图表入场 | 0.8s：柱子从下往上长，线从左往右画，格子依次出现 |
| Agent 图 | 采集中时，连线上的虚线缓慢流动 |
| 减少动效 | 全部直接显示最终状态 |

**保存**：布局保存在本机应用设置里，可以有多套。

## 2. 新增的后端接口（Codex 维护时要知道的）

### 2.1 会话阅读（`src/m1/transcript.js`）

- **能读的 Agent**：Codex、Claude Code、OpenCode、MiMo Code、Gemini CLI、DeepSeek Harness、Antigravity，即 `READERS`。ZCode、WorkBuddy、Cursor 没有核实过的对话格式，返回 `TRANSCRIPT_UNSUPPORTED`。
- **每家记录的位置和查找方法**：见 `SESSIONS-READER-20261101.md` 第 2 节。格式参照 CC Switch（MIT，`farion1231/cc-switch`，提交 `8be8405`）。
- **读取流程**：
  - 解析时保留全文，最多 10 万条，单条最多 3200 万字。
  - 发给窗口的是预览，由 `preview()` 生成。
  - 每次取全文（`part`）、查找（`find`）、导出（`markdown`）都重新读取并解析记录，并用文件大小和修改时间核对戳记，不一致返回 `TRANSCRIPT_CHANGED`。
  - **不缓存**。所有者的规则是“只显示不保存”，不要加跨请求的缓存；如果要加，先要有所有者的决定记录。
- **统计进程的命令**：`transcript`、`transcriptPart`、`transcriptFind`、`transcriptMarkdown`、`searchTranscripts`。它们已登记在 `statistics-contract.js` 的 READS 和 STORE_COMMANDS 里，错误码已加进 `statistics-errors.js` 的白名单。
- **IPC 通道**（`src/quota/main.js`）：
  - `usage:transcript`、`usage:transcriptPart`、`usage:transcriptFind`、`usage:searchTranscripts`；
  - `usage:transcriptCopy`：写剪贴板；
  - `usage:transcriptExport`：弹保存对话框，写文件，权限 0600；
  - `usage:openLink`：只接受 http/https，不带用户名密码，最长 2048 字符，交给系统浏览器打开。
- **跨会话搜索**（`search()`）：
  - 范围是会话页当前范围内能阅读的会话，从最近的开始，每批约 6 秒，返回的 `next` 用来继续下一批。
  - 先在原始文本里粗筛（同时匹配 JSON 转义和 `\u` 转义的写法），再解析。
  - 数据库每次搜索读一遍，逐个会话匹配，只保留命中结果。
  - 不建全文索引。

## 6. 当天踩到的坑

- **工作目录被重置**：Bash 工具会把工作目录重置回共享目录。有一次改动误写进了共享目录的 main 工作区，后来原样移回工作树、共享目录恢复干净后才合入。每条命令先 `cd` 到自己的工作树。
- **转义被吃掉**：heredoc 和 `node -e` 会吞掉 `\\`、反引号和 `\n`。含这些字符的改动用写文件或编辑器工具完成，不要在命令行里拼。
- **设计守卫**：
  - 页面不能写 `hover:`、`style=` 或 Tailwind 任意值，要放进 kit 组件或 `ui/src/theme/*.css`（例如这次新增的 `ResultRow`、`OutlineNav`、`.ff-reader-turn`、`.ff-reader-outline`）；
  - 圆角只能用 `rounded-lg` 及以上（lg/xl/2xl/full）。
- **CSS 冲突**：组件上的 Tailwind 定位类（例如 `relative`）会覆盖 theme CSS 里的 `position: sticky`。

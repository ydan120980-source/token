# 费用详情卡片、Agent 选择器和卡片边缘 · 2026-10-28

**状态**：Claude 实现，分支 `ui/shell-cost-ref`，接在 `UI-COST-KIT-20261028.md` 之后，没有合入 main。

## 1. 所有者的要求

所有者 2026-10-28 提出：
- 详情侧栏改成有边界的卡片，加入更多悬停交互，调整尺寸、排版和颜色（要鲜艳）；
- 参考一段“推理摘要”视频和截图的 UI 与动效：彩色分段条、两列图例；指向某一项时其余变淡，旁边弹出明细卡片；
- 所有 Agent 选择器统一成会话页那种样式；
- 检查卡片边缘有没有瑕疵。

随后所有者补充：“不用全量加，就加在详细展开就行了”。因此悬停交互和鲜艳配色**只用在费用详情卡片里**，其他页面和图表不加。

## 2. 改了什么

**费用详情**（`ui/src/pages/cost/detail.tsx`）：
- 浮动卡片：左侧面板离窗口边缘留 16px，圆角，整块像一张卡片（kit `Sheet` 新增 `floating`）。
- 标题区：Agent 图标放在圆角方块里，名字下面一行显示“使用方 · 范围”（kit `Sheet` 新增 `icon`、`subtitle`）。
- 六个指标放进浅色小方块；计价也一样。
- 用量构成换成 kit 新组件 `Breakdown`：
  - 分段条每段之间有间隔，图例两列，色块加数值；
  - 指向或用键盘聚焦某一项时，这一项高亮，其余变淡，详情卡片右侧弹出这一项的 Token、估算和占比；
  - 按 Esc 关闭。
- 用量构成用一组只在这里使用的鲜艳颜色：输入蓝、输出绿、缓存读取橙、缓存写入紫（`--vivid-*` token，浅色和深色各一套）。其他地方仍是 C 配色的蓝阶。
- 模型或使用方列表换成 kit 新组件 `LabelRow`：图标、名字、占比小胶囊、占比细条、Token 和金额，指向时整行有底色。
- “每日 Token”标题右侧显示指针所在那天的读数。
- “在用量页查看”“复制模型标识”移到卡片底部，固定在底栏。

**全站**：
- **Agent 选择器**（kit `AgentFilter`）：Agent 图标收在一个圆角底盘里，显示品牌本色；选中项是带阴影的卡片色方块，在选项之间弹簧滑动。凡是用 kit 的页面都会统一，M7 迁移后的用量页也会用这个。
- **卡片边缘**：首屏走马灯原来按自身尺寸裁切，卡片的柔和阴影在右边和下边被直接切平。现在每张幻灯片四周留 16px，走马灯整体向外扩 16px，阴影能完整显示。
- **费用走势**：堆叠面积每一层都铺一层均匀的浅色。原来用的是从上到下的渐变遮罩，下面几层几乎看不见。单线面积仍用渐变。
- **花在哪**：圆环改用大号，并在面板里垂直居中，下方不再留一大块空白。

## 3. 规则的变化

原来为费用详情卡片在“不做悬停交互和悬停卡片”的规则里开了一个例外。所有者随后更正：悬停从旧版照搬，新功能都要有悬停卡片，见 `UI-HOVER-20261028.md`，所以这个例外不再需要了。鲜艳配色仍只用在详情卡片里。

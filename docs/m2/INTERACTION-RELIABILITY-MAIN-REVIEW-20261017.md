## 主线程发现并修复的问题

费用页选择某个月份后，原实现用“当前被按下的时间范围”决定 Tab 入口。月份覆盖时间范围时，全部范围按钮都会变成 `tabindex=-1`，键盘用户无法直接 Tab 进入这组选择。

主线程先在新增交互套件加入回归，实际失败为可 Tab 进入的按钮数 `0 !== 1`。修复后保留之前时间范围的按钮作为唯一 Tab 入口；月份筛选期间它仍不显示为选中，方向键选择范围后正常清除月份。主线程在两个缩放档位复跑完整新增套件通过，并额外运行现有费用页套件。

提交文档中的主机绝对路径也改为相对证据位置，实际工作树位置只保留在忽略的本地验收 JSON 及交付消息中。

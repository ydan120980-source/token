# 首次切页与长会话 · 2026-11-12

在 `codex/responsiveness-20261112` 上以 `9702070` 为对照，继续处理上一次源码验收留下的界面延迟。用量首次切页达到 100 ms 的点击门槛。费用首次切页、会话列表的 20% 就绪改善和长会话的 100 ms 门槛仍开放。

## 改动

- 导航在离开旧页时已知道滚动位置。顶部到顶部的切换复用这个事实，避免新页刚挂载便读取滚动位置并触发同步布局。恢复非零历史位置仍走原有路径。右侧概要用 React 的延后值更新，页面本身先提交，浮层等对应的概要挂载后移交焦点。
- Hover 控件在浏览器交付布局尺寸后测量。费用双栏、叠条图和阅读位置轨复用原生尺寸。滚动条轨道立即启用原生滚动，第一次可见时才挂载滑块。真实费用页的旧路径在 `onThumbPositionChange` 中曾触发 26.1 ms 的布局。
- 滚动数字用一条十行文本绘制每位数字，沿用原行高和位移动效。真实阅读测量中的全窗 DOM 少约 600 个节点。阅读切换提供明确的起始动效值，位置轨只为被指向的轮次构建提示。
- 会话投影在同一次遍历中建立分组和观察引用，复用同一时区下的已知日历转换。传输仍返回完整会话列表，对重复字典项按字段校验一次后复用。首次列表仍包括跨范围分组需要的元数据，未知定价和会话来源保持原有语义。

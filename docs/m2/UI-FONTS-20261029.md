# 字体改为 Inter + 思源黑体 · 2026-10-29

**状态**：所有者 2026-10-29 决定把全部字体改为 Inter + 思源黑体。Claude 在分支 `ui/m11-apple-motion` 上实现，已合入 main。

## 1. 决定和原因

- 所有者原本想用 HarmonyOS Sans，后来又想用 Apple 的官方字体，最后定为 Inter + 思源黑体。
- **Apple 字体不能用**。Apple 的字体许可写明：
  - 只能用来制作 Apple 平台界面的设计稿；
  - 不能嵌入任何软件；
  - 不能在非 Apple 系统上使用。
  - 苹方（PingFang SC）是 macOS 系统自带的字体，不提供下载。
  - 来源：<https://developer.apple.com/fonts/>，2026-10-29 查阅。
- **改用两款开源字体**，风格最接近 Apple 字体，许可都是 SIL OFL 1.1，允许随应用分发和裁剪：
  - 拉丁字母和数字用 **Inter**，形状最接近 SF Pro；
  - 中文用 **思源黑体**，取 Google Fonts 的 Noto Sans SC 版本，风格最接近苹方。

文件都在 `design/desktop-reference/assets/fonts/`：

- 思源黑体的许可保留了字体名 “Source”。我们用的家族名是 Noto Sans SC，裁剪后仍用原名，不涉及这个保留名。

## 3. 思源黑体的裁剪

**为什么换来源**：noto-cjk 仓库的 CFF2 可变 OTF，harfbuzzjs 1.6.4 无法裁剪，所以改用同一字体在 Google Fonts 发布的 TrueType 可变版。

**保留的字符**，共 8474 个：
- GB2312 全部字符（汉字 6763 个和符号），用 Node 的 GBK 解码器逐码位解出；
- CJK 标点 U+3000–303F 和全角字符 U+FF00–FFEF；
- 可打印 ASCII；
- 界面源码中出现过的全部非 ASCII 字符：扫描 `ui/src`、`design/desktop-reference`、`src/m1`、`src/quota`，不含打包产物和第三方代码。

**工具**：`subset-font@2`（harfbuzzjs）。它装在临时目录里用，没有加进项目依赖，因为工作树的 `node_modules` 是主目录的链接。

**重新裁剪**（例如界面新增了生僻字）：
1. 在临时目录执行 `npm i subset-font@2`；
2. 用上面的字符集调用 `subsetFont(ttf, text, { targetFormat: 'woff2' })`；
3. 用输出覆盖 `NotoSansSC.woff2`。

**没收进的字符**：用户数据里的生僻字，例如项目名，会回落到系统的微软雅黑。

## 4. 接入

- `fonts.css`：声明 Inter、Noto Sans SC 和 Geist Mono 的 `@font-face`，字重都是 100–900。
- `tokens.css`：`--ui-font: Inter, 'Noto Sans SC', system-ui, 'Microsoft YaHei UI', 'Microsoft YaHei', sans-serif`。拉丁字母和数字用 Inter，中文自动落到思源黑体。
- 测试：
  - `ui-foundation-ui-test` 的字体断言改为 `/^Inter/`；
  - `ui-smoke` 的隔离页面预载 Inter、Noto Sans SC 和 Geist Mono。
- 打包：`build.files` 已包含 `design/desktop-reference/**`，新文件会自动进入打包版，不用改配置。

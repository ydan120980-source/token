# 额度时间线分组与口袋改版（2026-10-23）

## 所有者反馈

所有者在 `UI-QUOTA-TIMELINE-20261023.md` 之后继续反馈了四点：

- 口袋上仍有文字遮挡；
- 右侧时间线超过三个 Agent 时该如何设计；
- 图形还不够 Apple 风格，整体要更圆润；
- DeepSeek 卡片不要完全照搬参考图，要有自己的设计。

本增量只改额度页渲染层。

## 时间线

- **分组：** 每张卡片是一组。组内最紧急的那条时间线排在首行（已耗尽 → 最早重置 → 待刷新），显示 Agent 名称；名称旁的“+N”按钮展开或收起其余各条。展开过程有高度过渡；减少动态效果时直接切换。收起时，其余各条设为 `inert`，键盘无法进入。
- **数量：** 各组按紧急程度排序，最多显示 5 组。超过时，底部显示“显示另外 N 项”按钮，按钮上叠放隐藏各组的 Agent 标志。这样 Agent 再多，头部高度也保持不变。
- **轨道：** 轨道是一条圆角凹槽，样式参照 iOS 进度条。胶囊从“现在”伸向重置时间，由浅到深渐变，终点是一个带阴影的圆钮；悬停时圆钮外多一圈 Agent 色光环。
- **辅助线：** “现在”改为药丸标签，配一条贯穿所有时间线的竖线；网格改为淡虚线。
- **整行点击：** 每行都是可点击区域，由一个透明按钮覆盖整行，点击打开详情。“+N”按钮叠在它上方，可以单独点击。这个透明按钮不显示任何悬停底色，因此不会遮住行内容。
- **悬停提示：** 提示不会盖到名称列。上方空间不够时改为显示在时间线下方。
- **圆角：** 页头的列表行和统计块改为更大的圆角。

## 口袋

- **口袋上沿：** 改为中部下凹的弧线，像卡套上方便抽卡的拇指缺口，弧线上不放任何文字。口袋只盖住票据底部的留白；合成数据测得票据文字离口袋边缘至少 5px。
- **前后层次：** 后一张票据比前一张宽，看起来像一前一后插在口袋里。
- **口袋首行：** 左侧是总额名称。右侧显示总额覆盖的范围（“N 个积分包”，分页未读完时为“已返回的 N 个积分包”）；总额不可用时，右侧改为一个状态徽标，例如“服务不可用”。
- **数字下方的组成条：**
  - WorkBuddy：按到期时间分段，后面附“7 天内到期 X 积分”；
  - DeepSeek：显示服务报告的各组成部分（赠送余额、充值余额），配色与两张票据一致。条只表示同一总额内各部分的比例，不跨额度池合计。值都为 0 时不显示。

## 1. 依据

- 2026-10-26 和 2026-10-28 的复核（`UI-MIG-M4-M5-REVIEW-20261028.md`）都没有合入 Codex 的迁移版。复核的结论是：数据层可用，页面渲染不合格。
- 外观基准是当时 main 上的旧会话页：
  - 筛选两行：Agent 图标条和范围一行，搜索和排序一行；
  - 一行汇总，加“全部展开/全部折叠”；
  - 所有项目放在一张卡片里：项目行在上，会话行缩进在下，各列对齐；
  - 点会话打开明细。
- 不加说明文字，没有分隔线。分隔线一条依据 Apple 式表面规则，并延续所有者对“今天”卡片的要求。

## 2. 数据层：沿用 Codex，做了两处补充

- 来自 `ui/mig-m4-m8`（`247ffc1`）：
  - `sessions-model.js`：分组、合计、估算、明细内容；
  - `sessions-host.js`：读取、摘要缓存、复制、打开目录、恢复命令；
  - `ui/src/data/sessions-host.ts`；
  - 单元测试 `sessions-host.test.js`、`sessions-models.test.js`。
- 补充：
  - `window.sessionsUi` 保留为数据侧的读取接口（`list`、`loaded`、`reload`、`count`、`drillDown`）。小组件、用量页和主页即使在会话页没打开时也照常读它。
  - 从其它页“跳到会话页”时，跳转请求存在数据侧（`sessionsHost.drillDown`），页面挂载后读取，不会因为页面还没挂载而丢失。
  - 切到会话页时，如果列表过期就重新读取，和旧页的时机一致。
- 删除了旧的 `sessions-ui.js` 和 `sessions.css`，入口和本地预览服务的白名单同步更新。

## 3. 页面与组件库

- 页面是 `ui/src/pages/sessions/`，只组合组件。
- 组件库新增 `FoldList`：可折叠的分组行。
  - 项目行和会话行共用一个 12 列网格，所以跨项目也对齐；
  - 折叠时高度动画用 `spring.moderate`；减少动效时交叉淡入，不改变高度；
  - 项目行用箭头按钮折叠（键盘可用），也可以点行内空白处折叠；
  - 能打开明细的行，指针移上去有底色。
- 组件库的 `SearchField` 新增 `variant="filled"`：整条灰底的搜索框，与旧版工具栏一致。
- 明细用费用明细同款的右侧浮动卡片，内容有：
  - 三个读数；在窄卡片里，三个读数改成一列；
  - 用量构成，用彩色比例条，未报告的显示“未报告”，不显示 0；
  - 模型、会话 ID、工作目录，以及复制和打开按钮；
  - 按天的明细；
  - 底部是恢复命令按钮，或者不能恢复的原因。

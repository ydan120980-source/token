## 视频与可重复原因

提供的视频为 2560×1440、约 29.66 秒，包含用量页热力图、星期×小时格子和每日小时柱图。用隔离 Electron 解码本地视频，没有上传视频或读取其他媒体。

`108a54c` 引入的 `:has(:hover)` 规则在读一个格子时把其他格子压到 0.5，概览/小时柱图压到 0.4。鼠标跨过间隙时，整个图又恢复 1，进入下个格子再压暗。实际鼠标路径在修改前的热力图上重复得到 `0.5 → 1 → 0.5 → 1`。移除这些全图规则后，只保留当前格子自身反馈；小时提示跨过同一图内的间隙也保持显示，离开整图才关闭。定位提示时不再先写入 `(0,0)`。

## 修复行为

- 过去启动时恢复失败即永久缺少内存凭据，UI 只让用户重新授权。现在单次显式刷新可重新尝试本应用 vault；历史观测保留，失败仍可重试，返回 read/decrypt/record 白名单阶段用于区分诊断，不返回异常原文或凭据。不会绕过 Windows 加密。
- WorkBuddy 分页曾将任何重复/重叠页当作整个登录失败。现在只保留重叠前已校验的页，停止翻页且 `incomplete=true`；重复页不加入、不叠加、不声称完整。非法结构、矛盾总数、后续授权/网络失败仍拒绝，不发布假成功。
- 拥有 refresh grant 的应用连接在 access token 提前被服务端 401 拒绝时，受限续期并重读一次；不会因第一次拒绝就删除可续期登录。仅应用拥有的 grant 可走此路线，第二次仍拒绝才进入重新连接；不启动浏览器。
- 自动刷新使用原有一个共享定时器，加入其他服务的有效连接；未连接、忙碌和冷却中条目跳过；限流仍有 15 分钟冷却，慢批次后等完整间隔，唤醒不补跑历史 tick。没有配置任何新增默认开启。
- 顶部 cadence label/select 不参与压缩，预留 token 间距，原生 select 仍隐藏，由既有自定义控件呈现。仅此处局部布局修复。

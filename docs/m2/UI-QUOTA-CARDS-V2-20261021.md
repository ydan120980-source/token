# 额度卡片第二版与卡片偏好（2026-10-21）

所有者 2026-10-21 确认的 G2 步骤。前一版见 [UI-QUOTA-CARDS](UI-QUOTA-CARDS-20261020.md)。

## 所有者反馈与决定

- **Codex 卡片**：一张卡里有两个大数字。`3451.5086135` 原样显示，折成两行，把百分比顶出卡片；`purchased-credits` 是内部编号，没有翻译。
- **WorkBuddy**：
  - 看不到积分到底有多少。月度"周期积分"属于额度窗口（而不是余额），被收进"另有 1 项"，卡片只剩三个 0/100 的积分包。
  - 多个资源池时，行名用的是资源池编号 `package-0`，没有用服务返回的包名。
- **卡片尺寸**：所有者希望继续用固定尺寸，以后要加长按拖动换位置。
  - 这个理由成立：等大的格子交换位置不会让整页重新排版。
  - 卡片挤爆的原因是一张卡里内容太多，所以按参考卡片给每种卡片限定内容，没有放开高度。
- **小功能**：所有者要求加四五个提升体验的小功能，"可重命名"等。

## 卡片形状（固定 296px 正方形不变）

- **窗口卡**（有百分比窗口）：
  - 最多两个窗口，样式同参考卡：名称、重置时间、大百分比、分段条。
  - 有金额时，底部另加一行，例如"购买的积分 3,451.51 积分"。
- **钱包卡**（只有金额或余额）：
  - 最多三行明细；有大数字时只显示两行，大数字在下方。
  - 只有一项金额，或服务在同一资源池里报告了 `total` 时，才显示大数字。
  - 只剩一个大数字时垂直居中。
  - 跨资源池的合计属于 G4，本步不做。
- **其余内容**：没放进卡片的项目数写在详情按钮上，例如"另 1 项 · 详情"。按钮的无障碍名称仍是"账号详情"。
- **WorkBuddy 等多资源池的 Agent**：
  - 每行用资源池自己的名称（包名）。
  - 一次性积分包注明"积分包"；周期积分只写"N 天后重置"。
  - 已耗尽、已到期、不可用的金额显示为浅色。
- **金额显示**：
  - 卡片上按十进制字符串分组千位，最多两位小数，货币固定两位。
  - 四舍五入直接在数字字符串上做，不经过浮点数，所以 `9007199254740993.125` 显示为 `9,007,199,254,740,993.13`。
  - 原值放在悬停提示和详情里，与服务报告的字符串一致。
  - 内部编号 `purchased-credits` 显示为"购买的积分"。没有标签的余额按类型显示：充值余额、赠送余额、套餐额度。
- **卡片底部状态**：
  - 其他服务商的长错误信息在卡片上只写"需要处理"，前面加一个警示圆点；完整信息放在悬停提示和详情首段。
  - Codex 原本就是短状态，保持不变。
- **多个连接**：仍然每个连接一张卡，没有按 Agent 合并。
  - 原因：不同账号的额度不同，合并会藏起其中一个账号的额度。
  - 后端目前只对 Codex 判断是否为同一账号（`duplicateKnown`），其他服务商暂时不能判断是否重复。
  - 同一 Agent 的多张卡可以用下面的"重命名"区分。
  - 已在交接里请 GPT 为所有服务商补"同一账号"判断标记。

## 五个小功能（只影响显示）

这些设置保存在本机浏览器存储 `localStorage` 的 `agentusage.quotaCards.v1` 里，读写失败时退回默认显示。它们不改连接、凭据或额度数据，也不发请求。

1. **重命名卡片**：在详情面板的"卡片名称"里修改，回车或"保存名称"保存，清空则恢复原名。改名后，原连接备注显示在标题下方。
2. **隐藏卡片**：已连接和未连接的卡片都可以隐藏。页面上显示"已隐藏 N 张卡片 · 显示／收起"，展开后被隐藏的卡片以半透明显示，可以在详情里取消隐藏。
3. **卡片排序**：详情里的"前移／后移"会保存已连接卡片的顺序，新连接排在后面。以后的长按拖动可以直接沿用这份顺序。
4. **复制摘要**：工具栏"复制摘要"按页面顺序复制可见卡片的全部额度项。复制的是格式化后的数值，附带重置说明和读取时间，经由已有的 `usage:copyText` 写入剪贴板。
5. **剩余／已用切换**：工具栏的分段按钮切换百分比窗口显示"剩余"还是"已用"。
   - 已用优先取服务报告的 `usedPercent`，没有时用 100 − 剩余。
   - 未知仍显示未知。
   - 低额度提示始终按剩余量判断。

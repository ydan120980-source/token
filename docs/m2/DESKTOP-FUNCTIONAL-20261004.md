## 定价优先级、映射与默认配置

每个已批准 Agent（Codex / Claude Code / OpenCode / WorkBuddy / MiMo Code）都有倍率和计费来源，默认倍率 1、实际记录模型。可明确选择指定默认模型。配置保存于本应用 `billing.json`，现有手动价格仍保存于 `pricing.json`。

规则优先级：原标识的手动价格 → 明确模型映射 → 明确 Agent 默认模型 → provider/model 精确价格 → 实际模型的原厂标识匹配。原厂匹配仅用完整标识、明确前缀和无冲突的大小写匹配；不猜版本、路由或 free 后缀。自定义映射保留原始 provider/model。同步不覆盖手动价格、映射和默认配置。

价格目录可查全部模型，默认显示当前用过的模型；100 项分批展示，避免一次绘制数千行。映射面板显示实际已用模型和匹配进度；自动补齐可匹配标识，auto / mimo-auto / codex-auto-review 等在明确选择前仍未知。模型缺口与字段缺口分别展示，不能用“全部价格成功”掩盖字段缺失。

金额使用非重叠桶：未缓存输入、输出、缓存读取和缓存写入；推理已包含在输出，单列推理价格时从普通输出中扣除再计费。多档上下文按已知单请求长度选择；长度未知时涵盖全部已发布档位。推理数量未报告且价格不同则显示范围。必要用量或费率缺失仍保持 null，不能把 unknown 当免费。手动价格试算与保存后的估算使用同一 Agent 倍率与手动规则语义；未知缓存写入字段不会因原厂特例被错误隐藏，单元和最终包 UI 均验证两者一致。

公开快照的价格元数据增加可选 `billingSha256`，只包含配置 hash，不导出私有映射/默认配置文件。renderer 白名单新增 `reasoning-unreported` 固定原因。同步、配对、密钥恢复和持久防重放仍按 `DESKTOP-SCOPE-20261004.md` 保持设计状态，尚未实现生产同步。

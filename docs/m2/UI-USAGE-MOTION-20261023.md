# 用量页交互细节（2026-10-23）

所有者要求参照 easyui.site 的 11 个组件，优化用量页的交互动画和界面细节。现有渲染层已经具备的能力保持不动：
- 近 30 天柱条的生长动画；
- 热力图切换范围时的逐列扫入；
- 小时网格的入场动画；
- 趋势图的绘入、十字线和悬停提示。

本增量只补参考组件里有、而用量页还没有的部分。

## 改动

- **聚焦（参照 Bar Chart、Activity Heatmap）：** 指向近 30 天柱条、某天的 24 小时柱条、年度热力图或小时网格中的任意一项时，其余各项变淡（柱条降到 0.4 透明度，格子降到 0.5），让正在看的那一项更突出。只改透明度，因此减少动态效果时同样生效。热力图正在高亮某个时段时，保留原有高亮，不再叠加变淡。
- **热力图入场：** 年度热力图第一次滚入视野时，按列扫入一次，沿用已有的扫入动画。只在完整动效下播放；每次运行只播放一次。
- **刷新完成（参照 Pull to Refresh 的完成态）：** 刷新成功后，刷新图标缩小淡出，换成对勾，约 1.1 秒后恢复；减少动态效果时只做淡入淡出。实现为通用方法 `window.uiMotion.done(element)`，刷新失败时不显示对勾。
- **徽标（参照 Badge）：** “未定价”改为灰色胶囊徽标，表示一种状态，不再与金额混排，避免被读成一个数值。客户端行里的“N 条记录”也改为胶囊。
- **空图表（参照 Dot Shader，静态）：** 筛选后没有数据的趋势图，以向边缘渐隐的点阵作为背景；按所有者决定不做循环动画。

## 没有采用的部分

- Meteors：只用于空状态，用量页目前没有合适的位置。
- Date Picker、Sheet、Stepper、Donut Chart：留给费用页重做时使用。

## 验收

- 合成数据、源码模式下进行。
- `npm run verify` 通过（fail 0），`npm run audit:runtime` 通过。
- 受影响的界面套件 `overview`、`usage`、`activity`、`motion` 均通过。
- 探针在深浅两种外观下确认：
  - 悬停时，柱条其余项透明度为 0.4，格子为 0.5；
  - 热力图滚入视野后才开始扫入；
  - 刷新成功后出现对勾；
  - “未定价”显示为徽标。
- 打包版未验证。

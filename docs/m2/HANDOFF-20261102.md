## 5. 已知限制

- **改动视图只认编辑工具**：shell 改的文件看不到。整文件写入只算新增。
- **记住的是轮号**：Agent 改写记录后（Gemini 回退、Antigravity 压缩）位置可能不准。
- **接近末尾的短轮次**：页面滚不到让它贴顶的位置时，“当前轮”会落到上面可见的那一轮，保存的轮号也随之靠前。
- **跟随**：OpenCode 和 MiMo Code 共用数据库，同库其他会话有活动也会触发重读。等待时间不少于上次耗时的 10 倍。
- **位置轨按文字量估算**：能定位到轮，定位不到轮内某一行，滚动条是隐藏的。
- **没有虚拟列表**：一直滚到很靠后时页面元素仍会变多；没有测过 128 MB 上限附近的情况。

## 6. 当天踩到的坑

- **样式层顺序**：`shell.css` 的规则会压过 `app-layout.css`，提高选择器权重也没用。折叠栏角标就是这样失效的，修在 `shell.css`。
- **`content-visibility: auto` 会裁剪**：伸出轮次的内容（负外边距）会被切掉。所以代码块没有做加宽。
- **定位中的滚动**：`scrollTo` 跳转后约 1.6 秒内会持续校正。测试里要用真实滚轮，脚本改 `scrollTop` 会被拉回去。
- **透明元素的 `innerText`**：未渲染或正在过渡的元素可能返回空字符串，断言用 `textContent`。
- **命令行转义**：heredoc 和 `sed` 会吃掉或展开 `\\n`、反引号。含这些字符的改动用写文件的方式完成。
- **工作目录**：Bash 工具可能把工作目录重置回共享目录，每条命令先 `cd` 到自己的工作树。

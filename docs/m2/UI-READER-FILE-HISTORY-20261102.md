## 哪些会话改过这个文件

**用法**：阅读页右栏“文件”标签点一个文件，正文只留相关的轮次，下方出现“还有哪些会话改过它”；“只看”提示条上有同一个按钮。结果点一下就打开那个会话，并停在这个文件上：放得下就并排，放不下就替换这一栏。

**读取范围（边界变化，`AGENTS.md`、`docs/PRIVACY.md` 已同步）**：

- **只在点按钮时扫描**，不自动运行，也不建索引。
- **方式和跨会话搜索相同**：从新到旧，每批约 6 秒，可以继续查更早的会话。
- **先用文件名过滤**，文本里没有这个文件名的记录不解析。
- **返回的只有**：哪个会话、匹配的路径、增减行数和次数。不含改动内容和对话文字，也不保存。

**怎么算同一个文件**：

| 情况 | 结果 |
|---|---|
| 绝对路径相同（相对路径按该会话的工作目录换算） | 算，排在前面 |
| 工作目录不同，但相对路径相同且带目录（如另一个工作树的 `src/chart.js`） | 算，标“其他目录的同路径文件” |
| 工作目录不同，只有文件名相同（如别的项目的 `README.md`） | 不算 |
| 改动失败的调用 | 不算 |

**已知限制**：

- 和“改过的文件”一样，只认编辑工具，用 shell 改的文件看不到。
- 代码模式里 `tools.apply_patch` 的改动能看到，但用变量传入的读不出来。
- 文件改名不跟踪。
- 路径比较不分大小写，这是按 Windows 做的。
- 扫描很多长记录时要等好几批。

代码：`fileHistory`、`scan`（`src/m1/transcript.js`，`search` 和它共用 `scan`），`transcriptFileHistory`（`src/m1/store.js`），`ui/src/pages/sessions/file-history.tsx`。测试：`tests/m1/transcript-file-history.test.js`。

## 每轮 Token

- **位置轨**：记录报告了 Token 时，每轮的条按用量变宽，提示里写具体数字。用开方刻度，避免一轮特别大时其他轮都看不出差别。
- **颜色**：还是原来的中性色，多少不表示好坏。
- **未知**：这一轮没有 Token 数据时条最细，提示写“Token 未知”，不会读成“很少”。整个记录都没有时，位置轨和以前一样。
- **右栏“概况”**：列出 Token 最多的 5 轮，点击跳转。

数字和对话下方的“Token”同一来源，只显示，不进统计。

## 顺带修的：读取范围

**问题**：阅读页的“打开其他会话”和对比，之前只能看到列表当前时间范围内的会话；打开范围外的会话时，右栏也拿不到它的用量。

**现在**：阅读页和快速切换打开时加载全部会话列表，全部关闭后释放（`holdAll`）。读取失败时退回列表页已有的数据。

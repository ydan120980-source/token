# 额度钱包口袋按参考卡片重做（2026-10-22）

所有者认为叠加卡片"细节不够到位"，要求仿照 DeepSeek 参考卡片重做，并指出 WorkBuddy 卡片"ui 有遮挡"；测试只跑受改动影响的部分。前一版见 [UI-QUOTA-V4-POLISH](UI-QUOTA-V4-POLISH-20261022.md)。

## 参考卡片的做法与对应实现

| 参考卡片 | 实现 |
| --- | --- |
| 第一张票据是品牌色实色块，白色粗体字 | Agent 色调与深色混合后做上下渐变（保证白字对比度），文字用 `--on-category` |
| 第二张票据是浅色纸片，深色字 | 浅色外观下是白到浅灰的渐变；深色外观下是浅灰纸片配深色字（`--on-agent`） |
| 票据只写名称和金额 | 到期日期移到悬停提示；7 天内到期的积分数写进口袋里"可用积分"那一行 |
| 口袋横跨整张卡片、一直到底边 | 口袋向左右延伸到卡片边缘、向下到卡片底边，卡片底部的状态行和"详情"叠在口袋上 |
| 口袋上沿中间隆起一块，放标志和名称 | SVG 画出口袋上沿；隆起处放 Agent 标志，以及积分包数量（如"28 个积分包"，未读完时写"已返回的 N 个积分包"）或品牌名（如"DeepSeek"） |
| 口袋边缘在票据上投下阴影 | `drop-shadow` 使用新令牌 `--ticket-shade`（深浅外观各一个值） |
| 口袋颜色：浅色外观为浅灰，深色外观与卡片同色 | 新增 `--pocket` 变量：浅色外观取 `--soft`，深色外观取 `--card` |

## 遮挡的原因与处理

- **原因**：口袋贴着卡片底部对齐，内容一旦超高就向上溢出，第一张票据因此压住了标题下的"2 个连接 · 同一账号"。
- **处理**：
  - 改为 `justify-content: safe flex-end`，超高时只会向下溢出；
  - 原来单独一行的"7 天内到期 / 共 X"并入已有的行；
  - 票据和口袋上沿收紧。
- **截图工具实测**（`.cache/ui-tools/p-pocket.js`，不入库）：
  - 第一张票据与上方文字的间距：WorkBuddy 7px，DeepSeek 18px；
  - 口袋底边与卡片底边重合（0px）；
  - 状态行显示在口袋上方。
  - 深浅两种外观的数值相同。

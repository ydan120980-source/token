# 桌面定价与趋势交互重整 — 2026-10-04

本轮依据用户六张缺陷截图、CC Switch 录屏及 Apple design 技能，重整已交付桌面功能。沿用 Nowdex / Electron 43.4.0 / JS / Chart.js；唯一入口 `src/quota/main.js`。无 subagent，CodeGraph 和 Browser 技能运行时不可用，使用定向源码及仓库 Electron / Playwright 验证。此前 `functional`、`pricing`、`m2-desktop`、`polish` 交付保留，不 reset/clean。

## 界面与业务合同

- 成本定价由长列表叠加改为模型价格、计费配置、模型映射三个页签。公共价格同步保持独立头部；价格表和映射表各自限高滚动。“未定价明细”已从界面与控制器移除，原始价格未知/字段缺失语义继续保留。
- 模型选择不再调用系统 datalist。已有 select 和动态生成的模型控件使用同一个主题化弹层：搜索、轮滚、分页加载、方向键/回车/Escape、选中状态、焦点恢复；最高 360px，长标识可读，弹层与表格均限定自身滚动。弹层置于所属对话框或 popover 中，保持正确层级。
- 手动规则在独立对话框中编辑。可选日志模型并自动填充标识、复制已有费率、编辑输入/输出/缓存费率；单位统一 USD / 百万 Token。试算明确影响记录和单条样本金额，应用当前倍率；保存后关闭编辑器并重算，撤销恢复实际匹配规则。未知仍为空，明确免费才为 0。倍率和映射保持本应用持久化，不改变日志字段。
- 金额区间使用按场景定尺寸的细圆角连接线，明细使用 16px × 1.5px，累计使用 28px × 3px，修复原 0.24em 导致小金额分隔符不可读的问题。累计金额保持大字号与悬停数字动效，单行展示并按可用宽度缩放，布局高度稳定。
- 趋势主筛选为 Agent、来源、模型、刷新频率、时间范围。来源严格表示记录中的 provider 标识，不读取或关联账号凭据。来源随 Agent 缩小，模型随 Agent/来源缩小；无效旧选择恢复全部。时间范围采用预设与日期弹层；日均/累计、粒度、最新在前移入图表选项。
- 刷新频率为关闭 /5s /15s /30s /1min /5min，默认继续 15s。通过固定 IPC 白名单影响真实 Service 调度，并原子保存本应用 preferences.json。关闭仅停止定时任务，不关闭手动刷新、不改 enabled；暂停状态不会被频率选择偷偷恢复。失败退避至少遵守用户频率；应用关闭清理任务。旧配置没有该字段时仍为 15s，非法值拒绝写入。
- 趋势默认构成：未缓存输入、含推理输出、缓存读取、缓存写入四条 Token 曲线与独立右轴的费用虚线。费用和 Token 不相加，推理不重复计入。未知字段保持 null，缺日期不补造零。总量、模型对比仍可用；费用视图仅呈现适用的总量/模型选项。超过一年自动按周；首个不足整周/月的横轴显示实际覆盖起点，避免显示范围外日期。
- 图表延续单实例/数据集复用与可中断重定向；650ms easeOutQuart，首次进入视口以 720ms 曲线揭示回应，悬停有竖线、采样点及限定位置的浮层。减少动态/关闭动态停止动画，保留可读最终状态。没有添加动画强制启用开关；系统减少动态优先。

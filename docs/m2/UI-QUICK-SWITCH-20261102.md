# 快速切换 · 2026-11-02

**所有者决定（2026-11-02）**：要 Ctrl+K 快速切换。

任何页面按 Ctrl+K，或点标题栏的搜索图标，打开搜索框：

| 结果 | 打开后 |
|---|---|
| 会话（没输入时是最近 8 个） | 能阅读的进入阅读页；不能阅读的（ZCode、WorkBuddy、Cursor）进入会话页并搜索它 |
| 项目（输入后才出现） | 会话页搜索这个项目 |
| 页面（概览、用量、费用、会话、来源管理、设置） | 进入这一页 |

**键盘**：上下键选择，Enter 打开，Esc 或再按一次 Ctrl+K 关闭。正在阅读时，Ctrl+Enter 把会话并排打开。

**只搜名称**：名称、Agent 里的标题、项目、目录、Agent、模型和会话 ID，不读对话内容。对话内容搜索还在会话页。

**不保存任何东西**：不记搜索历史。打开时读取全部会话列表，关闭后释放。

**已知限制**：

- 并排已到 3 栏或窗口放不下时，Ctrl+Enter 不会打开新栏，也没有提示。
- 结果不按相关度排序，只按时间。

代码：`ui/src/pages/sessions/quick-switch.tsx`。测试在 `scripts/m1/session-reader-ui-test.js`。只测了合成数据和源码模式。

# 界面动效三档的区别 — 2026-10-15

2026-10-15 项目负责人在打包版里反馈："减少动态"和"关闭"选了之后看不出区别。本记录取代 `docs/m1/UI-MOTION-20261004.md` 中"reduced 只保留至多 80ms 淡入"的规定。

## 原因

`motion.css` 在减少动态下把所有元素的 `transition-duration` 设为 0。结果只剩 JS 驱动的 80ms 淡入（从 0.86 不透明度开始），几乎看不出来，实际效果和"关闭"一样。

## 现在的规定

| | 完整 | 减少动态 | 关闭 |
|---|---|---|---|
| 位移、缩放、旋转、尺寸变化（含悬停上浮、按下缩小、选中指示器滑动、展开高度、进度条增长） | 有 | 无，直接到终态 | 无 |
| 颜色、底色、描边、阴影、不透明度的过渡（悬停反馈、光环、选中底色） | 有 | 有，沿用各元素自己的时长 | 无 |
| 进入和更新时的淡入（页面、详情、弹窗、菜单、提示） | 淡入加位移 | 只淡入，150ms | 无 |
| 趋势图换 Agent、范围或指标 | 曲线从当前位置变形过去 | 曲线立即换成新数据，整个图表 150ms 淡入 | 立即切换 |
| 图例显隐 | 淡出或淡入，其余曲线重新缩放 | 只淡出或淡入，坐标立即变化 | 立即切换 |
| 关键帧动画（扫入、刷新图标旋转、活跃圆点脉动）、数字滚动、顺滑滚动 | 有 | 无 | 无 |

- 系统开启"减少动态"时仍然优先：应用里选"跟随系统"会按减少动态处理，应用不能恢复完整动效。
- 实现：减少动态下，全局只允许 `opacity`、颜色类、`box-shadow`、`visibility` 和弹出层的离散属性过渡，其余属性的过渡失效；悬停上浮、按下缩小在减少动态和关闭两档下都固定为 `transform: none`，统一列在 `motion.css` 一处。

## 同时修复

- 趋势图在 `c29ea12` 加了"超过 31 个点不做过渡"的限制，所以"最近一年""全部"等范围下换 Agent 时曲线直接跳变。现在一年以内的日数据（最多 400 个点）都会变形过渡；更长的范围会自动改按周显示，点数会变，这时重新绘入。`functional-ui-test` 增加了检查：在超过 31 个点的范围内切换 Agent，曲线必须有中间帧。把限制改回 31 后，这项检查会失败。

## 验收

源码模式下 verify、`audit:runtime`，以及全部 15 个 UI 套件通过（合成 fixture，独立的 usage/quota 目录）。motion 套件里关闭动效的平均提交耗时为 75–77ms，跟随系统为 97–98ms，在"不超过关闭的 1.5 倍加 20ms"的约束内。打包版没有验证。

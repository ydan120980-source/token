# 未计入估算：下一步如何处理

“用量已定价”表示已保存用量可以按当前计费规则估算，不代表真实账单已核对。未计入估算的 Token 没有丢失，仍计入用量统计。

在“设置 → 定价”的未计入估算列表中展开“处理方法”。费用页的计价覆盖也能直接打开对应模型的处理方法。每项都会显示原因；涉及来源时可定位到对应来源的读取位置。

| 原因 | 操作 | 能否恢复历史 |
| --- | --- | --- |
| 没有价格、费率缺失或参考价待核实 | 核对实际计费服务商/模型，设置映射或已确认的手动费率 | 用量完整的历史会按新规则重新估算 |
| 来源没报告缓存读取、输入、输出等字段 | 检查来源状态与解析能力；个人来源检查字段映射和计数语义，先预览再应用；内置来源核对 Agent 版本和解析适配 | 原始文件有字段时可重读；原始文件没有的历史无法补齐，同步价格无效 |
| 缓存写入未报告 | 先确认实际服务商是否单独收费；确认该项费率为 0 时可核对并设置手动费率；收费时仍需要写入数量 | 费用是否可算取决于真实计费规则；Token 数量继续保持未知，不伪造为零。已有来源合同可支持区间估算时沿用原规则 |
| 分项、总量或重复观测冲突 | 在对应来源查看错误与范围，核对重复导出；个人来源检查缓存/推理包含关系，修改后先预览 | 证据足够才能修复；不通过改价格掩盖冲突 |

订阅月费、账号额度和 API 等价估算是不同指标。订阅已付费或仍有免费额度，不构成缓存写入单价为 0 的依据。不要为了让覆盖率变成 100% 而填写无依据的零值。

## 公开 Agent 格式实验

本轮按 GitHub 公开格式独立编写合成记录，验证自定义映射闭环，没有运行第三方 Agent、导入公开用户会话或增加品牌白名单。

- oh-my-pi：固定 [076a85e 的会话格式](https://github.com/can1357/oh-my-pi/blob/076a85ed7dd037225f6d399ed40c4c21e9726251/docs/session.md)，用量语义参照该版本 [Anthropic provider 实现](https://github.com/can1357/oh-my-pi/blob/076a85ed7dd037225f6d399ed40c4c21e9726251/packages/ai/src/providers/anthropic.ts)。[配置示例](custom-source-examples/oh-my-pi.json)只映射 assistant message 的调用 ID、时间、模型、服务商和用量桶，不导入正文和上游金额。
- Triss：固定 [8baae4d 的用量合同](https://github.com/ayleen/triss-coworker/blob/8baae4dad67dd34f2124062e8caaf64fd92a87f9/docs/usage-accounting.md)。[配置示例](custom-source-examples/triss.json)映射互斥 Token 桶，输出使用含推理的 output_total。合同允许 call_id 为空：这类记录无法满足稳定身份要求，实验确认其被拒绝入账，不能用随机 ID 或行号代替。

这两份是公开格式的受控合成实验配置，不是所有版本、所有 provider 或真实安装的全面兼容承诺。导入后仍需通过本机选择器指定目录、核对包含语义并完整预览。若上游 ID 仅在会话内唯一，应让每条用量记录携带会话 ID 并映射 session；不能把本实验中的合成调用 ID 用于真实数据。来源启用由用户明确提交，不自动扫描第三方目录。

配置示例不含绝对路径、真实调用 ID、会话或正文。用量缺失继续保持未知；成本由本应用统一计价，不信任样本自带的 cost 为免费证据。

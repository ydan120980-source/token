## 实现：组件映射与固定选项

统一由 `ui/src/kit/index.ts` 导出；不透传 M1 属性清单以外的 fluid 属性。

| kit | 基于 | 固定选项 / 行为 |
|---|---|---|
| Button | fluid Button | 四种 variant；两档 size；danger 固定 ghost + destructive；显式 button type；loading 保留原 spinner，标 aria-busy。 |
| IconButton | fluid Button | ghost；icon / icon-compact；必填 label；Tabler 图标。 |
| Segmented | fluid Tabs/List/Item | 受控值、items、两档 size；原指示器和键盘行为。 |
| SubTabs | fluid TabsSubtle/Item | 受控下标，固定 idPrefix。 |
| Select | fluid Select/Trigger/Content/Item | options 白名单、两档 size、共用 portal；按 Q3 使用 moderate。 |
| Menu | fluid DropdownMenu/Trigger/Content/MenuItem | actions、disabled、danger；destructive 作用到实际标签；按 Q3 使用 moderate。内部原生 fluid trigger 保留 Radix 注入的 ref、ARIA 和事件，不放宽 kit API。 |
| Switch | fluid Switch | checked/onChange、右侧 label、disabled；原尺寸。 |
| CheckboxGroup | fluid CheckboxGroup/Item | value/onChange/items/disabled；由 items 映射索引；禁用不更新且移出 Tab 顺序。 |
| RadioGroup | fluid RadioGroup/Item | 同上；启用时保留原 roving tabindex，仅在禁用时覆盖。 |
| Slider | fluid Slider | 单值；min/max/step/label/format；原默认布局和键盘步进。 |
| TextField | fluid InputGroup/Field | 单受控字段；text/number、placeholder、error。 |
| SearchField | fluid InputGroup/Field + IconButton | 可访问标签、Tabler 搜索图标；非空时清除按钮，清除后焦点回输入框。 |
| Sheet | fluid Dialog/Content/Header/Title/Description/Footer | sm/lg/xl 为 400/540/880；slow；描述关联；关闭后焦点返回触发者。 |
| Disclosure | fluid Accordion/Item/Trigger/Content | single + collapsible；受控/defaultOpen；按 Q3 使用 moderate。 |
| Badge | fluid Badge | neutral→gray，warn→amber，无其他颜色入口。 |
| Banner | fluid Banner | info/warning/error；原 inline/low；通过原 motion 属性把 appear/dismiss 归到 moderate/.exit。 |
| DataTable | fluid Table/Header/Body/Row/Head/Cell | columns/rows；原行与分隔线；render 返回内容，不计算。 |
| ListRow | 规范类组合 | 高 36，subtitle/caption，hairline；可点击时为原生 button；selected token；焦点色取 focus-ring。 |
| Card | 规范类组合 | surface-3、rounded-2xl、p-6 / compact p-4；没有卡片套卡片。 |
| PageHeader | 规范类组合 | display/semibold，caption 说明，操作区。 |
| SectionHeader | 规范类组合 | title/semibold，操作区。 |
| Value | 规范类组合 | null/undefined 显示未知或未定价并标 data-value=unknown；其他字符串原样显示；tabular-nums。 |
| Figure | Motion + 规范类组合 | 四档字号；逐位 0–9 列滚动、右到左 staggerDelay；enter/update；位数变化淡入；减少/关闭动效直接终值；单位 caption。 |
| AgentMark | 已加载 agentCatalog + 官方资源 | 路径沿用 assets/ + meta.icon + .svg；内置即 assets/agents/<id>.svg，fallback 沿用 layout-grid；dot 只用现有 agent token；三档尺寸。 |
| EmptyState | 规范类组合 | 一行说明和可选操作，无插图。 |
| Toast / toast.show | Motion + 规范类组合 | moderate/.exit；单条替换，先退出；不另加自动关闭时长；不拦截鼠标；最后宿主卸载时清除消息。 |
| CarouselDots | fluid CarouselDots | 保留 count/value/onValueChange/autoplay/progress/getLabel；没有新增布局或动效入口；展示当前首屏所用的手动切换。 |

展示页只用合成常量和 React 本地状态，不调用任何 bridge。AgentMark 只读取已加载的 catalog 名称和图标路径。不包含定价、格式化、单位换算、跨 Agent 聚合或页面计算。Figure 只把单个数字映射成动画位置，不转换金额本身。未创建 M2 数据层。

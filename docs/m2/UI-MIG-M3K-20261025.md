## 与审核记录第 3 节相比的补充

1. **滚动区聚焦时去掉淡化**：在 `ui/src/theme/fluid-helpers.css` 增加 `.ff-scroll-focus` 规则。理由：kit 不能写任意值，theme 归 Claude。
2. **关闭动效时的滚动淡化**：
   - 问题：旧版 `motion.css` 在关闭动效时用 `animation: none !important` 关掉所有元素的动画。legacy 层的 `!important` 优先于后面所有层，所以 React 层的滚动淡化也被关掉了。
   - 修改：这条规则改为排除 `.ff-scroll-fade`。滚动淡化跟随滚动位置，不随时间播放，属于位置提示，不是动效；旧测试 T-I08 也要求关闭动效时保留边缘提示。
3. **测试辅助函数**：
   - `scripts/m1/ui-settle.js` 的 `settle()` 改为只等按时间播放的动画。滚动驱动的动画永远不会“结束”，不排除就会一直等。
   - `scripts/m1/ui-smoke.js` 把 `ff-scroll-fade` 列为共享类名。旧样式提到它只是为了排除。
4. **Combobox 的说明文字**：显示在选项名后面，格式为“名称 · 说明”，也参与搜索。

**状态**：所有者 2026-10-29 要求开始 M9：重新设计外框，并且不改主页面的圆角卡片。打包验收和全量测试交给 Codex。外框重设计由 Claude 在分支 `ui/m9-shell` 完成，已合入 main。其余收尾见第 3 节，交给 Codex。

## 1. 所有者的要求与参考

所有者的评价是：现在的外框排版太“AI 化”，logo 一般，可交互性不高。

给的参考有三类：
- Claude 式的“图标栏 + 导航栏”；
- 一个侧栏系统，可以收起成图标栏，底部有带操作的状态卡和个人资料行；
- Stacks 式的标题栏面包屑和浮起的选中态。

另外附了点阵、世界时钟、流星的卡片图作为氛围参考，其中彩虹按钮被明确划掉，不采用。

## 2. 本次实现（外观和交互；结构仍是旧外框）

- **logo**：重新画成点阵标记。墨色圆角方块上排着 3×3 的点，亮的点组成逐列升高的柱子，表示随时间增长的用量，呼应点阵参考。
  - 颜色跟随主题：浅色是墨色底白点，深色反过来。
  - 鼠标移到 logo 上，柱子的点依次升起；这个效果只在完整动效下出现。
- **导航**：
  - 分“工作”（概览、用量、费用、会话）和“管理”（来源管理、设置）两组；
  - 当前页是白色浮起的胶囊（卡片阴影），切页时这个胶囊会滑过去，复用 `motion.js` 原有的指示器；
  - 鼠标移上去有浅底，按下时更深；
  - 数量角标是靠右的橙色胶囊。
- **采集状态卡**（新，可操作）：放在侧栏底部，显示本机采集的状态，按钮随状态变化：
  - 已暂停时显示“恢复采集”；
  - 采集中按钮不可用，圆点闪动；
  - 上次没完成时显示“重新采集”；
  - 正常时显示“立即采集”，并显示最近一次的时间。
- **个人资料行**：头像和名字，鼠标移上去有浅底，点头像仍然打开资料编辑。
- **标题栏**：后退和前进按钮之后显示面包屑“Agent Usage / 当前页”。以前这行只给读屏器读，现在显示出来。
- **快捷键**：`Ctrl+1` 到 `Ctrl+6` 按侧栏顺序切换页面，输入框里不生效。
- **修正一个已有的 bug**：标题栏菜单的“刷新”在用量页会点击一个在 M7 已经删除的 `#refresh` 元素，现在改为调用 `usageHost.refresh()`。
- **兼容**：所有原有的 ID、`data-view`、`.topbar` 都保留，旧的视图切换、角标、侧栏收起和测试都不用改。
- **样式**：新样式写在 `ui/src/theme/shell.css`，不分层，所以会覆盖 legacy 层的外框规则；颜色、圆角和动效都用 tokens。
  - 字号直接写 14px 和 12px，没用 `--text-*` 变量。原因是 Tailwind 会把用到的同名主题变量重新声明一遍，和 legacy 冲突，`ui-bundle.test.js` 会因此失败。
- **页面区**：页面面板和其中的卡片都没有改。

顺序如下，每一步提交一次：

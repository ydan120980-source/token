# 柔和数字动效、滚轮传递与应用顶栏 — 2026-10-04

范围来自用户提供的 20.335 秒 Windows 录屏及三张截图：动效过快和反复抖动、Agent/模型区域滚轮失效、顶部原生标题条突兀。随后用户更正菜单要求，因此采用产品专属“统计 / 外观 / 关于”，不保留文件/编辑/视图/帮助的通用编辑器菜单。本轮主 agent 执行，无 subagent。沿用 apple-design skill 和现有 Electron / 普通 JS / CSS，不新增依赖，不修改系统外观配置。

## 动效收敛

- 数字从 460ms cubic-in-out 改为 760ms sine-in-out。相同幅度下理论峰值速度约为原先的 32%，没有过冲；最终统计、ARIA、导出及业务请求仍立即使用真实最终值。
- 可读数字最多约 30Hz 替换文本，RAF 中的进度保持连续；减少高刷新率下大量字符反复替换造成的视觉噪声。已启动任务若再次收到同一目标，仅更新目标元素和格式，不重启计时。目标变化从当前进度继续，未知值不经过零。
- 估价悬停保留固定字号和原始命中区域，取消展开时的字号收缩。相同展开状态的 pointerover / focus / click 不反复从下限重播。上限值仍在原位置呈现，离开/失焦收回，键盘行为保留。
- 时间范围切换不再让整个概览区反复从低透明度闪入；图表更新仅从 0.86 淡入。点击已选范围/页面不重绘，不重新播放。日期明细只在首次出现或选中另一天时入场。
- 页面跳转改为 520–900ms 的柔和加减速，用户滚轮/指针/键盘仍即时中断。固定顶栏的 44px 被纳入跳转目标留白。减少/关闭动态仍即时切换。

## 滚轮与留白

原先 `.day-agent-list` 使用 `overscroll-behavior: contain`，即使没有足够内容可以内部滚动，也会拦住向页面传递；长列表到边界后同样困住滚轮。本轮改为 auto，保留有界的长内容：短卡片直接滚动页面，长列表先滚动内部，到上下边界再滚动页面。模型表同样允许边界传递；选择菜单保留内部隔离，避免正在选项时误滚动背景。

日期卡片原有 24px 留白保留。800×600 下改成顶栏 + 横向导航 + 内容的明确分层，消除 fixed 容器遗留 bottom:0 导致导航撑满窗口的问题。跳至内容链接只在键盘聚焦时出现。

## 功能顶栏

应用顶部为 44px 固定功能栏，背景跟随浅色/深色，使用 [Electron 官方自定义标题栏与原生窗口控件方案](https://www.electronjs.org/docs/latest/tutorial/custom-title-bar)。右侧仍为 Windows 原生最小化/最大化/关闭；空白区可拖动，操作按钮明确为 no-drag，使用 titlebar-area 安全区避免覆盖原生按钮。

| 入口 | 真实操作 |
| --- | --- |
| 侧栏按钮 | 收起/展开导航，本机保存偏好，隐藏导航退出键盘交互树 |
| 后退 / 前进 | 四个页面的本地历史，边界禁用，回到原滚动位置；Alt+← / → |
| 统计 | 刷新当前页面（Ctrl+R）、导出用量统计（Ctrl+E），沿用现有刷新与导出流程 |
| 外观 | 侧栏（Ctrl+B）、深浅主题、跟随系统/减少动态/关闭动效、设置 |
| 关于 | 本产品 0.1.0 版本、本地用途、快捷键和估价口径；不显示开发环境 Electron 版本 |

页面历史在隐藏旧页之前保存滚动位置，避免长页变短后 scrollY 被浏览器归零。新加入的 IPC 只允许固定菜单名称、两类主题及窗口展示状态，验证主窗口/主 frame；不增加文件、网络、认证、账号切换或任意窗口命令权限。

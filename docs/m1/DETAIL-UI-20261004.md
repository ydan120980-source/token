## 实现

- 删除费用详情 dialog。所有估价金额支持悬停、键盘聚焦和点击，在原位置展开已定价金额上下界；离开/失焦收回，Escape 收回。没有可靠价格时仍显示“未定价”；没有价格区间但有未定价用量时仍保留 `+`。范围不是完整账单，首页可见覆盖比例/未知费用未包含说明，完整语义在按钮 aria-label 中。
- 已知数字使用 460ms cubic ease-in-out，无过冲，加速后减速；覆盖范围/筛选后的主估价、token、活跃天数、记录、今日/日期明细、趋势总量及额度百分比。ARIA 和 `data-final-value` 立即更新为最终值，展示从当前值继续；缺失/未定价/空数据直接更新，不从零虚构。首次出现直接显示，不做启动计数。一个 RAF 调度器管理所有当前计数，不叠加旧动画。
- 页面内跳转采用距离相关的 380–680ms 加减速曲线；轮滚、触摸、指针、导航/键盘、窗口缩放均可中断。跳至日期详情时焦点立即移到目标而不触发原生瞬移。减少/关闭模式即时跳转。新增数字与滚动任务在系统偏好变化及页面隐藏时收敛为最终静态状态。
- 原生 select 保留为状态接口，应用内以统一 combobox/listbox 展示。长列表提供搜索，菜单最大高度 304px，超出内部滚动，按可用空间向上/向下展开，限制在窗口边缘内。支持方向键、Home/End、Enter、Escape、Tab、选中标记、禁用和焦点恢复。下拉面板有短暂的锚点缩放/淡入，减少模式只淡入。系统文件选择器不变。
- 趋势工具栏明确分成“指标/显示/顺序”和“Agent/模型”两行；窄窗口再重排，模型选择不会孤零零贴在一侧。日期明细卡片恢复左右 24px 内边距（含边框实测约 25px），模型行留白与金额对齐，窄窗口允许换行。
- 模型表、日期 agent 列表、星期日期列表及价格维护的长内容设内部滚动上限；原生 details 统一使用 250ms 内容过渡和箭头反馈，长表格由有界容器限制高度。设置/导出/额度的现有交互与权限不改。

## 限制与异常

一次源码 UI stress 在等待数字完成时出现 `Target page, context or browser has been closed`，初次没有渲染器退出细节。已加入进程输出、退出码、页面错误及 render-process-gone/closed 诊断；带诊断复测通过且未复现，Windows Application 1000 查询没有取得相关记录。不能据此认定根因已定位或该偶发关闭已修复；失败现象保留为评审风险，不使用强制点击/跳过检查掩盖。

菜单初次展开被迟到的自动滚动通知误关闭的问题已复现并修复：按打开时实际 scrollY 判断，仅在位置变化时关闭。主估价字体收缩导致悬停区域变化的问题通过固定 90px 点击区域修正；金额主按钮保留节点与焦点，避免统计更新重建按钮。对未知金额不加 `+`，保持“未定价”的原语义。减少动态与未知值分支独立检查。

首次解压 detail 自动化在 `firstWindow()` 后过早切页，后加载的额度初始化将页面切回默认额度，导致金额目标被隐藏。依据源码，真实窗口在 `loadFile` 完成后显示；测试改为等待 document 的 load 状态，随后两个缩放比例通过。未采用强制悬停、禁用动画或跳过断言。此测试启动问题与上面的未定位压力窗口关闭分别记录，不能混为同一根因。

真实物理显示器手感、Nowdex 原生 Mac 逐帧一致性、真实额度变更和全新机器依赖安装未执行。计数动画是展示值，日志/导出不写中间值。大数据的既有同步重绘限制仍存在，不能宣称所有动作稳定 60 FPS。停在本轮用户评审，不开展其他 provider、云或 iOS。

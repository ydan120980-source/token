# Nowdex 参考界面调整

本轮范围是当前 Windows 应用的视觉与交互整理。参考用户选定的 Nowdex 用量页、主屏幕小组件及菜单面板截图，并核对 https://nowdex.app/zh-hans/ 。继续使用唯一入口 `src/quota/main.js` 与现有五来源统计，不添加新的额度 provider。

## 展示行为

- 用量概览使用大金额与独立指标，去掉常驻简介、时间覆盖说明、分类旁白、趋势注释及侧栏底部说明。实际字段标签、未知值、错误状态、操作确认仍保留。
- 费用保持已定价部分的原始下限。存在上下界差异或未定价用量时显示 `$金额+`；点击金额打开详情，展示原始上下界、定价覆盖与金额含义。没有可靠价格时仍显示“未定价”，不使用范围中点，也不把未知费用按零计。
- 额度卡片固定为 340 × 300 CSS 像素，按可用空间排列。最多展示两个窗口，额外窗口进入独立详情面板；备注截断，完整备注保留在标题与详情中。
- 额度条采用 50 个分段。未知值保持灰色并缺省 `aria-valuenow`；真实 0% 显示 0，过期重置日期显示“待刷新”，不推断额度自动恢复。
- 点击卡片右上角菜单打开约 440 像素宽的独立面板，卡片本身不展开。面板包含全部额度窗口、重置次数、刷新与移除操作；连接诊断默认收起。
- 保留浅色/深色、时间范围、模型筛选、热力图键盘操作、定价编辑、维护预览与原来的 IPC / 凭据边界。

## 实现合同

`design/desktop-reference/motion.js` 管理局部 WAAPI、系统偏好、状态提示、忙碌状态、选中背景和失效动画清理。`motion.css` 集中定义反馈、原生 dialog 顶层过渡、原生 details 内容过渡、主题、热力图和三种有效模式。旧零时长规则和热力图例外已经收敛到这里。

导航和 ARIA、最终统计值、图表数据、焦点、业务请求与取消立即更新。旧页面即时退出交互树；图表不从零重播，不做数字滚动。每个 WAAPI 目标仅保留当前动画，重复更新从当前呈现状态继续。原生 CSS 过渡由浏览器中断与反转；弹窗 `close()` 不等待动画，关闭期间弹窗及遮罩不接受指针输入。关闭再打开以最终 `open` 状态为准。

展开收起保留原生 `<details>` 键盘和语义；支持时采用 `::details-content`、`interpolate-size` 与离散内容可见性过渡，不支持时即时展开。含长表格的 details 不动画化表格高度，箭头仍反馈。输入、悬停、主题与图表不改变卡片目标尺寸。

设置新增“界面动效”：跟随系统／减少动态／关闭。本应用 localStorage 保存 `agentusage.motion.v1`，不写全局配置。有效模式 full/reduced/off；系统减少动态优先，应用不能恢复完整动效。reduced 移除位移、缩放、旋转与顺滑滚动，只保留至多 80ms 淡入；off 即时切换。偏好改变、窗口缩放、滚动和页面隐藏清理失效 WAAPI 与提示浮层；后台不转动刷新图标。只有真实忙碌期间显示旋转。

额度卡片以连接 ID 保留 DOM 节点；文字与属性增量更新，30 秒年龄文字更新不重复入场。额度窗口字段变化只淡入对应区域，新增/移除才改变卡片入场/退出。详情与诊断展开状态、焦点保留。移除的视觉副本 inert/aria-hidden，不延迟真实移除。账号和采集的主进程权限合同没有变化。

## 性能测量与限制

当前机器原生 Electron、合成 20,000 条记录/100 模型/200 天，每模式连续切换 20 次。源码测试：关闭动效平均约 169ms，完整动效平均约 169–173ms；单次同步提交最大约 312–347ms，压力帧间隔最大约 320–353ms。完整动效未明显增加现有计算耗时，也未残留动画队列。现有统计同步重绘仍阻塞主线程，不能宣称所有大数据交互稳定 60 FPS。

单独弹窗过渡的测试环境 requestAnimationFrame 平均约 3.32ms、最大约 3.5ms；这是自动化环境回调间隔，不是屏幕物理刷新率或真实视觉 FPS。每轮打包测试的精确值保存在对应 `results.json`，不同运行有波动。
